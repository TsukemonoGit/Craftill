# QRラベル作成（案B）仕様メモ

## 目的

- 単一商品のQRラベルをその場で印刷できるようにする。
- 同一商品ラベルを任意枚数（数量管理型・一点物型・在庫管理なし型すべて）で出力できるようにする。
- 複数商品をまとめて選び、1回の印刷ジョブに積めるようにする。

## 画面方針

- メニュー名を「商品一覧（QR生成）」へ変更する。
- 画面は2ペイン構成にする。
  - 左: 商品一覧（検索・種類絞り込み・キュー追加）
  - 右: 印刷キュー（商品ごとの枚数調整・削除・印刷）
- 下部（または右ペイン内）にプレビューを出す。

## 状態モデル

```swift
struct LabelPrintItem: Identifiable, Equatable {
    let productId: String
    var copies: Int
    var id: String { productId }
}
```

- `qrQueue: [LabelPrintItem]`
- `qrListFilterTypeId: String`
- `qrListSearchText: String`
- `qrPendingCopies: Int`

## 操作仕様

- 1商品追加
  - `+1枚`
  - `+N枚`（Nは共通入力値）
- まとめ追加
  - 現在の絞り込み結果を各1枚追加
  - 現在の絞り込み結果を各N枚追加
- キュー編集
  - 枚数を1以上で増減
  - 行削除
  - 全削除

## 印刷仕様

- 印刷対象はキューを展開した配列（`copies`分複製）とする。
  - 例: A×3, B×2 → [A, A, A, B, B]
- 既存のPDFページ分割ロジック（4列・行単位の高さ測定）を流用する。
- キューが空のときは印刷/保存不可。

## 既存導線との接続

- 商品登録直後の「QRラベルを開く」は維持する。
- 遷移時に登録商品をキューへ1枚追加して画面を開く。

## 実装ステップ

1. ViewModelへキュー状態と操作メソッドを追加
2. QR画面を2ペインUIへ置き換え
3. 既存のPNG保存・印刷処理をキュー展開配列へ接続
4. メニュー文言を「商品一覧（QR生成）」へ変更
5. 動作確認（空キュー・大量枚数・登録直後導線）
