# 商品画像の同梱置き場（A-1・P2対策）

商品ID と同じファイル名で画像をこのフォルダに置いてビルドすると、
アプリが起動時・商品追加時・CSV取り込み時に自動で `imageRef` を対応付けます。

- 対応拡張子: .png / .jpg / .jpeg
- 例: `MK-001.png` → 商品 `MK-001` の画像として表示（レジパネル・商品一覧）
- スナップショット送信時の `hasImage` もこの対応結果から導出されます（Bへは画像本体は送らない）。

運用中に差し替える画像は、端末の Documents/originals/ に同じファイル名で置いても解決されます。
