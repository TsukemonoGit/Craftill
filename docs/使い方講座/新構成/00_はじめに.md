> このフォルダは、`../全文_00-05.md` の内容を「読者が知りたいこと」で8つに分けた再構成版です。
> `base/`、`06_QRを試す.md`、`07`〜`61` は親フォルダ（`../`）にあります。

## この資料について

iPadの **Swift Playgrounds** だけで、レジアプリの土台を学ぶための資料です。Macが届いたらXcodeに移ります。

- **対象**: SwiftもPlaygroundsも初めての人
- **前提**: iPadとSwift Playgrounds（Macは最後まで不要）
- **ゴール**: 商品を選び、カートに入れ、合計を出し、会計状態を保存できるようになる
- **大事な約束**: `Product` / `CartLine` / `SaleState` などの型と中核ロジックは `base/` に1か所だけ。レッスン内で定義し直さない

## 何を作るか（レジアプリの全体像）

```text
商品を選ぶ → カートに入れる → 合計を出す → 支払う → 会計を記録する
                                      ├ 現金
                                      └ sats（ビットコインの少額単位）
```

- 商品には「数量管理」「一点物」「在庫なし」などの種類がある
- カートは1行ごとに商品・数量・単価を持つ
- 会計には「進行中」「保留」「完了」「取消」などの状態がある
- 売上・在庫・QR・CSV・SQLiteなどは追加レッスンで扱う

## 型と中核ロジックは base/ に1か所

> **`Product` / `CartLine` / `Sale` などの型は `../base/Types.swift` に1か所だけあります。**
> レッスンごとに書き直すと、レッスン間のコピペが全部壊れます。
>
> - `../base/Types.swift` … `Product` / `CartLine` / `Sale` / `StockMovement` などの型の正
> - `../base/3_標準ロジック.md` … 合計・在庫検証・減算・集計・送信の関数の正
> - `../base/5_カート編集.md` … カートへの追加と編集の正
> - `../base/6_会計の状態機械.md` … 状態遷移・確認・PIN・保存の正
>
> レッスンはここから使います。**型を手で書き直さない**でください。
> 詳しいルールは `../base/00_README.md`。

## Macのターミナルで実行する

Swift Playgroundsではペーストで足りる。Macのターミナルでは、`import`で他ファイルを読み込むことはできない。以下のどちらかで実行

```bash
# base の型と自分のコードを連結して実行
cat ../base/Types.swift my_lesson.swift | swift -

# まとめてビルド(Typeを先にピルド)
swift ../base/Types.swift my_lesson.swift
```

- `swiftc`でコンパイルする場合も、トップレベルの`print`があるファイルを複数並べると`expressions are not allowed at the top level`になる。
- 自分のコードの1行目に`import ../base/Types.swift`のような行は書かない。書くとエラーになる。
- 順序は`base/`→自分のコード。逆にすると「`cannot find type 'ProductType' in scope`」になる。
- `base/3`など他のファイルも使うときは、そのコードブロックの中身を`Types.swift`の後ろに足す。


> **Playgroundsでやるのが基本。** ターミナル実行は、`base/`を更新した時の確認用。
