# 集計する

元: `../siyou.md` A-8

日次の**売上集計**を出す練習。受取方法（現金／sats）ごとに、会計の**件数**と**金額**をまとめます。

- 円と sats は**合算しない**（別々に数える）。
- 件数は**会計単位**。同じ会計に現金とsatsが混ざる**併用会計**は、現金とsatsの**両方**に計上する。だから会計IDを **`Set`**（重複しない入れ物）で持って、同じ会計を二重に数えない。
- 金額は「**登録商品**」と「**野良商品**」に分けて内訳を出す。
- sats受領済みで中断した会計（`status = voided`）は**売上に含めず**、件数とsatsを別に出す。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動きます。
> 画面（SwiftUI）は **アプリ（App）** で作ります（`1_初心者メモ.md`）。

## 集計の入れ物

集計結果を1つにまとめます。件数は `Set<String>`（会計ID）で持ちます。

```swift
struct DailySummary {
    // 現金を受け取った会計
    var cashSaleIDs: Set<String> = []
    var cashJpy = 0                    // 現金決済の円合計＋併用会計の現金分
    // satsを受け取った会計
    var satsSaleIDs: Set<String> = []
    var satsAmount = 0                 // sats払いのsats合計
    // 併用会計（現金とsatsの両方に計上）
    var mixedSaleIDs: Set<String> = []
    // sats受領済みで中断（売上に含めない）
    var voidedSaleIDs: Set<String> = []
    var voidedSats = 0
    // 金額の内訳
    var cashRegistered = 0             // 現金のうち登録商品
    var cashAdhoc = 0                  // 現金のうち野良商品
    var satsRegistered = 0             // satsのうち登録商品
    var satsAdhoc = 0                  // satsのうち野良商品
}
```

- `Set<String>` … 同じ会計IDを2回入れても**1つ**として数える。件数を「会計単位」にするために使う。

## 集計する関数

会計（`sales`）で**件数と合計**を数え、明細（`sale_items`）で**内訳**を出します。

```swift
func summarize(_ sales: [Sale], items: [SaleItem]) -> DailySummary {
    var s = DailySummary()

    // ① 会計を1件ずつ見る（件数は会計単位＝Set）
    for sale in sales {
        if sale.status == "voided" {
            // sats受領済みで中断。売上には入れず、別に数える
            s.voidedSaleIDs.insert(sale.saleId)
            s.voidedSats += sale.totalSats ?? 0
            continue
        }
        guard sale.status == "completed" else { continue }

        let gotCash = (sale.method == "cash" || sale.method == "mixed")
        let gotSats = (sale.method == "lightning" || sale.method == "mixed")

        if gotCash {
            s.cashSaleIDs.insert(sale.saleId)
            s.cashJpy += sale.totalJpy ?? 0
        }
        if gotSats {
            s.satsSaleIDs.insert(sale.saleId)
            s.satsAmount += sale.totalSats ?? 0
        }
        if sale.method == "mixed" {
            s.mixedSaleIDs.insert(sale.saleId)   // 併用は別に数える
        }
    }

    // ② 金額の内訳を明細から足す（会計ごとの受取方法が分かれている）
    for item in items {
        guard let sale = sales.first(where: { $0.saleId == item.saleId }),
              sale.status == "completed" else { continue }

        if item.paidIn == "sats" {
            let amount = (item.unitPriceSats ?? 0) * item.qty
            if item.itemType == "registered" { s.satsRegistered += amount }
            else { s.satsAdhoc += amount }
        } else {
            let amount = item.unitPriceJpy * item.qty
            if item.itemType == "registered" { s.cashRegistered += amount }
            else { s.cashAdhoc += amount }
        }
    }
    return s
}
```

- `continue` … この会計の処理をやめて、次の会計へ進む。
- `guard ... else { continue }` … 対象外の明細は飛ばす（`1_初心者メモ.md` の `guard`）。
- 円とsatsは**別の変数**に足す。同じ変数に混ぜると合算になってしまう。

## 表示して確認する

```swift
let summary = summarize(sales, items: saleItems)

print("── 日次集計 ──")
print("現金: ¥\(summary.cashJpy)  \(summary.cashSaleIDs.count)件")
print("  内訳: 登録 ¥\(summary.cashRegistered) / 野良 ¥\(summary.cashAdhoc)")
print("sats: \(summary.satsAmount) sats  \(summary.satsSaleIDs.count)件")
print("  内訳: 登録 \(summary.satsRegistered) sats / 野良 \(summary.satsAdhoc) sats")
print("うち併用会計: \(summary.mixedSaleIDs.count)件")
print("sats受領済みで中断: \(summary.voidedSaleIDs.count)件 / \(summary.voidedSats) sats（売上に含めない）")
```

**できた合図**:
```
── 日次集計 ──
現金: ¥2900  3件
  内訳: 登録 ¥1700 / 野良 ¥1200
sats: 1200 sats  1件
  内訳: 登録 1200 sats / 野良 0 sats
うち併用会計: 1件
sats受領済みで中断: 1件 / 1200 sats（売上に含めない）
```

- 現金 = 会計1（¥1400）＋会計2の現金分（¥300）＋会計3（¥1200）= **¥2900**。3件。
- sats = 会計2の **1200 sats**。1件。
- 会計2は現金とsatsの**両方**に数えているが、件数はそれぞれ1件ずつ（`Set` で会計単位）。併用は**別に1件**。
- 会計4（sats確認済みで中断）は売上に入れず、**別**に 1件・1200 sats。

## おまけ: 登録商品は種類別にも分ける

`A-8` では、登録商品の内訳を**種類別**にも出します。明細の `paid_in` ごとに、円と sats を分けます。

```swift
struct TypeTotal {
    var qty = 0        // 販売数量
    var jpy = 0        // paid_in == "jpy" の円合計
    var sats = 0       // paid_in == "sats" のsats合計
}

func typeBreakdown(_ items: [SaleItem]) -> [String: TypeTotal] {
    var result: [String: TypeTotal] = [:]
    for item in items {
        guard item.itemType == "registered", let typeId = item.typeId else { continue }
        var total = result[typeId] ?? TypeTotal()
        total.qty += item.qty
        if item.paidIn == "sats" { total.sats += (item.unitPriceSats ?? 0) * item.qty }
        else { total.jpy += item.unitPriceJpy * item.qty }
        result[typeId] = total
    }
    return result
}

func typeName(_ typeId: String) -> String {
    productTypes.first { $0.typeId == typeId }?.name ?? typeId
}

for typeId in typeBreakdown(saleItems).keys.sorted() {
    let t = typeBreakdown(saleItems)[typeId]!
    print("\(typeName(typeId)): 数量 \(t.qty) / 円 \(t.jpy) / sats \(t.sats)")
}
```

**できた合図**:
```
キーホルダー: 数量 2 / 円 800 / sats 1200
ステッカー: 数量 3 / 円 900 / sats 0
```

## 覚えておくこと

- 件数は**会計単位**。併用会計は現金とsatsの**両方**に計上し、`Set` で同じ会計を二重に数えない。
- 併用会計の件数は**別に**表示する。
- 金額は「登録商品」「野良商品」に分ける。円とsatsは**合算しない**。
- sats受領済みで中断した会計（`voided`）は売上に含めず、件数とsatsを別に出す。
- 集計の元は**販売時点の単価**（`unit_price_jpy` / `unit_price_sats`）。今の商品マスタの価格ではない。
