# 画像の版識別子を作る

元: `../siyou.md` A-17

画像の中身から**短い識別子（版識別子）**を作る練習。
原本の内容が変われば識別子も変わる。アプリとBの双方に同じ識別子を出して、**目視で照合**する。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動く。
> 識別子の生成は画像ビルドスクリプト（Mac上）が行い、アプリとBはそれを**表示して比べる**役（`../siyou.md` A-17）。

---

## 版識別子って？

- 画像（または画像一式）の中身から作る**指紋**のような文字列。
- **内容が同じ → 同じ識別子**。1枚でも差し替えると**別の識別子**になる。
- アプリとBで画像は別々に配られる（アプリは同梱、Bはデプロイ）。だから
  両方に同じ識別子を出しておき、**片方の更新を忘れていないか目で確認**できる（`../siyou.md` A-17、C-1 #22）。

`../siyou.md` A-17 の処理「5. 版識別子の生成：原本の内容から識別子（ハッシュ等）を生成」に対応。

---

## 前提データ（ハッシュを作る小道具）

```swift
import Foundation
import CryptoKit

/// 中身の Data から SHA256 の 16進文字列（64文字）を作る
func sha256Hex(_ data: Data) -> String {
    let digest = SHA256.hash(data: data)
    return digest.map { String(format: "%02x", $0) }.joined()
}

/// Data から、先頭 `length` 文字だけを使った短い識別子を作る。
/// 64文字は長いので、表示用に切り詰める（同じ規則で両側が作れば照合できる）。
func versionID(_ data: Data, length: Int = 12) -> String {
    let hex = sha256Hex(data)
    return String(hex.prefix(length))
}
```

- `SHA256.hash(data:)` … 中身からハッシュを作る。
- `String(hex.prefix(length))` … 先頭から `length` 文字を取り出す（例: 12文字）。

## 画像1枚の版識別子

同じ中身なら同じ、1バイト違うと別になることを確かめる。

```swift
let imageA = Data("キーホルダー08の画像データ".utf8)
let imageA2 = Data("キーホルダー08の画像データ".utf8)   // 中身は同じ
let imageAModified = Data("キーホルダー08の画像デーX".utf8) // 1文字違い

print("A       : \(versionID(imageA))")
print("A(同じ) : \(versionID(imageA2))")
print("A(変更) : \(versionID(imageAModified))")
```

**できた合図**（値は環境で変わる。大事なのは一致/不一致）:
```
A       : 7d1f0a3c9b42
A(同じ) : 7d1f0a3c9b42   ← 一致する
A(変更) : c30e55a1d908   ← 変わる
```
中身が同じ `A` と `A(同じ)` は同じ識別子。1文字変えた `A(変更)` は別の識別子。

## 画像一式の版識別子（ビルド全体の版）

画像は1枚ではなく**全商品ぶん**ある。全体をまとめた識別子を作る。
商品IDの順に並べ、中身をつないでからハッシュする。1枚でも替われば全体が変わる。

```swift
struct ImageBlob {
    let productID: String
    let data: Data
}

/// 商品IDの昇順に並べて中身をつなぎ、1つの版識別子を作る。
/// 並び順を固定するので、同じ原本なら何度実行しても同じ値になる。
func buildVersionID(_ blobs: [ImageBlob], length: Int = 12) -> String {
    let joined = blobs
        .sorted { $0.productID < $1.productID }   // 商品IDの昇順
        .map { $0.data }                          // 中身だけ取り出す
        .reduce(into: Data()) { $0.append($1) }   // 順につなげる
    return versionID(joined, length: length)      // つないだ中身から識別子
}
```

- `.sorted { $0.productID < $1.productID }` … 並び順を固定する（これが無いと実行ごとに変わりうる）。
- `.reduce(into: Data()) { $0.append($1) }` … 空の `Data` に順番に足していく。

```swift
let blobsV1: [ImageBlob] = [
    ImageBlob(productID: "KH-008", data: Data("KH-008の画像".utf8)),
    ImageBlob(productID: "ST-001", data: Data("ST-001の画像".utf8)),
]

let blobsV2: [ImageBlob] = [
    ImageBlob(productID: "KH-008", data: Data("KH-008の画像(差し替え)".utf8)),  // 1枚替えた
    ImageBlob(productID: "ST-001", data: Data("ST-001の画像".utf8)),
]

print("ビルド版 v1: \(buildVersionID(blobsV1))")
print("ビルド版 v2: \(buildVersionID(blobsV2))")
```

**できた合図**:
```
ビルド版 v1: 2b9c4e7a10f3
ビルド版 v2: 88a1d0c56e77   ← 1枚差し替えると変わる
```

## アプリとBに表示して目視照合する

生成した版識別子を、**アプリの画面**と**Bのページ**の両方に小さく出す（`../siyou.md` A-17、B-1）。
営業前に、両方が同じ値かを見比べる。ここでは文字として出すだけの例。

```swift
let appVersionID = buildVersionID(blobsV1)   // アプリに同梱した画像から作った値

// SwiftUI で表示する例（アプリまたはブック）
// import SwiftUI
// Text("画像版: \(appVersionID)").font(.caption).foregroundColor(.secondary)

#if os(macOS)
print("アプリ(画像版): \(appVersionID)   ← 画面のすみに表示")
#else
print("アプリ(iPad): \(appVersionID)   ← 画面のすみに表示")
#endif
print("B(画像版)    : \(appVersionID)   ← Bのページ下部に表示（照合する）")
```

**照合のしかた**:
- **一致** … アプリとBが同じ画像を使っている。
- **不一致** … 片方の差し替え・デプロイを忘れている（`../siyou.md` C-1 #22）。手順をやり直す。

---

## 覚えておくこと

- 版識別子は「**原本の内容から作る短いハッシュ**」。アプリが画像データをBへ送るわけではない（`../siyou.md` A-14）。
- 並び順を固定してからハッシュする。固定しないと、同じ原本でも値が変わってしまう。
- アプリとBの**両方に表示**して、営業前に目で照合する（`../siyou.md` C-6 #57、#58）。
- 1枚差し替え → 再ビルド（アプリ）＋再デプロイ（B）の両方が必要。識別子の一致で抜けを確認できる。
