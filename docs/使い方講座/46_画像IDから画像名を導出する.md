# 商品IDから画像名を導出する

元: `../siyou.md` A-14, A-17

画像ファイルの名前は**商品IDと同じ**にする（例: `KH-008.jpg`）。これが今回の決まり。
商品IDさえ分かれば、画像ファイル名も、`image_ref` も、`has_image` も、Bの取得キーも**導出できる**ようにする。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動く。
> ファイル名を実際に探すのはビルド時（アプリ）とスクリプト（Mac）の役割。

---

## 決まりごと

- 画像ファイル名は **商品IDと同一**（`../siyou.md` A-1、A-17）。例: `ST-001.jpg`、`KH-008.jpg`。
- `image_ref` … アプリに同梱した画像への参照。**アプリの中だけで使い、Bへは送らない**（`../siyou.md` A-13）。
- `has_image`（画像の有無）… **保持しない**。`image_ref` の有無から**導出**する（`../siyou.md` A-13）。
- Bは画像データを受け取らず、商品IDから画像の名前を導出して取得する（`../siyou.md` A-14）。
  例: ファイル名 `KH-008.jpg`、KVのキー `img:KH-008`。

---

## 前提データ

```swift
import Foundation

struct Product {
    let id: String            // 商品ID 例: "KH-008"
    let typeId: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?
    var stock: Int?
    let imageRef: String?     // 同梱画像への参照（無いときは nil）
    let isPublic: Bool
}

enum StockMode {
    case counted   // 数量管理型
    case unique    // 一点物型
    case none      // 在庫管理なし型
}

let products: [Product] = [
    Product(id: "ST-001", typeId: "sticker",   name: "ステッカー まる",   priceJpy: 300, priceSats: 500,  stock: 10, imageRef: "ST-001.jpg", isPublic: true),
    Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく", priceJpy: 300, priceSats: nil,  stock: 10, imageRef: "ST-003.jpg", isPublic: true),
    Product(id: "KH-008", typeId: "keyholder", name: "キーホルダー 08",  priceJpy: 800, priceSats: 1200, stock: 1,  imageRef: "KH-008.jpg", isPublic: true),
    Product(id: "KH-013", typeId: "keyholder", name: "キーホルダー 13",  priceJpy: 800, priceSats: 1200, stock: 1,  imageRef: nil,          isPublic: true),
]
```

`KH-013` は画像を用意していない例（`imageRef` が `nil`）。

---

## 商品IDからファイル名を作る関数

```swift
/// 商品IDから画像ファイル名を作る。
/// - Parameter productID: 例 "KH-008"
/// - Parameter ext: 拡張子（既定は "jpg"）
/// - Returns: 例 "KH-008.jpg"
func imageFileName(for productID: String, ext: String = "jpg") -> String {
    return productID + "." + ext
}

/// 商品IDから image_ref を作る（ファイル名と同じ）。
func makeImageRef(for productID: String) -> String {
    return imageFileName(for: productID)
}

/// image_ref の有無から has_image を導出する。
/// 空文字も「画像なし」とみなす。
func hasImage(_ imageRef: String?) -> Bool {
    guard let ref = imageRef else { return false }
    return !ref.isEmpty
}

/// Bが画像を取得するときのキー名（ファイル名から導出）。
func kvImageKey(for productID: String) -> String {
    return "img:" + productID
}
```

- 名前は**1か所の決まり**（`商品ID + "." + 拡張子`）で作る。手で書く場所を増やすと食い違う。
- `hasImage` は `imageRef` から**計算するだけ**。新しい列としては持たない（`../siyou.md` A-13）。

---

## 表示して確認する

```swift
for p in products {
    let fileName = imageFileName(for: p.id)
    let ref = makeImageRef(for: p.id)             // 画像を用意した場合の参照
    let flag = hasImage(p.imageRef)               // ← 実際の image_ref から導出
    let key = kvImageKey(for: p.id)

    print("\(p.id)  ファイル名 \(fileName)  has_image \(flag)  KVキー \(key)")
}
```

**できた合図**:
```
ST-001  ファイル名 ST-001.jpg  has_image true   KVキー img:ST-001
ST-003  ファイル名 ST-003.jpg  has_image true   KVキー img:ST-003
KH-008  ファイル名 KH-008.jpg  has_image true   KVキー img:KH-008
KH-013  ファイル名 KH-013.jpg  has_image false  KVキー img:KH-013
```
`KH-013` は `imageRef` が `nil` なので `has_image` が `false`。それ以外は `true`。

## Bへの送信内容と画像（おさらい）

スナップショットに**画像データは入れない**（`../siyou.md` A-14）。入れるのは `has_image` だけ。

```swift
// Bへ送る1商品ぶんのイメージ（送る項目の例）
struct PublicProduct {
    let productID: String
    let typeId: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?
    let stock: Int?
    let hasImage: Bool       // ← image_ref から導出した真偽値
}

func toPublic(_ p: Product, mode: StockMode) -> PublicProduct {
    PublicProduct(
        productID: p.id,
        typeId: p.typeId,
        name: p.name,
        priceJpy: p.priceJpy,
        priceSats: p.priceSats,
        stock: (mode == .none) ? nil : p.stock,   // 在庫管理なし型は送らない（空）
        hasImage: hasImage(p.imageRef)            // image_ref から導出
    )
}
```

```swift
#if os(macOS)
// アプリ（Mac）：同梱リソースから画像を読む場所の例
// Bundle.main.url(forResource: "KH-008", withExtension: "jpg")
print("Mac: 同梱画像は Bundle から")
#else
// アプリ（iPad/iOS）：同じく Bundle から
print("iPad: 同梱画像は Bundle から")
#endif
```

`has_image` が `false` の商品は、Bは画像を取得せず**文字表示**にする（`../siyou.md` B-1）。

---

## 覚えておくこと

- 画像ファイル名は**商品IDと同一**（`KH-008` → `KH-008.jpg`）。ここがすべての出発点。
- `image_ref` はアプリ内だけ。Bへは送らない。Bは商品IDから名前を導出して取得する。
- `has_image` は**保持しない**。`image_ref` の有無から導出する（`../siyou.md` A-13）。
- ファイル名を作る関数は**1つ**にして、アプリ・B・スクリプトで同じ規則を使う。
