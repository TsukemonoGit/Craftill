# 28. 一点物型の重複を防ぐ

元: `../siyou.md` A-1（種類ごとのカート挙動・同一商品の再追加）

**ゴール**: **一点物型（`unique`）**の商品を、**同じ会計で2回**カートに追加しようとしたら**エラー**にする。
数量管理型（`counted`）・在庫管理なし型（`none`）は、再追加で**数量+1**にする。
カートを `[CartLine]` で持ち、**同じ `product.id` があるか**を調べて種類（`StockMode`）で分岐する。

> 画面は出さず、`print` で結果を見る**純ロジック**の練習。**ブック（Book）**で作る。
> **レッスン同士は独立**。このファイルだけで完結する。

## 前提データ（このまま貼れば動く）

```swift
// ── 在庫の扱い（種類ごと）──────────────
enum StockMode {
    case counted   // 数量管理型（ステッカー。数量+1）
    case unique    // 一点物型（キーホルダー。重複はエラー）
    case none      // 在庫管理なし型（数量+1）
}

// ── 種類の定義（product_types 相当）────
struct ProductType {
    let typeId: String
    let name: String
    let idPrefix: String
    let idDigits: Int
    let stockMode: StockMode
    let attrLabel1: String?
    let attrLabel2: String?
    let attrLabel3: String?
}

// ── 商品（products 相当）──────────────
struct Product {
    let id: String
    let typeId: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?   // nil なら sats払いでも現金で受け取る
    var stock: Int?
}

// ── カートの行（形は 03_レッスン.md レッスン2 で決めたものと同じ）──
struct CartLine {
    let id: String          // 登録商品は商品ID、野良は "ADHOC-1" など
    let typeId: String?     // 登録商品は種類ID、野良は nil
    let name: String        // カートに入れた時点の商品名
    let unitPriceJpy: Int   // カートに入れた時点の円単価
    let unitPriceSats: Int? // カートに入れた時点のsats単価
    var qty: Int
    let isAdhoc: Bool       // 野良かどうか
}

/// 登録商品からカートの行を作る
func line(_ p: Product, qty: Int) -> CartLine {
    CartLine(id: p.id, typeId: p.typeId, name: p.name,
             unitPriceJpy: p.priceJpy, unitPriceSats: p.priceSats,
             qty: qty, isAdhoc: false)
}

// ── 種類（今回の商品。../開発/6_データベース.md より）──
let productTypes: [ProductType] = [
    ProductType(typeId: "sticker", name: "ステッカー", idPrefix: "ST", idDigits: 3,
                stockMode: .counted, attrLabel1: "色", attrLabel2: "模様", attrLabel3: nil),
    ProductType(typeId: "keyholder", name: "キーホルダー", idPrefix: "KH", idDigits: 3,
                stockMode: .unique, attrLabel1: "色", attrLabel2: "模様", attrLabel3: nil),
]

// ── 商品のサンプル（../開発/6_データベース.md より）──
let products: [Product] = [
    Product(id: "ST-001", typeId: "sticker",   name: "ステッカー まる",     priceJpy: 300, priceSats: 500,  stock: 10),
    Product(id: "ST-002", typeId: "sticker",   name: "ステッカー さんかく", priceJpy: 300, priceSats: 500,  stock: 10),
    Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく",   priceJpy: 300, priceSats: nil,  stock: 10),
    Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01", priceJpy: 800, priceSats: 1200, stock: 1),
    Product(id: "KH-008", typeId: "keyholder", name: "キーホルダー 08", priceJpy: 800, priceSats: 1200, stock: 1),
]

// サンプルから1つ引く
func product(_ id: String) -> Product { products.first { $0.id == id }! }

// 在庫管理なし型（none）の確認用。今回の商品にはないが、既定の3種類目（A-1）
let serviceType = ProductType(typeId: "service", name: "受注サービス", idPrefix: "SV", idDigits: 3,
                              stockMode: .none, attrLabel1: nil, attrLabel2: nil, attrLabel3: nil)
let service = Product(id: "SV-001", typeId: "service", name: "受注サービス",
                      priceJpy: 1000, priceSats: nil, stock: nil)
```

## 1. 同じ商品がカートにあるか調べる

`product.id` を見て、カート内の**同じ行**を探す。

```swift
/// 同じ product_id の行がカートにあるか
func hasProduct(_ id: String, in cart: [CartLine]) -> Bool {
    return cart.contains { $0.id == id }
}

/// 同じ product_id の行の位置（無ければ nil）
func findLine(_ id: String, in cart: [CartLine]) -> Int? {
    return cart.firstIndex { $0.id == id }
}
```

- `contains { ... }` … 条件に合う要素が1つでもあれば `true`
- `firstIndex { ... }` … 条件に合う最初の位置を返す（無ければ `nil`）

## 2. 追加する関数（種類で分岐）

結果は `enum` で返し、成功と失敗をはっきり分ける。

```swift
// 追加の結果
enum AddResult {
    case added(productId: String, qty: Int)  // 追加できた（追加後の数量）
    case rejected(reason: String)            // 追加できなかった
}

/// 商品をカートに追加する。一点物型は同一会計で2回目をはねる
func addToCart(_ product: Product,
               types: [ProductType],
               cart: inout [CartLine]) -> AddResult {
    guard let pt = types.first(where: { $0.typeId == product.typeId }) else {
        return .rejected(reason: "種類が未定義")
    }
    let index = findLine(product.id, in: cart)

    switch pt.stockMode {
    case .unique:
        // 一点物型: すでにカートにあればエラー（1回だけ）
        if index != nil {
            return .rejected(reason: "一点物（\(product.name)）は同一会計で追加済みです")
        }
        cart.append(line(product, qty: 1))
        return .added(productId: product.id, qty: 1)

    case .counted:
        // 数量管理型: 再追加は数量+1
        if let i = index {
            cart[i].qty += 1
            return .added(productId: product.id, qty: cart[i].qty)
        } else {
            cart.append(line(product, qty: 1))
            return .added(productId: product.id, qty: 1)
        }

    case .none:
        // 在庫管理なし型: 再追加は数量+1（上限なし）
        if let i = index {
            cart[i].qty += 1
            return .added(productId: product.id, qty: cart[i].qty)
        } else {
            cart.append(line(product, qty: 1))
            return .added(productId: product.id, qty: 1)
        }
    }
}
```

- `index != nil` … 「すでにある」。一点物型ではここで止める
- `inout` … 配列を**その場で書き換える**ために渡す（`cart` を戻り値にせず直接変更する）

## 3. 動かしてみる

```swift
// 結果を1行で出す補助
func show(_ label: String, _ result: AddResult) {
    switch result {
    case .added(let id, let qty): print("\(label): 追加OK（\(id) 数量\(qty)）")
    case .rejected(let reason):   print("\(label): エラー / \(reason)")
    }
}

var cart: [CartLine] = []

// 一点物型（unique）: 1回目はOK、2回目はエラー
show("KH-001 1回目", addToCart(product("KH-001"), types: productTypes, cart: &cart))
show("KH-001 2回目", addToCart(product("KH-001"), types: productTypes, cart: &cart))

// 数量管理型（counted）: 再追加で数量が増える
show("ST-001 1回目", addToCart(product("ST-001"), types: productTypes, cart: &cart))
show("ST-001 2回目", addToCart(product("ST-001"), types: productTypes, cart: &cart))
show("ST-001 3回目", addToCart(product("ST-001"), types: productTypes, cart: &cart))

// 在庫管理なし型（none）: 再追加で数量が増える
let allTypes = productTypes + [serviceType]
show("SV-001 1回目", addToCart(service, types: allTypes, cart: &cart))
show("SV-001 2回目", addToCart(service, types: allTypes, cart: &cart))

// カートの中身
for line in cart {
    print("\(line.id)  ×\(line.qty)")
}
```

**できた合図**:
```
KH-001 1回目: 追加OK（KH-001 数量1）
KH-001 2回目: エラー / 一点物（キーホルダー 01）は同一会計で追加済みです
ST-001 1回目: 追加OK（ST-001 数量1）
ST-001 2回目: 追加OK（ST-001 数量2）
ST-001 3回目: 追加OK（ST-001 数量3）
SV-001 1回目: 追加OK（SV-001 数量1）
SV-001 2回目: 追加OK（SV-001 数量2）
KH-001  ×1
ST-001  ×3
SV-001  ×2
```
- KH-001 は **1行だけ**（2回目は追加されない）
- ST-001 は**同じ行の数量**が増える（行が増えるのではない）

## まとめ

- カートは `[CartLine]` で持ち、**同じ `product_id` があるか**を `firstIndex { ... }` で調べる
- **一点物型（`unique`）**: すでにあれば**エラー**。追加できるのは同一会計で1回だけ
- **数量管理型（`counted`）・在庫管理なし型（`none`）**: 再追加は**数量+1**（新しい行は足さない）
- 追加の成否は `enum AddResult` で返すと、結果を分けて扱いやすい
- 重複の判定は**追加経路（QR・手動・商品パネル）によらず同じ**（A-1）
