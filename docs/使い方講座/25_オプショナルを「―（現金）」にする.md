# 25. オプショナルを「―（現金）」にする

元: `../siyou.md` A-3（カート表示）、A-6-1（請求sats額・現金分）

**ゴール**: `price_sats`（sats単価）が**空（nil）**の行を、画面では「**―（現金）**」と表示する。
その行は sats払いでも**現金で受け取る**（sats合計には入れず、**現金分**に入れる）。
ついでに `if let` / `guard let`（オプショナルの取り出し）を復習する。

> 画面は出さず、`print` で結果を見る**純ロジック**の練習。**ブック（Book）**で作る。

## 前提データ（このまま貼れば動く）

```swift
import Foundation

// ── 在庫の扱い（種類ごと）──────────────
enum StockMode {
    case counted   // 数量管理型
    case unique    // 一点物型
    case none      // 在庫管理なし型（今回は商品なし）
}

// ── 種類の定義（product_types 相当）────
struct ProductType {
    let typeId: String
    let name: String
    let idPrefix: String
    let idDigits: Int
    let stockMode: StockMode
    let attrLabel1: String?
    let attrLabel2: String?
    let attrLabel3: String?
}

// ── 商品（products 相当）──────────────
struct Product {

// ── カートの行 ─────────────────────────
struct CartLine {

    let unitPriceJpy: Int   // カートに入れた時点の円単価
    let unitPriceSats: Int? // カートに入れた時点のsats単価
    var qty: Int
    let isAdhoc: Bool       // 野良かどうか
}

// ── サンプル（../開発/6_データベース.md より）──
let productTypes: [ProductType] = [

let products: [Product] = [

func line(_ p: Product, qty: Int) -> CartLine {
```

## 1. sats単価を文字列にする

```swift
/// sats単価を表示用の文字列にする。nil なら「―（現金）」
func satsLabel(_ priceSats: Int?) -> String {
    if let sats = priceSats {     // 値が入っていれば取り出す（if let）
        return "\(sats) sats"
    } else {                      // 空（nil）のとき
        return "―（現金）"
    }
}

print(satsLabel(500))     // 500 sats
print(satsLabel(nil))     // ―（現金）
```

**ポイント**: 「空」を画面では「**―（現金）**」と見せる。数字が無いことを**そのまま**伝える記号。

## 2. カート行を表示する

```swift
func cartRowText(_ line: CartLine) -> String {
    return "\(line.name)  ¥\(line.unitPriceJpy)  \(satsLabel(line.unitPriceSats))  ×\(line.qty)"
}

print(cartRowText(line(product("KH-001"), qty: 1)))  // キーホルダー 01  ¥800  1200 sats  ×1
print(cartRowText(line(product("ST-003"), qty: 1)))  // ステッカー しかく  ¥300  ―（現金）  ×1
```

## 3. 合計での扱い（sats合計に入れない）

sats払いのとき：

- sats単価**あり**の行 → **sats合計**へ
- sats単価**なし**の行（「―（現金）」）→ **現金分**へ

現金合計には**全行**を足す。

```swift
struct Totals {
    var sats = 0          // sats単価のある行のsats合計
    var cashForSats = 0   // sats単価のない行の円合計（＝現金分）
    var cash = 0          // 全行の円合計
}

func totals(_ cart: [CartLine]) -> Totals {
    var t = Totals()
    for line in cart {
        if let s = line.unitPriceSats {                 // sats単価あり
            t.sats += s * line.qty
        } else {                                    // 「―（現金）」の行
            t.cashForSats += line.unitPriceJpy * line.qty
        }
        t.cash += line.unitPriceJpy * line.qty          // 現金合計には全部
    }
    return t
}
```

- `if let s = line.unitPriceSats` … nil かどうかで分岐。`s` は `{ }` の中だけで使える（`01_初心者メモ.md`）

## 4. `guard let` の復習

「ダメなら先に抜ける」書き方。1行のsats小計を出す関数で比べてみる。

```swift
/// if let 版: nil のときは 0 を返す
func satsSubtotalIf(_ line: CartLine) -> Int {
    if let s = line.unitPriceSats {
        return s * line.qty
    }
    return 0
}

/// guard let 版: nil なら先に return して、残りは本筋
func satsSubtotalGuard(_ line: CartLine) -> Int {
    guard let s = line.unitPriceSats else {
        return 0          // else の中は必ず抜ける
    }
    return s * line.qty   // ここでは s が使える
}

print(satsSubtotalIf(line(product("KH-001"), qty: 2)))    // 2400
print(satsSubtotalGuard(line(product("ST-003"), qty: 2))) // 0（sats単価なし）
```

| | 取り出した値が使える範囲 | 向いてる用途 |
| --- | --- | --- |
| `if let` | `{ }` の中だけ | 条件分岐 |
| `guard let` | そのあと全部 | ダメなときは先に抜ける |

## 5. 動かしてみる

```swift
// ST-001（sats500）＋ ST-003（―（現金））＋ KH-008（sats1200）
let cart = [
    line(product("ST-001"), qty: 1),
    line(product("ST-003"), qty: 1),
    line(product("KH-008"), qty: 1),
]

for l in cart {
    print(cartRowText(l))
}

let t = totals(cart)
print("sats払い　\(t.sats)sats ＋ \(t.cashForSats)円")
print("現金　　　\(t.cash)円")
```

**できた合図**:
```
ステッカー まる  ¥300  500 sats  ×1
ステッカー しかく  ¥300  ―（現金）  ×1
キーホルダー 08  ¥800  1200 sats  ×1
sats払い　1700sats ＋ 300円
現金　　　1400円
```
- ST-003 の ¥300 は **sats合計に入らず、現金分（300円）** になっている
- 現金合計は全行の合計なので 300 + 300 + 800 = **1400円**
