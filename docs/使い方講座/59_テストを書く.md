# テストを書く

元: `../siyou.md` A-1, A-2, A-3, A-7

**テスト**とは、「この関数はこう動くはず」という**期待**をコードで書いて、実際の結果と**自動で比べる**仕組みです。
手で毎回確かめなくても、合っているかどうかを機械が判定してくれます。

主に **Swift Testing**（`import Testing` / `@Test` / `#expect`）を使い、**XCTest** にも軽く触れます。
題材は、在庫の減算（A-7）・合計2行（A-3）・ID正規化（A-2）・一点物の重複エラー（A-1）。

> ここではテストの考え方と書き方を学びます。**同じファイルに対象の関数とテストを置けば**、実行して動きを確かめられます。
> 本物のプロジェクトでは、テストはアプリとは**別のターゲット**に置き、`@testable import アプリ名` で読み込みます。

---

## テストの形

```
① 用意（given） … テスト用のデータをそろえる
② 実行（when）  … 関数を呼ぶ
③ 検証（then）  … 期待と実際を比べる（ここがテストの本体）
```

比べる部分が**アサーション**（`#expect(...)`）です。`#expect` の中は `true` になるはず。ならなければ「失敗」として報告されます。

## テスト対象と前提データ

```swift
import Foundation

// ── 種類（A-1）────────────────────────
enum StockMode: String { case counted, unique, none }

struct ProductType {
    let typeId: String
    let idPrefix: String
    let idDigits: Int
    let stockMode: StockMode
}

struct Product {
    let id: String
    let typeId: String       // 種類ID（"sticker" など）
    let name: String
    let priceJpy: Int
    let priceSats: Int?
    var stock: Int?
    let stockMode: StockMode
}

struct CartLine {
    let id: String          // 登録商品は商品ID、野良は "ADHOC-1" など
    let typeId: String?     // 登録商品は種類ID、野良は nil
    let name: String        // カートに入れた時点の商品名
    let unitPriceJpy: Int   // カートに入れた時点の円単価
    let unitPriceSats: Int? // カートに入れた時点のsats単価
    var qty: Int
    let isAdhoc: Bool       // 野良かどうか
}

let productTypes: [ProductType] = [
    ProductType(typeId: "sticker",   idPrefix: "ST", idDigits: 3, stockMode: .counted),
    ProductType(typeId: "keyholder", idPrefix: "KH", idDigits: 3, stockMode: .unique),
]

// ── テスト対象の関数 ───────────────────

// ID正規化（A-2）
func normalizeProductID(_ raw: String) -> String? {
    let half = raw.applyingTransform(.fullwidthToHalfwidth, reverse: false) ?? raw
    let upper = half.uppercased()
    let prefix = String(upper.filter { $0.isLetter })
    let digitText = upper.filter { $0.isNumber }
    guard let pt = productTypes.first(where: { $0.idPrefix == prefix }) else { return nil }
    guard let n = Int(digitText) else { return nil }
    return prefix + "-" + String(format: "%0\(pt.idDigits)d", n)
}

// 合計（A-3）
func totals(_ cart: [CartLine]) -> (sats: Int, cashForSats: Int, cash: Int) {
    var sats = 0, cashForSats = 0, cash = 0
    for line in cart {
        if let s = line.unitPriceSats { sats += s * line.qty }
        else { cashForSats += line.unitPriceJpy * line.qty }
        cash += line.unitPriceJpy * line.qty
    }
    return (sats, cashForSats, cash)
}

func totalLines(_ cart: [CartLine]) -> (satsLine: String, cashLine: String) {
    let t = totals(cart)
    let hasSats = cart.contains { $0.unitPriceSats != nil }
    let satsLine: String
    if !hasSats { satsLine = "sats払い　選択不可（sats単価のある商品がありません）" }
    else if t.cashForSats == 0 { satsLine = "sats払い　\(t.sats)sats" }
    else { satsLine = "sats払い　\(t.sats)sats ＋ \(t.cashForSats)円" }
    return (satsLine, "現金　　　\(t.cash)円")
}

// 在庫減算（A-7）
enum StockError: Error, Equatable { case insufficient(productID: String) }

func decrementStock(_ cart: [CartLine], stock: inout [Product]) throws {
    // ① 検証（足りなければ何も変えずに例外）
    for line in cart {
        guard let p = stock.first(where: { $0.id == line.id }),
              p.stockMode != .none, let current = p.stock else { continue }
        if line.qty > current { throw StockError.insufficient(productID: line.id) }
    }
    // ② 減算
    for line in cart {
        guard let i = stock.firstIndex(where: { $0.id == line.id }),
              stock[i].stockMode != .none, let current = stock[i].stock else { continue }
        stock[i].stock = current - line.qty
    }
}

// 一点物の重複（A-1）
enum AddResult: Equatable { case added(qty: Int); case duplicate; case soldOut }

func addToCart(_ p: Product, cart: inout [CartLine]) -> AddResult {
    if p.stockMode != .none, let s = p.stock, s <= 0 { return .soldOut }
    if let i = cart.firstIndex(where: { $0.id == p.id }) {
        if p.stockMode == .unique { return .duplicate }
        cart[i].qty += 1
        return .added(qty: cart[i].qty)
    }
    cart.append(CartLine(id: p.id, typeId: p.typeId, name: p.name, unitPriceJpy: p.priceJpy,
                         unitPriceSats: p.priceSats, qty: 1, isAdhoc: false))
    return .added(qty: 1)
}
```

## 59-1. 在庫減算のテスト（A-7）

「数量ぶん減る」「一点物は1→0」「足りなければエラー」を確かめます。**テストごとに在庫を新しく作る**のがコツです。

```swift
import Testing

@Suite("在庫の減算（A-7）")
struct StockDecrementTests {

    // テスト用の在庫を毎回新しく作る
    private func makeStock() -> [Product] {
        [
            Product(id: "ST-001", typeId: "sticker", name: "ステッカー まる", priceJpy: 300, priceSats: 500, stock: 10, stockMode: .counted),
            Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
            Product(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
        ]
    }

    @Test("数量管理型は数量ぶん減る")
    func countedDecreases() throws {
        var stock = makeStock()
        let cart = [CartLine(id: "ST-001", typeId: "sticker", name: "ステッカー まる",
                             unitPriceJpy: 300, unitPriceSats: 500, qty: 2, isAdhoc: false)]
        try decrementStock(cart, stock: &stock)
        #expect(stock.first { $0.id == "ST-001" }?.stock == 8)
    }

    @Test("一点物は1から0になる")
    func uniqueBecomesZero() throws {
        var stock = makeStock()
        let cart = [CartLine(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01",
                             unitPriceJpy: 800, unitPriceSats: 1200, qty: 1, isAdhoc: false)]
        try decrementStock(cart, stock: &stock)
        #expect(stock.first { $0.id == "KH-001" }?.stock == 0)
    }

    @Test("在庫不足ならエラーになる")
    func shortageThrows() {
        #expect(throws: StockError.self) {
            var stock = makeStock()
            let cart = [CartLine(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02",
                                 unitPriceJpy: 800, unitPriceSats: 1200, qty: 2, isAdhoc: false)]   // 在庫1に2
            try decrementStock(cart, stock: &stock)
        }
    }
}
```

- `@Suite("説明")` … テストのまとまり（無くても動く）
- `@Test("説明") func ...` … テスト1件。名前は英語、説明は日本語でよい
- `#expect(条件)` … 条件が `true` なら合格
- `#expect(throws: エラーの型) { ... }` … 中でその型のエラーが投げられれば合格

## 59-2. 合計2行のテスト（A-3）

文字列まで含めて確かめます。`satsLine` は3パターン（satsのみ／sats＋現金分／選択不可）を全部試します。

```swift
@Suite("合計2行（A-3）")
struct TotalsTests {

    @Test("全部sats単価あり → satsのみ")
    func satsOnly() {
        let cart = [
            CartLine(id: "ST-001", typeId: "sticker", name: "ステッカー まる", unitPriceJpy: 300, unitPriceSats: 500, qty: 2, isAdhoc: false),
            CartLine(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01", unitPriceJpy: 800, unitPriceSats: 1200, qty: 1, isAdhoc: false),
        ]
        let lines = totalLines(cart)
        #expect(lines.satsLine == "sats払い　2200sats")
        #expect(lines.cashLine == "現金　　　1400円")
    }

    @Test("sats単価なしを含む → sats ＋ 現金分")
    func withCashPart() {
        let cart = [
            CartLine(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02", unitPriceJpy: 800, unitPriceSats: 1200, qty: 1, isAdhoc: false),
            CartLine(id: "ST-003", typeId: "sticker", name: "ステッカー しかく", unitPriceJpy: 300, unitPriceSats: nil, qty: 1, isAdhoc: false),
        ]
        let lines = totalLines(cart)
        #expect(lines.satsLine == "sats払い　1200sats ＋ 300円")
        #expect(lines.cashLine == "現金　　　1100円")
    }

    @Test("全部sats単価なし → 選択不可")
    func allCash() {
        let cart = [CartLine(id: "ST-003", typeId: "sticker", name: "ステッカー しかく",
                             unitPriceJpy: 300, unitPriceSats: nil, qty: 2, isAdhoc: false)]
        #expect(totalLines(cart).satsLine == "sats払い　選択不可（sats単価のある商品がありません）")
    }
}
```

## 59-3. ID正規化のテスト（A-2）

## 59-4. 一点物の重複エラーのテスト（A-1）

「1回目は追加、2回目は重複で追加されない」を確かめます。**カートの件数**も見ます。

```swift
@Suite("一点物の重複エラー（A-1）")
struct DuplicateTests {

    @Test("一点物は2回目が duplicate")
    func uniqueTwice() {
        var cart: [CartLine] = []
        let p = Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01",
                        priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique)
        #expect(addToCart(p, cart: &cart) == .added(qty: 1))
        #expect(addToCart(p, cart: &cart) == .duplicate)
        #expect(cart.count == 1)   // 行が増えていない
    }

    @Test("数量管理型は2回目で数量2")
    func countedTwice() {
        var cart: [CartLine] = []
        let p = Product(id: "ST-001", typeId: "sticker", name: "ステッカー まる",
                        priceJpy: 300, priceSats: 500, stock: 10, stockMode: .counted)
        #expect(addToCart(p, cart: &cart) == .added(qty: 1))
        #expect(addToCart(p, cart: &cart) == .added(qty: 2))
        #expect(cart.first?.qty == 2)   // 同じ行の数量が増える
    }
}
```

## 59-5. テストが失敗する例 → 直す

テストは**失敗するから**役に立ちます。失敗の見方と直し方を2つ見ます。

### 例1: テストの「期待」が間違っていた

```swift
@Test("（失敗例）ID正規化")
func brokenExpectation() {
    #expect(normalizeProductID("kh8") == "KH-8")   // ← 期待の書き間違い
}
```

**出る失敗**:

```
✘ Test "ID正規化" recorded an issue: Expectation failed:
    ("KH-008") == "KH-8"
```

実際は `KH-008`（3桁ゼロ埋め）。なので**テスト側**を直します。

```swift
#expect(normalizeProductID("kh8") == "KH-008")   // ← 直した
```

### 例2: 実装の「検証」が抜けていた（バグ）

在庫を減らす前に、足りるかを確かめない実装が紛れ込んだとします。

```swift
// バグのある実装: 検証をせずに減らしてしまう
func decrementStockBuggy(_ cart: [CartLine], stock: inout [Product]) throws {
    for line in cart {
        guard let i = stock.firstIndex(where: { $0.id == line.id }),
              let current = stock[i].stock else { continue }
        stock[i].stock = current - line.qty   // ← 在庫がマイナスになり得る！
    }
}
```

テストを書くと、**期待どおりエラーが投げられず**失敗します。

```swift
@Test("在庫不足ならエラー（失敗例）")
func shortageShouldThrow() {
    #expect(throws: StockError.self) {
        var stock = [Product(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02",
                             priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique)]
        let cart = [CartLine(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02",
                             unitPriceJpy: 800, unitPriceSats: 1200, qty: 2, isAdhoc: false)]
        try decrementStockBuggy(cart, stock: &stock)
    }
}
```

**出る失敗**:

```
✘ Test "在庫不足ならエラー" recorded an issue:
    Expected an error of type StockError to be thrown, but no error was thrown
```

**直す**: 「検証してから減算」の順にします（正しい `decrementStock` のように、**先に全行をチェックして、足りなければ例外を投げる**）。
これで在庫がマイナスにならず、テストが通り、実際のレジでも**在庫超過の販売を防げます**。

> ポイント: 失敗したときは「**テストが間違っている**（期待を直す）」のか「**実装が間違っている**（コードを直す）」のかを、期待値と実際の値を見て見分けます。

## 59-6. XCTest（こちらも広く使われている）

**Swift Testing** が新しい方式で、**XCTest** は以前からの標準です。どちらも1つのプロジェクトで使えます。

| | Swift Testing | XCTest |
| --- | --- | --- |
| import | `import Testing` | `import XCTest` |
| テスト1件 | `@Test func foo()` | `func testFoo()`（`test`で始まる） |
| まとまり | `@Suite struct ...` | `final class ...: XCTestCase` |
| 検証 | `#expect(a == b)` | `XCTAssertEqual(a, b)` |
| エラー検証 | `#expect(throws:)` | `XCTAssertThrowsError` |

```swift
import XCTest

final class TotalsXCTests: XCTestCase {
    func testCashTotal() {
        let cart = [CartLine(id: "ST-001", typeId: "sticker", name: "ステッカー まる",
                             unitPriceJpy: 300, unitPriceSats: 500, qty: 2, isAdhoc: false)]
        XCTAssertEqual(totals(cart).cash, 600)
    }

    func testNormalizeFullWidth() {
        XCTAssertEqual(normalizeProductID("ｋｈ８"), "KH-008")
    }

    func testShortageThrows() {
        var stock = [Product(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02",
                             priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique)]
        let cart = [CartLine(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02",
                             unitPriceJpy: 800, unitPriceSats: 1200, qty: 2, isAdhoc: false)]
        XCTAssertThrowsError(try decrementStock(cart, stock: &stock))
    }
}
```

## Xcodeでテストを実行する

1. **テストターゲット**を用意する（`File > New > Target...` の **Unit Testing Bundle**）。テストはアプリ本体とは別のターゲットに置く
2. テストから対象のコードを読むには、ファイル先頭で `@testable import アプリ名` する（同じファイルにまとめている場合は不要）
3. **⌘U**（Product > Test）でテストを実行する
4. **左の Test Navigator**（`⌘6`）でテスト一覧が出る。各テストの左の ▷ で**1件だけ**実行できる
5. 失敗した行には**赤い印**が付く。右側のメッセージに「期待」と「実際」が出る
6. 直したら、また ⌘U

> **Swift Testing** は **Xcode 16 以降**で使えます。古いXcodeでは XCTest を使ってください。

**できた合図**:
- `59-1`〜`59-4` のテストが**すべて緑（合格）**になる
- `59-5` の「失敗例」は赤になり、直すと緑になる
- Test Navigator で、テストの件数と結果が一覧で見える

## まとめ

- テストは「**用意 → 実行 → 検証**」。検証は `#expect(...)`（Swift Testing）や `XCTAssertEqual(...)`（XCTest）
- **テストごとにデータを新しく作る**（毎回 `makeStock()` する）と、順番に左右されない
- 「期待どおりの**失敗**」も大切: `#expect(throws:)` で、エラーになるべき場面を確かめる
- 失敗したら、**テストの間違い**か**実装の間違い**かを、期待値と実際の値で見分けて直す
- Swift Testing は `import Testing` / `@Suite` / `@Test` / `#expect`。XCTest は `XCTestCase` / `test...` / `XCTAssert...`
- 実行は **⌘U**。Neo（macOS）でも同じ手順で回せる
