# 会計状態をまるごと保存する

元: `../siyou.md` A-3

会計の途中経過を**まるごと端末に保存**して、**再起動・強制終了・スリープからの復帰**のあとでも続きから戻れるようにする練習です（A-3）。

保存する物：

- カート（商品・数量・野良の明細を含む）
- 会計状態（`SaleState`）
- 支払方法（`cash` / `lightning` / `mixed`）
- 請求額（**現金の請求額**、**請求sats額**、**現金分**）
- **sats入金の確認済み**かどうか（**確認時刻**を含む）

入れ子になった `Codable` の struct を作り、`UserDefaults` に **JSON** で保存 → 復元します。
保存は**更新のたび**。完了・取消のときは消します。

> 純ロジック（保存の形と復元）は**ブック（Book）**で試せます。
> 実際に復帰の動きを確かめるのは **アプリ（App）** です（`01_初心者メモ.md`）。

---

## 前提データ

```swift
import Foundation

// ── 会計の状態（A-4 の状態マシン）──
enum SaleState: String, Codable {
    case idle             // 待機中
    case scanning         // スキャン中
    case choosingPayment  // 支払方法選択
    case cashInput        // 現金入力中
    case satsWaiting      // sats待ち
    case mixedCashInput   // 併用現金入力中（sats確認済み）
    case done             // 完了
}

// ── カートの1行（登録商品と野良を同じ形で持つ）──
struct CartLine: Codable {
    let id: String          // 登録商品は商品ID、野良は "ADHOC-1" など
    let typeId: String?     // 登録商品は種類ID、野良は nil
    let name: String        // カートに入れた時点の商品名
    let unitPriceJpy: Int   // カートに入れた時点の円単価
    let unitPriceSats: Int? // カートに入れた時点のsats単価
    var qty: Int
    let isAdhoc: Bool       // 野良かどうか
}

// ── 請求額（A-6-1）──
struct RequestAmounts: Codable {
    var cashRequestJpy: Int   // 現金の請求額（全行の円合計 or 現金分）
    var requestSats: Int      // 請求sats額（sats単価のある行）
    var cashPartJpy: Int      // 現金分（sats単価のない行の円合計）
}

// ── sats入金の確認済み（確認時刻を含む）──
struct SatsConfirmation: Codable {
    var confirmedAt: String   // 済ボタン承認時刻（ISO 8601）
}

// ── 保存する会計状態のまるごと ──
struct SaleSession: Codable {
    var state: SaleState
    var cart: [CartLine]
    var paymentMethod: String?      // cash / lightning / mixed（未選択なら nil）
    var amounts: RequestAmounts
    var satsConfirmation: SatsConfirmation?   // 未確認なら nil
}
```

## 保存・復元する入れ物（UserDefaults）

```swift
enum SaleSessionStore {
    static let key = "saleSession"

    /// 保存する（更新のたびに呼ぶ）
    static func save(_ session: SaleSession) {
        if let data = try? JSONEncoder().encode(session) {
            UserDefaults.standard.set(data, forKey: key)
        }
    }

    /// 復元する（起動時に呼ぶ）。保存が無ければ nil
    static func load() -> SaleSession? {
        guard let data = UserDefaults.standard.data(forKey: key) else { return nil }
        return try? JSONDecoder().decode(SaleSession.self, from: data)
    }

    /// 消す（完了・取消のときに呼ぶ）
    static func clear() {
        UserDefaults.standard.removeObject(forKey: key)
    }
}
```

- `Codable` … 「JSONに変換してよい」という印（`03_レッスン.md` のレッスン8）。
- 入れ子の struct もそれぞれ `Codable` にすると、**まるごと1つ**で保存できる。
- `try?` … 失敗するかもしれない処理（失敗したら nil）。

## 保存してみる

`mixedCashInput`（sats確認済みの併用現金入力中）の状態を作って保存します。これが一番復元が難しい場面です。

```swift
let cart: [CartLine] = [
    CartLine(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02", unitPriceJpy: 800, unitPriceSats: 1200, qty: 1, isAdhoc: false),
    CartLine(id: "ST-003", typeId: "sticker", name: "ステッカー しかく", unitPriceJpy: 300, unitPriceSats: nil, qty: 1, isAdhoc: false),
]

let session = SaleSession(
    state: .mixedCashInput,                       // 併用現金入力中（sats確認済み）
    cart: cart,
    paymentMethod: "mixed",                       // 併用
    amounts: RequestAmounts(cashRequestJpy: 300,  // 現金の請求額＝現金分
                            requestSats: 1200,     // 請求sats額
                            cashPartJpy: 300),     // 現金分
    satsConfirmation: SatsConfirmation(confirmedAt: "2026-10-13T11:05:00+09:00"))

SaleSessionStore.save(session)
print("保存した")
```

**できた合図**: `保存した`

## 復元してみる

アプリを閉じた／強制終了した／スリープから戻った、という場面をまねて、保存した物を読み直します。

```swift
if let restored = SaleSessionStore.load() {
    print("状態:", restored.state.rawValue)
    print("支払方法:", restored.paymentMethod ?? "未選択")
    print("現金の請求額:", restored.amounts.cashRequestJpy)
    print("請求sats額:", restored.amounts.requestSats)
    print("現金分:", restored.amounts.cashPartJpy)
    print("sats確認:", restored.satsConfirmation?.confirmedAt ?? "未確認")
    print("カート:")
    for line in restored.cart {
        let kind = line.isAdhoc ? "（野良）" : ""
        print("  \(line.name)\(kind) ×\(line.qty)")
    }
} else {
    print("保存は無かった")
}
```

**できた合図**:
```
状態: mixedCashInput
支払方法: mixed
現金の請求額: 300
請求sats額: 1200
現金分: 300
sats確認: 2026-10-13T11:05:00+09:00
カート:
  キーホルダー 02 ×1
  ステッカー しかく ×1
```

- `rawValue` … `enum` の中の文字列表現（`.mixedCashInput` → `"mixedCashInput"`）。
- `satsConfirmation?` … 未確認なら `nil` なので、`?.` と `??` で安全に出す。
- 「sats待ち」「sats確認済みの併用現金入力中」まで戻せるのがミソ。**確認時刻**も一緒に戻る。

---

## 消す（完了・取消のとき）

会計が終わったら、古い状態は不要です。消しておくと、次回起動で**待機中**から始まります。

```swift
SaleSessionStore.clear()
print(SaleSessionStore.load() == nil)   // true（消えている）
```

**できた合図**: `true`

---

## ポイント

- 保存するのは **カート・状態・支払方法・請求額・sats確認（時刻込み）**。野良の明細も含む。
- **入れ子の `Codable`** にして、`SaleSession` を**まるごと1つ**で保存する。
- `UserDefaults` に JSON（`Data`）で入れる。キーは1つ（例: `"saleSession"`）。
- **更新のたび**に `save`。起動時に `load`。完了・取消で `clear`。
- 復元後、カメラ読み取りが再開できることを確かめる。再開できないときは再起動を促す表示を出す（A-3）。
- スリープ復帰（Neoは蓋の開閉）でも、`load` で直前の状態に戻す。
