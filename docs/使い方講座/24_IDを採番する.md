## 1. ID形式「接頭辞-番号」

商品IDは **`<接頭辞>-<番号>`** という形式です。

- 接頭辞（`id_prefix`）は**種類ごと**に決まります（例：ステッカー `ST`、キーホルダー `KH`）
- 番号は**種類ごとに連番**で採番します
- 番号は**種類定義の `id_digits` 桁でゼロ埋め**します（例：3桁 → `001`, `008`, `020`）
- 接頭辞は種類間で**重複させない**（siyou A-1）

今回のサンプルに合わせると：

| 種類 | 接頭辞・桁数 | ID例 |
| --- | --- | --- |
| ステッカー | `ST`・3桁 | `ST-001`, `ST-002`, `ST-003` |
| キーホルダー | `KH`・3桁 | `KH-001`〜`KH-020` |

---

## 2. 「既存の最大番号の次から」連番

採番の基本ルール（siyou A-18）：

- **既存の最大番号の次から連番**で振る
- **欠番は再利用しない**（過去に存在した番号が消えても、再度その番号は使わない）
- **番号が桁数を超える場合はエラー**（例：3桁で `999` を超える → エラー）
- 撮影日時などの**昇順で振る考え方**（新しく作るものには後の番号を振る）

つまり「今ある中で一番大きな番号 + 1」を次の番号にします。

## 3. ブックで採番ロジックを試す

まず、ある接頭辞の中から最大番号を求める関数を作ってみましょう。

```swift
// 指定した接頭辞の既存商品から、最大番号を求める
func maxNumber(for prefix: String, in productsList: [Product]) -> Int {
    var maxNum = 0
    for p in productsList {
        // IDが prefix- で始まるかチェック
        if p.id.hasPrefix(prefix + "-") {
            let parts = p.id.split(separator: "-", omittingEmptySubsequences: true)
            if parts.count == 2 {
                // 番号部分をIntに変換
                if let num = Int(String(parts[1])) {
                    if num > maxNum {
                        maxNum = num
                    }
                }
            }
        }
    }
    return maxNum
}

print(maxNumber(for: "ST", in: products))  // 3（ST-003が最大）
print(maxNumber(for: "KH", in: products))  // 20（KH-020が最大）
print(maxNumber(for: "XX", in: products))  // 0（該当なし）
```

- `.hasPrefix(prefix + "-")` で対象の接頭辞だけに絞り込む
- `split(separator: "-")` で「接頭辞」と「番号」に分割
- `Int(String(...))` で番号部分を整数に変換

**できた合図**: `3`, `20`, `0` が出る。

## 4. 次のIDを生成する

次に「最大番号+1」の新しいIDを生成します。番号は桁数に応じてゼロ埋めします。

```swift
// 次のIDを生成する（接頭辞・桁数・既存リストから）
func nextID(prefix: String, digits: Int, in productsList: [Product]) -> String? {
    let maxNum = maxNumber(for: prefix, in: productsList)
    let nextNum = maxNum + 1
    
    // 番号が桁数を超える場合はエラー（nilを返す）
    let maxByDigits = Int(pow(10.0, Double(digits))) - 1  // 例: digits=3 → 999
    if nextNum > maxByDigits {
        return nil  // 桁数オーバー
    }
    
    // ゼロ埋めして "PREFIX-XXX" 形式で返す
    let format = "%0\(digits)d"
    return prefix + "-" + String(format: format, nextNum)
}

print(nextID(prefix: "ST", digits: 3, in: products))  // ST-004
print(nextID(prefix: "KH", digits: 3, in: products))  // KH-021
```

- `Int(pow(10.0, Double(digits))) - 1` でその桁数で表せる最大値を求めます（3桁なら999）
- `nextNum > maxByDigits` の場合は `nil` を返す（「番号が桁数を超える場合はエラー」の表現）
- `String(format: "%03d", ...)` の形でゼロ埋めします

**できた合図**: `ST-004` と `KH-021` が出る。

---

## 5. 欠番は再利用しない（確認）

「欠番は再利用しない」の意味を確認してみましょう。

例えば `KH-005` を「消した」（リストから外した）としても、次に採番するときは**最大番号の次**、つまり `KH-021` を振るのが正解です。

```swift
// KH-005 を一時的に除外したリストを想定
let productsWithoutKH005 = products.filter { $0.id != "KH-005" }

// 最大番号を見てみる
print(maxNumber(for: "KH", in: productsWithoutKH005))  // 20（最大はまだKH-020）

// 次のID
print(nextID(prefix: "KH", digits: 3, in: productsWithoutKH005))  // KH-021（KH-005は再利用しない）
```

- `filter` で条件に合うものだけ残します（`$0` は配列の1個ずつ）
- 欠番があっても**最大番号+1**なので再利用しません

**できた合図**: 最大番号は20のままで、次は `KH-021` になる。

## 6. 桁数オーバーのケース

桁数を1桁（`id_digits: 1`）にした場合を試してみましょう。

```swift
// 1桁（最大9）までしか表せない想定
let nextForSingleDigit = nextID(prefix: "X", digits: 1, in: [Product(id: "X-9", name: "", priceJpy: 0, priceSats: nil, stock: 0)])
print(nextForSingleDigit ?? "エラー: 桁数を超えています")  // エラー

// X-9の次は10だが、1桁では表せない → nil
```

**できた合図**: 「エラー: 桁数を超えています」と出る。

## 7. 実際の種類定義を使って採番する

最後に、冒頭の `productTypes` を使って実際の流れをシミュレートしてみましょう。

```swift
// ステッカー用に次のIDを採番
if let stickerType = productTypes.first(where: { $0.typeId == "sticker" }) {
    if let newID = nextID(prefix: stickerType.idPrefix, digits: stickerType.idDigits, in: products) {
        print("新しいステッカーID:", newID)  // ST-004
    }
}

// キーホルダー用に次のIDを採番
if let khType = productTypes.first(where: { $0.typeId == "keyholder" }) {
    if let newID = nextID(prefix: khType.idPrefix, digits: khType.idDigits, in: products) {
        print("新しいキーホルダーID:", newID)  // KH-021
    }
}
```

- `.first(where:)` で条件に合う最初の要素を探します
- 種類定義の `idPrefix` と `idDigits` をそのまま使って採番します

**できた合図**: `新しいステッカーID: ST-004` と `新しいキーホルダーID: KH-021` が出る。

## まとめ

- ID形式：`<接頭辞>-<番号>`（接頭辞は種類ごと、種類間で重複させない）
- 採番：**既存の最大番号の次から連番**。**欠番は再利用しない**
- ゼロ埋め：種類定義の `id_digits` 桁でゼロ埋め
- エラー：**番号が桁数を超える場合はエラー**
- 考え方：撮影日時などの**昇順で振る**（新規には後の番号）

**補足（データ作成ツール A-18）**：アプリの取り込み自体はA-18の有無に関わらず同じ検証・同じルールで行います。ここで学んだ「既存最大+1」「欠番非再利用」「桁数超過エラー」がその基礎になります。
