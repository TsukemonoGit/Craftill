# 追加レッスン: 野良商品を追加する【小】

元: `../siyou.md` A-1
`2_練習メニュー.md` の「10. 野良商品を追加する」。

**野良商品**＝商品マスタに**登録していない**品（他者作品の販売代行など）。営業中にカートから追加する（A-1）。

| 入力項目 | 必須 | 内容 |
| --- | --- | --- |
| 円価格 | **必須** | 1以上の整数。上限なし |
| sats価格 | 任意 | 未入力なら「sats払いでも現金で受け取り」 |
| 品名 | 任意 | 未入力なら既定名「**野良**」 |
| 数量 | 必須 | 既定1。カート上で＋／－ |

- **在庫管理の対象外**（`stock_movements` に記録しない）。
- カート行に「**野良**」の表示を付ける。
- sats価格が未入力なら、確認表示とカート行に「**sats単価なし：sats払いでも現金で受け取り**」を併記する。

> ここは**純ロジック**なので **ブック（Book）** で書ける。画面（SwiftUI）は **アプリ（App）** で作る（`1_初心者メモ.md`）。
> このファイルだけで完結。冒頭のコードをそのままPlaygroundsに貼り、その下に続けて書けば動く。

## 入力を受け取る形

任意の項目は `?`（nil かも）で表す。未入力なら既定値を当てる。

```swift
struct AdhocInput {
    var priceJpy: Int?     // 必須（nil はエラー）
    var priceSats: Int?    // 任意
    var name: String       // 任意（空なら「野良」）
    var qty: Int?          // 任意（既定1）
}
```

## 野良のカート行を作る

```swift
enum AdhocResult {
    case ok(CartLine)
    case error(String)
}

func makeAdhoc(_ input: AdhocInput, id: String) -> AdhocResult {
    // 円価格は必須・1以上
    guard let jpy = input.priceJpy, jpy >= 1 else {
        return .error("円価格は1以上で入力してください")
    }

    // 品名は空なら既定名「野良」
    let trimmed = input.name.trimmingCharacters(in: .whitespaces)
    let name = trimmed.isEmpty ? "野良" : trimmed

    // 数量は未入力なら1
    let qty = input.qty ?? 1

    let line = CartLine(id: id, name: name, priceJpy: jpy,
                        priceSats: input.priceSats, qty: qty, isAdhoc: true)
    return .ok(line)
}
```
- `guard let ... else { return .error(...) }` … 必須チェックは**先に抜ける**（`1_初心者メモ.md`）
- `input.qty ?? 1` … 「nil なら 1」の意味（nil 合体演算子）
- 野良は在庫を持たないので、`stock` や `StockMode` は使わない

## 表示する

確認表示とカート行の2つを作る。sats単価がないときは、両方に注意書きを付ける。

```swift
/// 追加前の確認表示（金額を大きく見せる想定）
func confirmText(_ line: CartLine) -> String {
    var t = "金額 ¥\(line.priceJpy)　品名 \(line.name)　数量 \(line.qty)"
    if line.priceSats == nil {
        t += "\nsats単価なし：sats払いでも現金で受け取り"
    }
    return t
}

/// カート行の表示（野良は「野良」を付ける）
func rowText(_ line: CartLine) -> String {
    var t = line.isAdhoc ? "野良 " : ""
    t += "\(line.name)  ¥\(line.priceJpy) ×\(line.qty)"
    if line.priceSats == nil {
        t += "  ―（現金）"     // A-3 のカート表示に合わせる
    }
    return t
}
```

## 試す

```swift
// 例1: 品名あり・sats価格なし
switch makeAdhoc(AdhocInput(priceJpy: 1200, priceSats: nil, name: "委託品A", qty: 1), id: "ADHOC-1") {
case .ok(let line):
    print(confirmText(line))
    print(rowText(line))
case .error(let e):
    print("エラー: \(e)")
}

// 例2: 品名なし（既定名「野良」）・sats価格あり
switch makeAdhoc(AdhocInput(priceJpy: 500, priceSats: 800, name: "", qty: nil), id: "ADHOC-2") {
case .ok(let line): print(rowText(line))
case .error(let e): print("エラー: \(e)")
}

// 例3: 円価格が未入力 → エラー
switch makeAdhoc(AdhocInput(priceJpy: nil, priceSats: nil, name: "試作", qty: 1), id: "ADHOC-3") {
case .ok(let line): print(rowText(line))
case .error(let e): print("エラー: \(e)")
}
```

## ポイント

- 円価格だけが**必須**。`guard let` で先にチェック
- 未入力を `??`（nil 合体）で既定値にする（品名 →「野良」、数量 → 1）
- 野良は**在庫管理の対象外**。`stock_movements` に記録しない
- sats価格がないときは「**sats単価なし：sats払いでも現金で受け取り**」を**確認表示とカート行の両方**に出す
- カート行には「野良」を付ける（登録商品と区別する）
