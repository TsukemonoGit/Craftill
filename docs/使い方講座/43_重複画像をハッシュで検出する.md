# 重複画像をハッシュで検出する

元: `../siyou.md` A-18

同じ写真を**二度取り込んで二重に採番しない**ようにする練習。
画像の中身から「ハッシュ」という短い指紋を作り、**同じ指紋なら同じ写真**とみなす。
`import CryptoKit` の `SHA256` を使う。CryptoKit は iPadの**ブック（Book）**でも使える。

> 取り込み（採番）は Mac上の**コマンドラインツール／スクリプト**の役目（`../siyou.md` A-18）。
> ここではファイルを読まず、中身の `Data` を手で用意して仕組みを確かめる。

---

## ハッシュって？

- 中身を**決まった長さの文字列**に変換する計算。SHA256なら64文字の16進数。
- **同じ中身 → 必ず同じハッシュ**。1バイトでも違うと**別のハッシュ**。
- 指紋なので、ハッシュを見比べるだけで「同じ写真か」を判定できる。写真そのものを全部比べなくてよい。

---

## 前提データ

```swift
import Foundation
import CryptoKit

/// 取り込み対象の写真1枚（本来はファイル。ここでは中身の Data を持つ）
struct ImportedPhoto {
    let sourceName: String   // 取り込み元のファイル名
    let data: Data           // 画像の中身（ここでは文字列から作る）
}

/// 中身の Data から SHA256 の 16進文字列を作る
func sha256Hex(_ data: Data) -> String {
    let digest = SHA256.hash(data: data)                       // 計算する
    return digest.map { String(format: "%02x", $0) }.joined()  // 16進2桁ずつ連結
}
```

- `SHA256.hash(data:)` … 中身からダイジェスト（ハッシュの本体）を作る。
- `digest.map { String(format: "%02x", $0) }` … 各バイトを `00`〜`ff` の文字にする。
- `.joined()` … つなげて1本の文字列にする。

## すでに取り込んだ写真（台帳）

`../siyou.md` A-18 の台帳 `id_map.csv` は `source_hash`（内容のハッシュ）を持つ。
ここでは、そのハッシュを `Set` で持っておく。

```swift
// 既に取り込み済みの写真（台帳のイメージ）
let ledger: [ImportedPhoto] = [
    ImportedPhoto(sourceName: "IMG_0001.HEIC", data: Data("写真Aの中身".utf8)),
    ImportedPhoto(sourceName: "IMG_0002.HEIC", data: Data("写真Bの中身".utf8)),
]

// 取り込み済みハッシュの集合（Set = 重複のない集合。01_初心者メモ.md 参照）
var knownHashes: Set<String> = Set(ledger.map { sha256Hex($0.data) })
```

---

## 再取り込みで重複を除く

`inbox/` に置いた写真を読み、**台帳と照合**して重複を外す。
同じ取り込みの中でも、同じ中身が2回出たら2枚目はスキップする。

```swift
// 今回の inbox/ の中身
let inbox: [ImportedPhoto] = [
    ImportedPhoto(sourceName: "R001.HEIC", data: Data("写真Aの中身".utf8)),  // 台帳と重複
    ImportedPhoto(sourceName: "R002.HEIC", data: Data("写真Cの中身".utf8)),  // 新規
    ImportedPhoto(sourceName: "R003.HEIC", data: Data("写真Bの中身".utf8)),  // 台帳と重複
    ImportedPhoto(sourceName: "R004.HEIC", data: Data("写真Cの中身".utf8)),  // 今回の2枚目（重複）
]

var toNumber: [ImportedPhoto] = []   // 採番する写真
var skipped: [String] = []           // スキップしたファイル名

for photo in inbox {
    let h = sha256Hex(photo.data)
    if knownHashes.contains(h) {
        skipped.append(photo.sourceName)     // 既にある → 採番しない
    } else {
        toNumber.append(photo)               // 新しい → 採番する
        knownHashes.insert(h)                // 覚えておく（今回の重複も防ぐ）
    }
}
```

**ポイント**: `knownHashes.insert(h)` を**新規のときも**行う。
これを忘れると `R004`（今回の2枚目の「写真C」）を重複と判定できない。

## 表示して確認する

```swift
// 既存IDの最大番号の次から採番する（ここでは KH-020 まで採番済みとする）
var nextNumber = 21

print("新規採番: \(toNumber.count) 件")
for photo in toNumber {
    let id = String(format: "KH-%03d", nextNumber)
    nextNumber += 1
    print("  \(photo.sourceName) → \(id)")
}

print("スキップ（重複）: \(skipped.count) 件")
for name in skipped {
    print("  \(name)")
}
```

**できた合図**:
```
新規採番: 1 件
  R002.HEIC → KH-021
スキップ（重複）: 3 件
  R001.HEIC
  R003.HEIC
  R004.HEIC
```
「写真C」だけが `KH-021` になり、A・Bの再取り込みと、Cの2枚目はスキップされる。

## 実際のファイルを読む場合（アプリ／Macのツール）

ファイルを読むときは、中身を `Data` にしてから同じ関数に渡すだけ。

```swift
// アプリ、または Mac のコマンドラインツールでの例
func hashOfFile(at url: URL) -> String? {
    guard let data = try? Data(contentsOf: url) else { return nil }
    return sha256Hex(data)   // さっきと同じ関数
}

#if os(macOS)
// Mac ではフォルダを直接読みやすい
let folder = URL(fileURLWithPath: "originals")
print("originals: \(folder.path)")
#else
// iPad/iOS は自分のアプリのフォルダ（サンドボックス）の中だけ読める
let docs = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
print("書類フォルダ: \(docs.path)")
#endif
```

## 覚えておくこと

- 同じ中身 → 同じハッシュ。これで**再取り込みの重複採番**を防ぐ（`../siyou.md` A-18）。
- 新しい写真を採番したら、そのハッシュも集合へ入れる（同じ取り込み内の重複対策）。
- ファイル全体のバイト列をハッシュにすると、**同じ絵でもメタデータが違うと別物**になる。
  絵そのものが同じかを見たいときは、画像をデコードした画素データをハッシュにする方法もある（発展）。
- 結果は「新規件数」「スキップ件数・ファイル名」で表示する（`../siyou.md` A-18 の取り込み結果）。
