# QRの連続読み取りを防ぐ【小】

元: `../siyou.md` A-2

カメラでQRを読み取ると、同じQRが**連続で何度も**読めてしまいます。そのまま追加すると、**1回の読み取りでカートに何個も**入ってしまいます。

そこで、**直前に読み取った文字列と時刻**を覚えておき、**同じ文字列なら1〜2秒は無視する**（クールダウン）関数を作ります（A-2）。

> クールダウンの判定は**純ロジック**なので **ブック（Book）** で試せます。
> カメラでの読み取り本体（AVFoundation / Vision）は **アプリ（App）** の役目です（`01_初心者メモ.md`）。

---

## 前提データ

```swift
import Foundation

// ── 商品（products 相当）──
struct Product {
    let id: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?
    var stock: Int?
}

// 登録商品（../開発/6_データベース.md のサンプル。一部抜粋）
let products: [Product] = [
    Product(id: "ST-001", name: "ステッカー まる",   priceJpy: 300, priceSats: 500,  stock: 10),
    Product(id: "ST-003", name: "ステッカー しかく", priceJpy: 300, priceSats: nil,  stock: 10),
    Product(id: "KH-001", name: "キーホルダー 01",   priceJpy: 800, priceSats: 1200, stock: 1),
    Product(id: "KH-008", name: "キーホルダー 08",   priceJpy: 800, priceSats: 1200, stock: 1),
]

/// 登録商品をIDで探す。無ければ nil。
func findProduct(_ id: String) -> Product? {
    products.first { $0.id == id }
}
```

## クールダウンの構造体

直前に読んだ**文字列**と**時刻**を持ち、同じ文字列が**時間内**に来たら無視します。

```swift
/// 同じQRの連続読み取りを無視するためのクールダウン。
struct QRCooldown {
    private var lastText: String?     // 直前に読み取った文字列
    private var lastTime: Date?       // そのときの時刻
    let interval: TimeInterval        // クールダウン（秒）。1〜2秒

    init(interval: TimeInterval = 1.5) {
        self.interval = interval
    }

    /// 読み取り値を1つ受け取る。
    /// - Returns: 処理してよければ true、クールダウン中（同じ文字列で時間内）なら false。
    mutating func accept(_ text: String, now: Date = Date()) -> Bool {
        if let last = lastText, last == text,
           let t = lastTime, now.timeIntervalSince(t) < interval {
            return false   // 直前と同じ & 時間内 → 無視する
        }
        // 違う文字列、または時間が過ぎた → 受け付けて記録を更新
        lastText = text
        lastTime = now
        return true
    }
}
```

- `private var` … 外から直接いじらせない（`accept` 経由だけ）。
- `mutating func` … 構造体自身の `lastText` / `lastTime` を書き換える関数。呼ぶ側は `var` で持つ。
- `now.timeIntervalSince(t)` … 直前に読んだ時刻からの**経過秒**。`interval` 未満なら無視。
- 同じ文字列でも**時間が過ぎれば通す**。違う文字列は**すぐ通す**（別の商品を続けて読める）。

## 試す

`Date` を手で渡せるようにしてあるので、待たずに動きを確かめられます。

```swift
var cooldown = QRCooldown(interval: 1.5)
let t0 = Date(timeIntervalSince1970: 0)

print(cooldown.accept("KH-008", now: t0))                          // true  （1回目）
print(cooldown.accept("KH-008", now: t0.addingTimeInterval(0.5)))  // false （0.5秒後：同じ → 無視）
print(cooldown.accept("KH-008", now: t0.addingTimeInterval(1.6)))  // true  （1.6秒後：時間切れ → OK）
print(cooldown.accept("KH-001", now: t0.addingTimeInterval(1.7)))  // true  （別のID → すぐOK）
```

**できた合図**:
```
true
false
true
true
```

- `addingTimeInterval(0.5)` … 0.5秒後の時刻を作る。
- 2番目だけ `false`（同じQRを0.5秒後に読んだ）。これが**重複追加の防止**。

## カートへの追加と組み合わせる

読み取り値を受け取って、クールダウンを通ってからカートへ入れます。

```swift
var cart: [String] = []            // 商品IDを並べる（練習用の簡単なカート）
var scanCooldown = QRCooldown(interval: 1.5)

enum ScanResult {
    case added(String)      // 追加した商品名
    case cooling(String)    // クールダウン中で無視した
    case unknown(String)    // 登録にないQR
}

func handleScan(_ text: String, now: Date) -> ScanResult {
    // ① まずクールダウンで重複を防ぐ
    guard scanCooldown.accept(text, now: now) else {
        return .cooling(text)
    }
    // ② 登録商品か確認する（登録にないIDは入れない。A-2）
    guard let p = findProduct(text) else {
        return .unknown(text)
    }
    cart.append(p.id)
    return .added(p.name)
}

func show(_ r: ScanResult) -> String {
    switch r {
    case .added(let name):  return "追加: \(name)"
    case .cooling(let text): return "クールダウン中で無視: \(text)"
    case .unknown(let text): return "登録にないQR: \(text)"
    }
}

let s = Date(timeIntervalSince1970: 100)
print(show(handleScan("KH-008", now: s)))                            // 追加: キーホルダー 08
print(show(handleScan("KH-008", now: s.addingTimeInterval(0.3))))    // クールダウン中で無視: KH-008
print(show(handleScan("XX-999", now: s.addingTimeInterval(0.4))))    // 登録にないQR: XX-999
print("カート:", cart)                                                // ["KH-008"]
```

**できた合図**:
```
追加: キーホルダー 08
クールダウン中で無視: KH-008
登録にないQR: XX-999
カート: ["KH-008"]
```

- `guard ... else { return ... }` … ダメなら先に抜ける（`01_初心者メモ.md` の `guard`）。
- 同じQRを0.3秒後に読んでも、カートには**1つ**しか入らない。

---

## ポイント

- 直前に読んだ**文字列**と**時刻**を持ち、**同じ文字列**なら **1〜2秒**は無視する（A-2）。
- **違う文字列**はすぐ通す。**時間が過ぎた**同じ文字列も通す。
- クールダウンは「重複追加の防止」。登録にないIDは別の判定で弾く（ここでは `findProduct`）。
- 判定は `Date` を引数で渡せるようにすると、**待たずにテスト**できる。
