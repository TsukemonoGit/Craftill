# 使い方講座の入口

**これは「勉強・練習・準備用」のフォルダ。** アプリの仕様（何を作るか）は隣の `../開発/` にある。
ここは「Swift初めての人が、Macが来る前に準備し、来たら作り始める」ための講座。

## このフォルダのファイル
1. `01_初心者メモ.md` … Swiftの言葉（struct, enum, ? など）が分からない時に見る
2. `02_練習メニュー.md` … **やることのチェックリスト**（上から1つずつ）。追加レッスン7〜60の一覧もここ
3. `03_レッスン.md` … 各メニューの**やり方とコード**。2で詰まったら
4. `04_Svelteで理解するSwift.md` … Svelteが分かる人向け。対応表と例。**随時参照**
5. `05_Xcodeでプロジェクト作成.md` … Macが来たら最初に見る。マルチプラットフォームで作成
6. `06_QRを試す.md` … QR生成の練習。iPadでもMacでも動くコード | 随時
7. `base/` … **型の正と標準ロジック**。`siyou.md` から作った型と関数がここにある
8〜60. **追加レッスン**（下の「追加レッスン」参照）… `03_レッスン.md` のあとで。

> 追加レッスン（7〜60）の**一覧とチェック欄は `02_練習メニュー.md` にまとめてある**。
> **やるかやらないかは自由**。全部やらなくてよい。1つ1つが独立している。

## 追加レッスンの考え方
- **部品をつくる（7〜22）**: レジ・在庫まわりの機能を1つずつ作る
- **さらに細かい部品（23〜48）**: CSV・QR・画像・SQLite など、細かい処理を1つずつ
- **仕上げ（49〜60）**: エラー処理・プロトコル・テスト・統合演習など、独力で組むための回

どれも**それぞれ独立**。前提データは各ファイルの冒頭に書いてあるので、どのレッスンからでも始められる。
各レッスンの先頭には、対応する `../siyou.md` の節番号（A-1 など）を書いてある。

> **型と中核ロジックは `base/` に 1 か所だけあります。**
> - `base/Types.swift` … `Product` / `CartLine` / `Sale` / `StockMovement` などの型の正
> - `base/3_標準ロジック.md` … 合計・在庫検証・減算・集計・送信の関数の正
>
> レッスンはここから使います。型が変わると全部のレッスン間コピペが壊れるため、**手で書き直さない**でください。

## 使い方
- 新しい言葉が出たら `01_初心者メモ.md`
- 次に何をするかは `02_練習メニュー.md` の未チェック
- その項目のコードは `03_レッスン.md`
- 分からない言葉は都度ググってOK（この段階では覚えなくてよい）

## 大事なコツ
- **まとめてやらない。1つずつ。**
- **コピペより自分で打つ。** 値を少し変えて試すと覚える
- エラーが出たら `01_初心者メモ.md` の「つまずき」を見る

`../開発/04_最小構成やること.md` の「1. 土台」から。練習で作ったロジックはそのまま持ち込める。
