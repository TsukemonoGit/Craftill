# 32. 属性ラベルを取り出す

元: `../siyou.md` A-1（属性）

**ゴール**: 種類定義の `attrLabel1〜3`（**左詰め**）と商品の `attr1〜3` を対応させ、
商品一覧で「**色:赤 模様:○**」のように表示する。
ラベルがない属性に値がある場合はエラーにする。

> 純ロジックの練習。**ブック（Book）**で作る。

## 前提データ（このまま貼れば動く）

```swift
import Foundation

    case counted   // 数量管理型（ステッカー）
    case unique    // 一点物型（キーホルダー）
    case none      // 在庫管理なし型（今回は商品なし）

// ── 種類の定義（product_types 相当）──────
struct ProductType {
    let typeId: String       // 例: "sticker"
    let name: String         // 例: "ステッカー"
    let idPrefix: String     // 例: "ST"
    let idDigits: Int        // 例: 3

    let attrLabel1: String?  // 例: "色"
    let attrLabel2: String?  // 例: "模様"
    let attrLabel3: String?  // 例: nil

// ── 商品（products 相当）────────────────
struct Product {
    let id: String
    let typeId: String
    let name: String

// ── 種類定義（`../開発/6_データベース.md` より）
let productTypes: [ProductType] = [

let products: [Product] = [

    Product(id: "ST-002", typeId: "sticker", name: "ステッカー さんかく", priceJpy: 300, priceSats: 500,  stock: 10, attr1: "赤", attr2: "さんかく", attr3: nil, isPublic: true),
```

## 32-1. 2つの配列をそろえて見る

ラベルと値は**同じ順番**で対応している。

| | 1つ目 | 2つ目 | 3つ目 |
| --- | --- | --- | --- |
| 種類定義のラベル | `attrLabel1` | `attrLabel2` | `attrLabel3` |
| 商品の値 | `attr1` | `attr2` | `attr3` |

ラベルは**左から詰める**。`attrLabel1` があって `attrLabel2` が空、という並びだけが正しい（`attrLabel2` が空で `attrLabel3` に値があるのは取り込みエラー）。

---

## 32-2. ラベルと値をくっつける関数

表示は文字列、エラーは理由、と分けて返すために `enum` を使う。

```swift
enum AttrDisplay {
    case text(String)   // 例: "色:赤 模様:○"
    case error(String)  // ラベルのない属性に値がある
}

/// 商品の属性を「色:赤 模様:○」の形にする。
func attributeText(for product: Product) -> AttrDisplay {
    guard let pt = productTypes.first(where: { $0.typeId == product.typeId }) else {
        return .error("種類が未定義")
    }
    let labels = [pt.attrLabel1, pt.attrLabel2, pt.attrLabel3]
    let values = [product.attr1, product.attr2, product.attr3]

    var parts: [String] = []
    for i in 0..<3 {
        switch (labels[i], values[i]) {
        case (.some(let label), .some(let value)):
            parts.append("\(label):\(value)")   // ラベルと値がそろっている
        case (.none, .some(let value)):
            return .error("ラベルのない属性に値「\(value)」があります")
        default:
            break                                // どちらも無ければ何も出さない
        }
    }
    return .text(parts.joined(separator: " "))
}
```

- `for i in 0..<3` … 0,1,2 の3回まわす（3つ分の属性）
- `(.some(let label), .some(let value))` … 両方に入っていれば取り出す（`01_初心者メモ.md` のオプショナル）
- `(.none, .some(let value))` … **ラベルが無いのに値がある** → エラー
- `.joined(separator: " ")` … 配列を空白でつないで1本の文字列にする

## 32-3. 商品一覧のように出してみる

```swift
for p in products {
    switch attributeText(for: p) {
    case .text(let s):
        print("\(p.id)  \(s)")
    case .error(let e):
        print("\(p.id)  エラー: \(e)")
    }
}
```

**できた合図**（抜粋）:
- `ST-001  色:黄 模様:まる`
- `ST-003  色:青 模様:しかく`
- `KH-001  色:赤 模様:○`
- `KH-008  色:緑 模様:☆`

## 32-4. わざと壊した例（エラーの確認）

種類「ステッカー」はラベルが「色・模様」の2つだけ。3つ目に値を入れるとエラーになる。

```swift
// わざと attr3 に値を持たせた商品
let bad = Product(id: "ST-099", typeId: "sticker", name: "こわれた例",
                  priceJpy: 300, priceSats: nil, stock: 1,
                  attr1: "赤", attr2: nil, attr3: "まる", isPublic: true)

switch attributeText(for: bad) {
case .text(let s):   print("OK: \(s)")
case .error(let e):  print("エラー: \(e)")   // ラベルがない attr3 に値がある
}
```

**できた合図**: `エラー: ラベルのない属性に値「まる」があります`

## ポイント
- 表示は**種類定義のラベル**と**商品の値**を同じ番号で対応させる
- ラベルは**左詰め**。1つ目が空で2つ目に値、という並びは作らない
- その番号のラベルが無いのに値がある場合はエラー（CSV取り込みの検証と同じ考え方）
- 値が無い属性は表示しない。画像が無い商品では、この文字表示が画像の代わりになる
