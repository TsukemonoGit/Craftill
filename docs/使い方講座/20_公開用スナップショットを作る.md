# 公開用スナップショットを作る

元: `../siyou.md` A-14（B への送信）
`../siyou.md` A-19-5（日時）、A-19-4（送信ログの採番）
受け入れテスト C-6 #86〜#92

B（公開Webアプリ）へ送る**スナップショット**を作ります。送るのは**1つのJSON**で、
A の在庫情報を B が表示するために使います（A-14）。

- 対象は **`is_public` の登録商品だけ**。野良商品は含めない
- 種類定義は、**公開対象の商品が属する種類だけ**
- 画像データ（バイナリ / Base64）は**含めない**。**`image_ref` も含めない**。
  画像の**有無だけ**を `has_image` で送る（A-14、P7）
- `stock` は在庫管理なし型（`none`）では**空**
- `Codable` な struct にして **JSON** にエンコード

**正は `base/2_型定義.md` の `Snapshot*` 型と、`base/3_標準ロジック.md` §8 の `makeSnapshot` にあります。**

## わざと間違う①: `attrs` の空を詰めて送る

**これが一番危ない間違い**です。

```swift NG
// わざと間違う版①：属性の値を compactMap して送る
struct SnapshotProduct: Codable {
    let attrs: [String]        // ★ 空を詰めてしまう
}

let attrs = [p.attr1, p.attr2, p.attr3].compactMap { $0 }
```

**`attrLabels` は「左から詰める」前提**（仮置き Q20、A-19-2）ですが、
**`attrs` を詰めて送ると位置がズレます**。

**具体的な例**（`sticker` の `attrLabels = ["色", "模様"]`）:

| 商品 | `attr1` | `attr2` | `attr3` | `compactMap` 後 | 壊れ方 |
| --- | --- | --- | --- | --- | --- |
| `ST-001` | 黄 | まる | nil | `["黄", "まる"]` | ✅ 位置が合う |
| `ST-009` | 黄 | **nil** | nil | **`["黄"]`** | ❌ **「模様」が `attrs[0]` に入る** |

B の画面は **`attrLabels[1]`（模様）に `attrs[1]` を当てる**ので、
`ST-009` では **「模様：黄」と表示**してしまいます（A-14）。

**正**は `base/2` の **`[String?]`**（`nil` を残す）。位置が保たれます。

```swift 断片
// base/Types.swift の正
struct SnapshotProduct: Codable, Equatable {
    let attrs: [String?]   // ★ 空を含めない。左から詰める（attrLabels と位置を揃える）
}

// base/3 §8 の makeSnapshot
attrs: [p.attr1, p.attr2, p.attr3],   // ★ compactMap しない
```

| | `[String]`（詰める） | **`[String?]`**（残す） |
| --- | --- | --- |
| `ST-009` の表示 | 「模様：黄」 ❌ | 「模様：―」 ✅ |
| JSON | `["黄"]` | `["黄", null]` |
| B 側の実装 | 属性が**1つ**と看出 | `attrLabels[i]` に `attrs[i]` を**そのまま当てる** |

> **`attrLabels` だけ `compactMap` するのは正しい**です。
> ラベルは「**あるものだけ**」を並べるものだから（A-13）。
> **値は「**ある位置**」を保つものです。** ここが非対称。

## わざと間違う②: `stockModeForType` を自分で作る

```swift NG
// わざと間違う版②：補助関数をローカルに作る
extension Product {
    func stockModeForType(_ types: [ProductType]) -> StockMode {
        types.first { $0.typeId == typeId }?.stockMode ?? .none
    }
}
```

**`base/2` に `stockMode(in:)` と `managesStock(in:)` があります。** 同じことを書いています。

**なぜ危険か**:

| | 見つからないとき | `?? .none` |
| --- | --- | --- |
| 種類が見つからない | **見つからない**（BUG） | **`none`（在庫管理なし）** |

**`?? .none` は「種類が無い＝在庫管理なし」と決めつけます。**
`stockMode(in:)` は `StockMode` を返しますが、`managesStock(in:)` は `Bool` を返すので、
**呼び出し側が意図を読み違えない**ようにできています。

**また `makeSnapshot` は `stockModeForType` さえ使いません。**
`stock: p.stock` を**そのまま**入れるだけです（§4 で）。

## わざと間違う③: `createdAt` を `String` にする

```swift NG
// わざと間違う版③：生成時刻を文字列で作る
struct Snapshot: Codable {
    let createdAt: String     // ★ base は Date
}
let snapshot = makeSnapshot(..., createdAt: "2026-10-13T12:00:00+09:00")
```

A-19-5 の決まりは**3 層**です。

| 層 | 持ち方 |
| --- | --- |
| Swift の構造体 | **`Date`** |
| JSON の境界 | `Date` を ISO 8601 へ変換（`.iso8601`） |
| SQLite | `TEXT` |

**`String` で持つと**、書ける人にしか書けなくなります。
**誰かが `2026-10-13 12:00:00`（スペース区切り）を入れると**、B 側でパースに失敗します。

**Encodersは 1 本だけ使い回します**（`base/2` の `jsonEncoder`）。

## わざと間違う④: `JSONEncoder` をその場で作る

```swift NG
// わざと間違う版④：その場で encoder を作る
func snapshotJSON(_ snapshot: Snapshot) throws -> Data {
    let encoder = JSONEncoder()
    encoder.keyEncodingStrategy = .convertToSnakeCase
    encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
    return try encoder.encode(snapshot)
}
```

**`keyEncodingStrategy` は正しい**（A-13 の `snake_case` に対応）。
**でも `dateEncodingStrategy` が無い**ので、`created_at` が
**Unix 時間（数字）**になります（A-19-5 の「ISO 8601・タイムゾーン付き」違反）。

| | `.dateEncodingStrategy` なし | `.iso8601` |
| --- | --- | --- |
| `created_at` | `1789...`（Unix 時間） | `2026-10-13T12:00:00+09:00` |

**設定が encoder ごとに散らばると**、**どれが正か分からなくなります**（`38_日時をISO8601にする.md`）。

**正**:

```swift 断片
// base/2 の正：encoder は 1 本だけ
let jsonEncoder: JSONEncoder = {
    let e = JSONEncoder()
    e.dateEncodingStrategy = .iso8601
    return e
}()
```

`keyEncodingStrategy` だけ変えたいなら、**`snapshot` 専用の encoder** を **1 つ**用意します。
**encoder は「送る形式ごとに 1 本」**、`dateEncodingStrategy` は**共有**。

## 1. `makeSnapshot` の正（`base/3` §8）

```swift 断片
/// 送信スナップショットを作る。**`image_ref` は含めない**。`has_image` は導出（A-14）。
func makeSnapshot(types: [ProductType], inventory: [Product], now: Date) -> Snapshot {
    let publicProducts = inventory.filter { $0.isPublic }
    let usedTypeIDs = Set(publicProducts.map { $0.typeId })
    let usedTypes = types
        .filter { usedTypeIDs.contains($0.typeId) }
        .map { t in
            SnapshotType(typeId: t.typeId, name: t.name, stockMode: t.stockMode,
                         attrLabels: [t.attrLabel1, t.attrLabel2, t.attrLabel3].compactMap { $0 })
        }
    let products = publicProducts.map { p in
        SnapshotProduct(productId: p.id, typeId: p.typeId, name: p.name,
                        priceJpy: p.priceJpy, priceSats: p.priceSats,
                        attrs: [p.attr1, p.attr2, p.attr3],     // ★ compactMap しない
                        stock: p.stock, hasImage: p.imageRef != nil)
    }
    return Snapshot(createdAt: now, types: usedTypes, products: products)
}
```

**この非対称を覚えてください。**

| | 処理 | なぜ |
| --- | --- | --- |
| `attrLabels` | **`compactMap`**（詰める） | 「**あるものだけ**」を並べる |
| `attrs` | **そのまま**（残す） | 「**ある位置**」を保つ |

## できた合図

- **`KH-020`（非公開）は含まれない**。送るのは `is_public` だけ
- **種類は 3 つ**（公開対象が属するものだけ）。`KH-020` しか属さない種類は**落ちます**
- **`TB-001`（在庫管理なし型）の `stock` は `nil`**（JSON にはキーごと出ない）
- **`ST-009`（`attr2` が無い）の `attrs` は `[黄, nil, nil]`**。**位置が保たれる**
- **`has_image` は導出**。`image_ref` は **JSON に現れない**
- **`product_id` / `stock_mode` は snake_case**。`camelCase` は混ざらない
- **`created_at` は ISO 8601**（Unix 時間にならない）
- **送信ログ `L-000001` / `L-000002`**。**送信失敗しても在庫は変わらない**（A-14）

## ポイント

- **`attrs` は `[String?]`**。`compactMap` すると**位置がズレる**（A-14、Q20）
- **`attrLabels` は `compactMap` する**。「あるものだけ」を並べるものだから
- **`Snapshot` は `Product` とは別型**。`image_ref` を**持たない**（A-14、P7）
- **`hasImage` は導出**。保持項目ではない（A-14）
- **`createdAt` は `Date`**。`String` で持たない（A-19-5）
- **encoder は 1 本**。`dateEncodingStrategy` を散らさない（`38` の教訓）
- **`stock` は在庫管理なし型で `nil`**。`nil` は JSON ではキーごと出ない
- **送信ログ `recordSync`** は**失敗しても在庫・会計に触らない**（A-14）
- **`is_public == false` は送らない**。種類も**公開対象が属するものだけ**
