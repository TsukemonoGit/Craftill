# 公開用スナップショットを作る

元: `../siyou.md` A-14

B（公開Webアプリ）へ送る**スナップショット**を作る練習です。送るのは**1つのJSON**で、Aの在庫情報をBが表示するために使います。

- 対象は **`is_public` の登録商品だけ**。野良商品は含めない。
- 種類定義は、**公開対象の商品が属する種類だけ**。
- 画像データ（バイナリ / Base64）は**含めない**。`image_ref` も含めない。画像の**有無だけ**を `has_image`（`image_ref` の有無から**導出**）で送る。
- `stock` は在庫管理なし型（`none`）では**空**。
- `Codable` な struct にして **JSON にエンコード**する。

> スナップショットの組み立ては**純ロジック**なので **ブック（Book）**。
> 実際に送る処理（HTTPS）は **アプリ（App）** の役目です（`1_初心者メモ.md`）。

## 前提データ

```swift
import Foundation

// ── 在庫の扱い（種類ごと）──
enum StockMode: String, Codable {
    case counted = "counted"   // 数量管理型
    case unique  = "unique"    // 一点物型
    case none    = "none"      // 在庫管理なし型
}

// ── 種類（product_types 相当）──
struct ProductType {
    let typeId: String
    let name: String
    let idPrefix: String
    let idDigits: Int
    let stockMode: StockMode
    let attrLabels: [String]   // 例: ["色", "模様"]
}

// ── 商品（products 相当）──
struct Product {
    let id: String
    let typeId: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?       // 空（nil）の場合あり
    var stock: Int?           // 在庫管理なし型は nil
    let attr1: String?
    let attr2: String?
    let attr3: String?
    let imageRef: String?     // 同梱画像への参照（Bへは送らない）
    let isPublic: Bool        // 公開状態
}

let productTypes: [ProductType] = [
    ProductType(typeId: "sticker",   name: "ステッカー",   idPrefix: "ST", idDigits: 3, stockMode: .counted, attrLabels: ["色", "模様"]),
    ProductType(typeId: "keyholder", name: "キーホルダー", idPrefix: "KH", idDigits: 3, stockMode: .unique,  attrLabels: ["色", "模様"]),
]

// ── 商品のサンプル（../開発/6_データベース.md）──
let products: [Product] = [

    Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく", priceJpy: 300, priceSats: nil,  stock: 9, attr1: "青", attr2: "しかく", attr3: nil, imageRef: "ST-003.jpg", isPublic: true),

    Product(id: "KH-003", typeId: "keyholder", name: "キーホルダー 03",   priceJpy: 800, priceSats: 1200, stock: 1, attr1: "緑", attr2: "□",       attr3: nil, imageRef: nil,          isPublic: true),   // 画像なし
    Product(id: "KH-020", typeId: "keyholder", name: "キーホルダー 20",   priceJpy: 800, priceSats: 1200, stock: 1, attr1: "紫", attr2: "☆",       attr3: nil, imageRef: "KH-020.jpg", isPublic: false),  // 非公開（送らない例）
```

## 送る形（スナップショット）

`snake_case` で送れるように、Swiftでは `camelCase` で書き、あとでキーを変換します。

```swift
// ── 種類定義（公開対象の商品が属する種類だけ）──
struct SnapshotType: Codable {
    let typeId: String        // 種類ID
    let name: String          // 表示名
    let stockMode: String     // 在庫の扱い
    let attrLabels: [String]  // 属性ラベル
}

// ── 商品 ──
struct SnapshotProduct: Codable {
    let productId: String     // 商品ID
    let typeId: String        // 種類ID
    let name: String          // 名前
    let priceJpy: Int         // 円価格
    let priceSats: Int?       // sats価格（空の場合あり）
    let attrs: [String]       // 属性の値
    let stock: Int?           // 在庫（none は nil＝空）
    let hasImage: Bool        // 画像の有無（image_ref の有無から導出）
}

// ── スナップショット全体 ──
struct Snapshot: Codable {
    let createdAt: String     // スナップショット作成時刻
    let types: [SnapshotType]
    let products: [SnapshotProduct]
}
```

- `stock: Int?` … 在庫管理なし型は `nil` にする。`nil` の項目はJSONで**キーごと出ない**（＝空になる）。
- `hasImage` は**保持しない**。`imageRef != nil` から**その場で導出**する（A-13）。

## 組み立てる関数

```swift
/// 公開用スナップショットを作る。
func makeSnapshot(products: [Product],
                  types: [ProductType],
                  createdAt: String) -> Snapshot {

    // ① 公開対象の登録商品だけに絞る（野良はそもそも products に無い）
    let publicProducts = products.filter { $0.isPublic }

    // ② 公開対象の商品が属する種類だけを集める（順序は types のまま）
    let usedTypeIDs = Set(publicProducts.map { $0.typeId })
    let snapshotTypes = types
        .filter { usedTypeIDs.contains($0.typeId) }
        .map { t in
            SnapshotType(typeId: t.typeId,
                         name: t.name,
                         stockMode: t.stockMode.rawValue,
                         attrLabels: t.attrLabels)
        }

    // ③ 商品をスナップショットの形にする
    let snapshotProducts = publicProducts.map { p -> SnapshotProduct in
        // 属性の値（nil は詰める）
        let attrs = [p.attr1, p.attr2, p.attr3].compactMap { $0 }
        // 在庫管理なし型は空。それ以外は現在庫
        let stock: Int? = (p.stockModeForType(types) == .none) ? nil : p.stock

        return SnapshotProduct(productId: p.id,
                               typeId: p.typeId,
                               name: p.name,
                               priceJpy: p.priceJpy,
                               priceSats: p.priceSats,
                               attrs: attrs,
                               stock: stock,
                               hasImage: p.imageRef != nil)   // 画像の有無を導出
    }

    return Snapshot(createdAt: createdAt, types: snapshotTypes, products: snapshotProducts)
}

// 商品の種類の stock_mode を引く小さな補助
extension Product {
    func stockModeForType(_ types: [ProductType]) -> StockMode {
        types.first { $0.typeId == typeId }?.stockMode ?? .none
    }
}
```

- `.compactMap { $0 }` … `nil` を捨てて、値がある物だけ残す。
- `Set(...)` … 種類IDの重複をなくす。
- `hasImage` は `imageRef != nil` の**導出値**。`stock` も種類の `stock_mode` で**空にする**。

## JSON にエンコードする

```swift
func snapshotJSON(_ snapshot: Snapshot) throws -> Data {
    let encoder = JSONEncoder()
    encoder.keyEncodingStrategy = .convertToSnakeCase   // productId → product_id
    encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
    return try encoder.encode(snapshot)
}

let snapshot = makeSnapshot(products: products, types: productTypes,
                            createdAt: "2026-10-13T12:00:00+09:00")

if let data = try? snapshotJSON(snapshot), let text = String(data: data, encoding: .utf8) {
    print(text)
}
```

## ポイント

- 対象は **`is_public` の登録商品だけ**。野良は含めない。
- 種類定義は、**公開対象の商品が属する種類だけ**。
- 画像データ（バイナリ / Base64）と `image_ref` は**送らない**。有無だけを `has_image` として `image_ref` の有無から**導出**する。
- `stock` は在庫管理なし型では**空**（`nil`）。
- `Codable` にして、`snake_case` のキーで **JSON** にエンコードする。
- 全商品を毎回送る方式なので、送信失敗の再試行・順序管理は不要（A-14）。
