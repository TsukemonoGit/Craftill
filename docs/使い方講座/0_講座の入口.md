# 使い方講座の入口

**これは「勉強・練習用」のフォルダ。** 実装（本番のコード）は隣の `../開発/` にある。
ここは「Swift初めての人が、Macが来る前にiPadで準備する」ための講座。

## 順番（上から1つずつ）
1. `1_初心者メモ.md` … Swiftの言葉（struct, enum, ? など）が分からない時に見る
2. `2_練習メニュー.md` … やることのチェックリスト（上から1つずつ）
3. `3_レッスン.md` … 各メニューの**やり方とコード**。2で詰まったらここ

## 使い方
- 新しい言葉が出たら `1_初心者メモ.md`
- 次に何をするかは `2_練習メニュー.md` の未チェック
- その項目のコードは `3_レッスン.md`
- 分からない言葉は都度ググってOK（この段階では覚えなくてよい）

## 大事なコツ
- **まとめてやらない。1つずつ。**
- **コピペより自分で打つ。** 値を少し変えて試すと覚える
- エラーが出たら `1_初心者メモ.md` の「つまずき」を見る

`../開発/4_最小構成やること.md` の「1. 土台」から。練習で作ったロジックはそのまま持ち込める。
