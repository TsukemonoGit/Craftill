# 使い方講座の入口

**これは「勉強・練習・準備用」のフォルダ。** アプリの仕様（何を作るか）は隣の `../開発/` にある。
ここは「Swift初めての人が、Macが来る前に準備し、来たら作り始める」ための講座。

## 順番（上から1つずつ）
1. `1_初心者メモ.md` … Swiftの言葉（struct, enum, ? など）が分からない時に見る
2. `2_練習メニュー.md` … やることのチェックリスト（上から1つずつ）
3. `3_レッスン.md` … 各メニューの**やり方とコード**。2で詰まったらここ
4. `4_Svelteで理解するSwift.md` … Svelteが分かる人向け。対応表と例。**随時参照**
5. `5_Xcodeでプロジェクト作成.md` … Macが来たら最初に見る。マルチプラットフォームで作成
6. `6_QRを試す.md` … QR生成の練習。iPadでもMacでも動くコード | 随時
7〜22. **追加レッスン**（下の一覧）… `3_レッスン.md` のあとで。**やるかやらないかは自由**

各レッスンの先頭には、対応する `../siyou.md` の節番号（A-1 など）を書いてある。

## 使い方
- 新しい言葉が出たら `1_初心者メモ.md`
- 次に何をするかは `2_練習メニュー.md` の未チェック
- その項目のコードは `3_レッスン.md`
- 分からない言葉は都度ググってOK（この段階では覚えなくてよい）

## 大事なコツ
- **まとめてやらない。1つずつ。**
- **コピペより自分で打つ。** 値を少し変えて試すと覚える
- エラーが出たら `1_初心者メモ.md` の「つまずき」を見る
