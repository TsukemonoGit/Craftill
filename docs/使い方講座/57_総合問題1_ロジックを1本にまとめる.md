## 自分で書く手順

型と配列は上にそろっています。ここから先は、次の関数を**自分で**書いてみましょう（中身だけ考える）。

1. **`totals(_ cart:) -> Totals`**（A-3）
   - `sats` … sats単価がある行の「sats単価×数量」
   - `cashForSats` … sats単価がない行の「円単価×数量」（＝現金分）
   - `cash` … 全行の「円単価×数量」
   - 入れ物は `struct Totals { var sats = 0; var cashForSats = 0; var cash = 0 }` を用意する

2. **`totalLines(_ cart:) -> (satsLine: String, cashLine: String)`**（A-3 の2行）
   - 全行satsなし → `"sats払い　選択不可（sats単価のある商品がありません）"`
   - 現金分0 → `"sats払い　○sats"`
   - それ以外 → `"sats払い　○sats ＋ ○円"`
   - 現金の行は `"現金　　　○円"`

3. **`normalizeProductID(_ raw:) -> String?`**（A-2）
   - 大文字化 → 英字と数字に分ける → 接頭辞を `productTypes` と照合 → `idDigits` 桁でゼロ埋め
   - 知らない接頭辞や数字なしは `nil`

4. **`addToCart(_ p:, cart: inout) -> AddResult`**（A-1）
   - `AddResult` は `enum AddResult { case added(productId: String, qty: Int); case rejected(reason: String) }`
   - 在庫0の `counted`／`unique` は `.rejected("SOLD OUT…")`
   - `unique` で同じ商品がすでにあれば `.rejected("一点物…追加済み")`
   - `counted`／`none` はすでにあれば数量+1、なければ追加

5. **`resolveMethod(chooseSats:, cart:) -> String`**（A-13 の `method`）
   - satsを選ばなければ `"cash"`。選んだ場合、現金分が0なら `"lightning"`、あれば `"mixed"`

6. **`buildSale(...) -> (sale: Sale, items: [SaleItem])`**（A-4, A-13）
   - 明細の `paidIn` … `cash` は全部 `"jpy"`。`lightning`／`mixed` は「sats単価がある行が `sats`、ない行が `jpy`」
   - `method` ごとに `totalJpy`／`totalSats`／`confirmedAt` を入れる
   - `cash`／`mixed` は受取額とお釣りを入れる

7. **`completeSale(...) -> CompleteResult`**（A-7）
   - 「在庫検証 → 在庫減算 → 在庫変動ログ」の順。検証で失敗したら**何も変えずに** `.failure`
   - 検証で足りなかった商品的理由を**全件**集めて `.failure` に渡す（1 件で止めない）
   - `enum CompleteResult { case success(lines: [String]); case failure([String]) }`
   - 対象かどうかの判定は `stockTargets` に 1 か所でまとめる（`08_在庫を減らす.md` と同じ方針）

8. **`summarize(_ sales:, items:) -> DailySummary`**（A-8）
   - 件数は会計単位（`Set<String>`）。円とsatsは別々に足す
   - `voided` は売上に含めず、別に数える

> 書けたら、下の**模範解答**と見比べてください。動けば、シナリオを少し変えて（商品や枚数を変えて）試すのがおすすめです。

## 模範解答

### 57-1. 合計と2行

```swift
struct Totals {
    var sats = 0         // sats単価のある行のsats合計
    var cashForSats = 0  // sats単価のない行の円合計（＝現金分）
    var cash = 0         // 全行の円合計
}

func totals(_ cart: [CartLine]) -> Totals {
    var t = Totals()
    for line in cart {
        if let s = line.unitPriceSats { t.sats += s * line.qty }
        else { t.cashForSats += line.unitPriceJpy * line.qty }
        t.cash += line.unitPriceJpy * line.qty
    }
    return t
}

func totalLines(_ cart: [CartLine]) -> (satsLine: String, cashLine: String) {
    let t = totals(cart)
    let hasSats = cart.contains { $0.unitPriceSats != nil }
    let satsLine: String
    if !hasSats {
        satsLine = "sats払い　選択不可（sats単価のある商品がありません）"
    } else if t.cashForSats == 0 {
        satsLine = "sats払い　\(t.sats)sats"
    } else {
        satsLine = "sats払い　\(t.sats)sats ＋ \(t.cashForSats)円"
    }
    return (satsLine, "現金　　　\(t.cash)円")
}
```

### 57-2. ID正規化（A-2）

```swift
func normalizeProductID(_ raw: String) -> String? {
    let upper = raw.uppercased()
    let prefix = String(upper.filter { $0.isLetter })
    let digitText = upper.filter { $0.isNumber }
    guard let pt = productTypes.first(where: { $0.idPrefix == prefix }) else { return nil }
    guard let n = Int(digitText) else { return nil }
    return prefix + "-" + String(format: "%0\(pt.idDigits)d", n)
}
```

### 57-3. カートに追加（A-1）

```swift
enum AddResult {
    case added(productId: String, qty: Int)
    case rejected(reason: String)
}

func addToCart(_ p: Product, cart: inout [CartLine]) -> AddResult {
    // SOLD OUT（在庫管理ありで在庫0）は追加しない
    if p.stockMode != .none, let stock = p.stock, stock <= 0 {
        return .rejected(reason: "SOLD OUT（\(p.name)）")
    }
    let index = cart.firstIndex { $0.id == p.id }

    switch p.stockMode {
    case .unique:
        if index != nil { return .rejected(reason: "一点物（\(p.name)）は同一会計で追加済みです") }
        cart.append(line(p, qty: 1))
        return .added(productId: p.id, qty: 1)
    case .counted, .none:
        if let i = index {
            cart[i].qty += 1
            return .added(productId: p.id, qty: cart[i].qty)
        } else {
            cart.append(line(p, qty: 1))
            return .added(productId: p.id, qty: 1)
        }
    }
}
```

### 57-4. 支払方法と会計の組み立て

```swift
func resolveMethod(chooseSats: Bool, cart: [CartLine]) -> String {
    if !chooseSats { return "cash" }
    return totals(cart).cashForSats == 0 ? "lightning" : "mixed"
}

func paidIn(_ line: CartLine, method: String) -> String {
    if method == "cash" { return "jpy" }
    return line.unitPriceSats != nil ? "sats" : "jpy"
}

func buildSale(saleId: String, cart: [CartLine], chooseSats: Bool,
               receivedJpy: Int?, confirmedAt: String?,
               now: String) -> (sale: Sale, items: [SaleItem]) {

    let method = resolveMethod(chooseSats: chooseSats, cart: cart)
    let t = totals(cart)

    var sale = Sale(saleId: saleId, status: "completed", method: method,
                    totalJpy: nil, totalSats: nil, receivedJpy: nil, changeJpy: nil,
                    confirmedAt: nil, refunded: 0, completedAt: now)

    var items: [SaleItem] = []
    for (n, line) in cart.enumerated() {
        items.append(SaleItem(
            itemId: String(format: "I-%03d", n + 1),
            saleId: saleId,
            itemType: line.isAdhoc ? "adhoc" : "registered",
            typeId: line.isAdhoc ? nil : line.typeId,
            productId: line.isAdhoc ? nil : line.id,
            qty: line.qty,
            unitPriceJpy: line.unitPriceJpy,
            unitPriceSats: line.unitPriceSats,
            paidIn: paidIn(line, method: method),
            nameSnapshot: line.name))
    }

    switch method {
    case "cash":
        sale.totalJpy = t.cash
    case "lightning":
        sale.totalSats = t.sats
        sale.confirmedAt = confirmedAt
    case "mixed":
        sale.totalSats = t.sats
        sale.totalJpy = t.cashForSats
        sale.confirmedAt = confirmedAt
    default:
        break
    }

    if method == "cash" || method == "mixed" {
        sale.receivedJpy = receivedJpy
        if let r = receivedJpy, let req = sale.totalJpy { sale.changeJpy = r - req }
    }
    return (sale, items)
}
```

### 57-5. 完了処理（在庫検証→減算→ログ。A-7）

考え方は `08_在庫を減らす.md` と同じ。**検証が終わってからまとめて反映する**。
対象（在庫管理ありの登録商品の行）の判定は `stockTargets` に 1 か所でまとめ、検証と減算の両方で使い回します。

```swift
enum CompleteResult {
    case success(lines: [String])
    case failure([String])        // 不足の理由を全件
}

/// 減算の対象だけを、在庫表の位置（index）と現在値つきで取り出す。
/// 野良（isAdhoc）と在庫管理なし型は含まれない。
func stockTargets(_ cart: [CartLine], in stock: [Product]) -> [(index: Int, line: CartLine, current: Int)] {
    var targets: [(index: Int, line: CartLine, current: Int)] = []
    for line in cart {
        guard !line.isAdhoc,
              let i = stock.firstIndex(where: { $0.id == line.id }),
              stock[i].stockMode != .none,
              let current = stock[i].stock else { continue }
        targets.append((index: i, line: line, current: current))
    }
    return targets
}

/// 在庫不足の理由を全件返す。問題なければ空配列。
func checkStock(_ cart: [CartLine], stock: [Product]) -> [String] {
    var problems: [String] = []
    for t in stockTargets(cart, in: stock) where t.line.qty > t.current {
        problems.append("在庫不足: \(t.line.name)（在庫 \(t.current)、必要 \(t.line.qty)）")
    }
    return problems
}

func completeSale(saleId: String, cart: [CartLine],
                  stock: inout [Product], movements: inout [StockMovement],
                  at: String) -> CompleteResult {
    let problems = checkStock(cart, stock: stock)
    if !problems.isEmpty { return .failure(problems) }

    var memo: [String] = []
    for t in stockTargets(cart, in: stock) {
        let after = t.current - t.line.qty
        stock[t.index].stock = after
        movements.append(StockMovement(id: "M-\(saleId)-\(t.line.id)", productId: t.line.id,
                                       delta: -t.line.qty, reason: "sale", saleId: saleId, at: at))
        memo.append("\(t.line.name): 在庫 \(t.current) → \(after)")
    }
    return .success(lines: memo)
}
```

### 57-6. 日次集計（A-8）

```swift
struct DailySummary {
    var cashSaleIDs: Set<String> = []
    var cashJpy = 0
    var satsSaleIDs: Set<String> = []
    var satsAmount = 0
    var mixedSaleIDs: Set<String> = []
    var voidedSaleIDs: Set<String> = []
    var voidedSats = 0
    var cashRegistered = 0
    var cashAdhoc = 0
    var satsRegistered = 0
    var satsAdhoc = 0
}

func summarize(_ sales: [Sale], items: [SaleItem]) -> DailySummary {
    var s = DailySummary()
    for sale in sales {
        if sale.status == "voided" {
            s.voidedSaleIDs.insert(sale.saleId)
            s.voidedSats += sale.totalSats ?? 0
            continue
        }
        guard sale.status == "completed" else { continue }
        if sale.method == "cash" || sale.method == "mixed" {
            s.cashSaleIDs.insert(sale.saleId)
            s.cashJpy += sale.totalJpy ?? 0
        }
        if sale.method == "lightning" || sale.method == "mixed" {
            s.satsSaleIDs.insert(sale.saleId)
            s.satsAmount += sale.totalSats ?? 0
        }
        if sale.method == "mixed" { s.mixedSaleIDs.insert(sale.saleId) }
    }
    for item in items {
        guard let sale = sales.first(where: { $0.saleId == item.saleId }),
              sale.status == "completed" else { continue }
        if item.paidIn == "sats" {
            let amount = (item.unitPriceSats ?? 0) * item.qty
            if item.itemType == "registered" { s.satsRegistered += amount } else { s.satsAdhoc += amount }
        } else {
            let amount = item.unitPriceJpy * item.qty
            if item.itemType == "registered" { s.cashRegistered += amount } else { s.cashAdhoc += amount }
        }
    }
    return s
}
```

## ポイント

- 会計1件は「**`sales` 1行 ＋ `sale_items` のN行**」。金額は `totalJpy` と `totalSats` を**別々**に持つ（円とsatsは合算しない）
- 合計は「**sats合計**」「**現金分**」「**現金合計**」の3つを区別する。現金分があるかで `lightning` と `mixed` が決まる
- 一点物型（`unique`）は同一会計で**1点だけ**。数量管理型（`counted`）は再追加で数量+1
- 在庫の減算は**完了のときだけ**。対象は在庫管理ありの登録商品のみ。野良は在庫を触らない（A-7）
- 在庫を減らしたら、必ず `stock_movements` に `sale` として記録する（A-7）
- 日次集計の件数は**会計単位**（`Set`）。併用会計は現金とsatsの**両方**に計上し、併用の件数は別に出す（A-8）
- `normalizeProductID` の桁数・接頭辞は、固定値ではなく**種類定義（`productTypes`）に従う**（A-2）
