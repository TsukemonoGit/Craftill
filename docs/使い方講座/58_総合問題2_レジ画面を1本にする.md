# 総合演習2: レジ画面を1本にする【大問】

元: `../siyou.md` A-3, A-4, A-5

SwiftUI で、**レジ画面1枚**に次を統合した最小アプリを作ります。

- **商品パネル**（タップで追加。SOLD OUT は押せない）
- **カート**（数量の＋／－・削除・**合計2行**）
- **支払方法選択**（現金／sats払い）
- **現金会計**（受取額を数字キーで入力 → お釣り）

状態は **`@Observable` の store** で1か所にまとめて共有し、**会計状態（A-4）**で表示を切り替えます。
`@main` 付きなので、**そのまま動きます**。

> これは画面（UI）を出すので **アプリ（App）** で作ります。`@Observable` は **macOS 14 / iOS 17 以降**で使えます。
> このファイルだけで完結します。**前提データ**を貼ったうえで、「自分で書く手順」を自分で書き、そのあと**模範解答**と見比べてください。

## 前提データ（型・サンプル。このまま貼れば動く）

```swift
import SwiftUI
import Observation

#if os(macOS)
import AppKit      // Mac では NSImage（画像があるときだけ使う）
#else
import UIKit       // iPad では UIImage
#endif

// ── 在庫の扱い（種類ごと。A-1）────────────
enum StockMode: String {
    case counted = "counted"   // 数量管理型（ステッカー）
    case unique  = "unique"    // 一点物型（キーホルダー）
    case none    = "none"      // 在庫管理なし型（今回は商品なし）
}

// ── 商品（products 相当。A-13）────────────
struct Product: Identifiable {
    let id: String
    let typeId: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?       // nil なら sats払いでも現金で受け取る
    var stock: Int?           // none は nil
    let stockMode: StockMode
}

// ── カートの1行 ─────────────────────────
struct CartLine {
    let id: String          // 登録商品は商品ID、野良は "ADHOC-1" など
    let typeId: String?     // 登録商品は種類ID、野良は nil
    let name: String        // カートに入れた時点の商品名
    let unitPriceJpy: Int   // カートに入れた時点の円単価
    let unitPriceSats: Int? // カートに入れた時点のsats単価
    var qty: Int
    let isAdhoc: Bool       // 野良かどうか
}

// ── 合計の入れ物（A-3）──────────────────
struct Totals {
    var sats = 0         // sats単価のある行のsats合計
    var cashForSats = 0  // sats単価のない行の円合計（＝現金分）
    var cash = 0         // 全行の円合計
}

// ── 会計状態（A-4）──────────────────────
enum SaleState {
    case idle             // 待機中
    case scanning         // スキャン中
    case choosingPayment  // 支払方法選択
    case cashInput        // 現金入力中
    case done             // 完了
}

// ── サンプル商品（../開発/6_データベース.md より。ST-003 は satsなし）──
func sampleProducts() -> [Product] {
    [
        Product(id: "ST-001", typeId: "sticker",   name: "ステッカー まる",     priceJpy: 300, priceSats: 500,  stock: 10, stockMode: .counted),
        Product(id: "ST-002", typeId: "sticker",   name: "ステッカー さんかく", priceJpy: 300, priceSats: 500,  stock: 10, stockMode: .counted),
        Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく",   priceJpy: 300, priceSats: nil,  stock: 10, stockMode: .counted),
        Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
        Product(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
        Product(id: "KH-003", typeId: "keyholder", name: "キーホルダー 03", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
        Product(id: "KH-008", typeId: "keyholder", name: "キーホルダー 08", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
        Product(id: "KH-020", typeId: "keyholder", name: "キーホルダー 20", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
    ]
}

// 商品IDと同名の画像がアプリに入っているか（OSでAPIが違う）
func hasImage(_ name: String) -> Bool {
    #if os(macOS)
    return NSImage(named: name) != nil
    #else
    return UIImage(named: name) != nil
    #endif
}
```

## 自分で書く手順

型とサンプルは上にそろっています。ここから先は、次の順で**自分で**書いてみましょう。

1. **`@Observable final class RegisterStore`**
   - プロパティ: `var products`、`var cart`、`var state`、`var receivedJpy`、`var payBySats`
   - 計算プロパティ: `totals`、`satsLine`、`cashLine`、`hasSatsLine`、`cashDue`、`change`、`canConfirm`

2. **storeのメソッド**
   - `add(_:)` … 在庫0の `counted`／`unique` は追加しない。`unique` は重複しない。`counted` は数量+1。`idle` なら `scanning` へ
   - `changeQty(_:by:)` … 0以下になったら行を削除。カートが空なら `idle` へ
   - `goToPayment()` / `backToScan()` / `chooseCash()` / `chooseSats()` / `confirmCash()` / `cancelSale()`
   - `chooseSats()` で現金分が0なら**そのまま完了**。あれば `cashInput` へ
   - `pressDigit(_:)` / `backspace()` / `addQuick(_:)` … 受取額の入力
   - 完了時は **在庫検証 → まとめて減算**。足りなければ `state` を変えず、理由を `stockProblems` に入れる（A-7。`08_在庫を減らす.md`）

3. **画面（View）**
   - `ProductPanel` … 商品を並べる（タップで `add`、SOLD OUT は無効）
   - `CartPanel` / `CartRow` … カートと合計2行
   - `PaymentChoice` … 現金／sats払い（sats単価の行がなければ無効）
   - `CashInput` … 請求額・受取額・お釣り・数字キー・確定
   - `DoneView` … 完了とお釣り
   - `RegisterView` … 左に商品パネル、右にカート＋状態ごとの操作エリア

4. **`@main`** … `WindowGroup { RegisterView(store: store) }`

> 書けたら、下の**模範解答**と見比べてください。

## 模範解答

### 58-1. 状態をまとめる store

```swift
@Observable
final class RegisterStore {
    var products: [Product] = sampleProducts()
    var cart: [CartLine] = []
    var state: SaleState = .idle
    var receivedJpy = 0          // 現金の受取額
    var payBySats = false        // sats払いを選んだか
    var stockProblems: [String] = []   // 完了時に出た在庫不足の理由（画面に出す）

    // ── 合計（円とsatsは合算しない）──
    var totals: Totals {
        var t = Totals()
        for line in cart {
            if let s = line.unitPriceSats { t.sats += s * line.qty }
            else { t.cashForSats += line.unitPriceJpy * line.qty }
            t.cash += line.unitPriceJpy * line.qty
        }
        return t
    }
    var hasSatsLine: Bool { cart.contains { $0.unitPriceSats != nil } }

    // 合計の2行（A-3）
    var satsLine: String {
        let t = totals
        if !hasSatsLine { return "sats払い　選択不可（sats単価のある商品がありません）" }
        if t.cashForSats == 0 { return "sats払い　\(t.sats)sats" }
        return "sats払い　\(t.sats)sats ＋ \(t.cashForSats)円"
    }
    var cashLine: String { "現金　　　\(totals.cash)円" }

    // いま受け取るべき現金（現金払い＝円合計、sats払い＝現金分）
    var cashDue: Int { payBySats ? totals.cashForSats : totals.cash }
    var change: Int { receivedJpy - cashDue }
    var canConfirm: Bool { receivedJpy >= cashDue }

    // ── カートに追加（A-1）──
    func add(_ p: Product) {
        guard state == .idle || state == .scanning else { return }
        if p.stockMode != .none, let stock = p.stock, stock <= 0 { return }   // SOLD OUT
        if let i = cart.firstIndex(where: { $0.id == p.id }) {
            if p.stockMode == .unique { return }   // 一点物の重複は追加しない
            cart[i].qty += 1
        } else {
            cart.append(CartLine(id: p.id, typeId: p.typeId, name: p.name, unitPriceJpy: p.priceJpy,
                                 unitPriceSats: p.priceSats, qty: 1, isAdhoc: false))
        }
        if state == .idle { state = .scanning }
    }

    func changeQty(_ id: String, by delta: Int) {
        guard let i = cart.firstIndex(where: { $0.id == id }) else { return }
        let next = cart[i].qty + delta
        if next <= 0 { cart.remove(at: i) } else { cart[i].qty = next }
        if cart.isEmpty { state = .idle }
    }

    // ── 状態遷移（A-4）──
    func goToPayment() { if !cart.isEmpty { state = .choosingPayment } }
    func backToScan() { state = cart.isEmpty ? .idle : .scanning }

    func chooseCash() { payBySats = false; receivedJpy = 0; state = .cashInput }

    func chooseSats() {
        payBySats = true; receivedJpy = 0
        if totals.cashForSats == 0 { complete() }   // 現金分なし → そのまま完了
        else { state = .cashInput }                 // 現金分だけ現金で受け取る
    }

    func pressDigit(_ d: Int) { receivedJpy = receivedJpy * 10 + d }
    func backspace() { receivedJpy /= 10 }
    func addQuick(_ yen: Int) { receivedJpy += yen }
    func confirmCash() { if canConfirm { complete() } }

    func cancelSale() { cart = []; receivedJpy = 0; payBySats = false; stockProblems = []; state = .idle }

    // ── 完了: 在庫検証 → まとめて減算（A-7。考え方は 08_在庫を減らす.md）──
    /// 減算の対象（在庫管理ありの登録商品の行）を、位置と現在値つきで取り出す。
    /// 野良（isAdhoc）と在庫管理なし型は含まれない。
    private func stockTargets() -> [(index: Int, line: CartLine, current: Int)] {
        var targets: [(index: Int, line: CartLine, current: Int)] = []
        for line in cart where !line.isAdhoc {
            guard let i = products.firstIndex(where: { $0.id == line.id }),
                  products[i].stockMode != .none,
                  let current = products[i].stock else { continue }
            targets.append((index: i, line: line, current: current))
        }
        return targets
    }

    /// 検証で足りなければ **何も変えず**、元の状態のまま理由を `stockProblems` に入れる。
    @discardableResult
    private func complete() -> [String] {
        let targets = stockTargets()
        var problems: [String] = []
        for t in targets where t.line.qty > t.current {
            problems.append("在庫不足: \(t.line.name)（在庫 \(t.current)、必要 \(t.line.qty)）")
        }
        stockProblems = problems
        guard problems.isEmpty else { return problems }   // ← ここで 1 件も書き換えない

        for t in targets {
            products[t.index].stock = t.current - t.line.qty
        }
        state = .done
        return []
    }

    func finishDone() { cancelSale() }   // 完了画面から待機中へ
}
```

### 58-2. 商品パネル

```swift
struct ProductPanel: View {
    let store: RegisterStore

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            Text("商品").font(.headline).padding()
            ScrollView {
                LazyVGrid(columns: [GridItem(.adaptive(minimum: 100), spacing: 8)], spacing: 8) {
                    ForEach(store.products) { p in
                        ProductCell(product: p) { store.add(p) }
                    }
                }
                .padding()
            }
        }
        .frame(minWidth: 340)
    }
}

struct ProductCell: View {
    let product: Product
    let onTap: () -> Void

    private var soldOut: Bool { product.stockMode != .none && (product.stock ?? 0) <= 0 }

    var body: some View {
        Button(action: onTap) {
            VStack(spacing: 4) {
                thumb
                Text(product.name).font(.caption).lineLimit(1)
                Text("¥\(product.priceJpy)").font(.caption2).foregroundStyle(.secondary)
                if soldOut { Text("SOLD OUT").font(.caption2).foregroundStyle(.red) }
            }
            .frame(width: 100, height: 104)
            .background(Color.gray.opacity(soldOut ? 0.08 : 0.15))
            .cornerRadius(8)
        }
        .buttonStyle(.plain)
        .disabled(soldOut)
    }

    @ViewBuilder
    private var thumb: some View {
        if hasImage(product.id) {
            Image(product.id).resizable().scaledToFit().frame(width: 40, height: 40)
        } else {
            Text(product.id).font(.caption2)
                .frame(width: 40, height: 40).background(Color.gray.opacity(0.2)).cornerRadius(4)
        }
    }
}
```

### 58-3. カートと合計2行

```swift
struct CartPanel: View {
    let store: RegisterStore

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            Text("カート").font(.headline).padding()
            ScrollView {
                VStack(spacing: 0) {
                    ForEach(store.cart) { line in
                        CartRow(line: line,
                                onMinus: { store.changeQty(line.id, by: -1) },
                                onPlus:  { store.changeQty(line.id, by: +1) })
                        Divider()
                    }
                }
                .padding(.horizontal)
            }
            Divider()
            VStack(alignment: .trailing, spacing: 4) {
                Text(store.satsLine)
                Text(store.cashLine)
            }
            .frame(maxWidth: .infinity, alignment: .trailing)
            .padding()
        }
    }
}

struct CartRow: View {
    let line: CartLine
    let onMinus: () -> Void
    let onPlus: () -> Void

    var body: some View {
        HStack(spacing: 10) {
            VStack(alignment: .leading, spacing: 2) {
                Text(line.name)
                Text("¥\(line.unitPriceJpy) ・ \(satsText)")
                    .font(.caption).foregroundStyle(.secondary)
            }
            Spacer()
            Button("−", action: onMinus)
            Text("\(line.qty)").frame(minWidth: 24)
            Button("＋", action: onPlus)
            Text("¥\(line.unitPriceJpy * line.qty)").frame(width: 72, alignment: .trailing)
        }
        .padding(.vertical, 6)
    }

    private var satsText: String { line.unitPriceSats.map { "\($0) sats" } ?? "―（現金）" }
}
```

```swift
struct CashInput: View {
    let store: RegisterStore

    var body: some View {
        VStack(spacing: 8) {
            Text(store.payBySats ? "sats払い（現金分）" : "現金").font(.headline)
            if store.payBySats {
                Text("請求sats \(store.totals.sats) sats").font(.callout).foregroundStyle(.secondary)
            }
            amountRow("請求額", store.cashDue)
            amountRow("受取額", store.receivedJpy)
            amountRow("お釣り", store.canConfirm ? store.change : 0)
            keypad
            HStack(spacing: 12) {
                Button("確定") { store.confirmCash() }.disabled(!store.canConfirm)
                Button("戻る") { store.backToScan() }
            }
        }
        .padding()
    }

    private func amountRow(_ label: String, _ yen: Int) -> some View {
        HStack { Text(label).foregroundStyle(.secondary); Spacer(); Text("¥\(yen)") }
    }

    private var keypad: some View {
        VStack(spacing: 6) {
            ForEach([[7, 8, 9], [4, 5, 6], [1, 2, 3]], id: \.self) { row in
                HStack(spacing: 6) {
                    ForEach(row, id: \.self) { d in
                        Button("\(d)") { store.pressDigit(d) }
                    }
                }
            }
            HStack(spacing: 6) {
                Button("0") { store.pressDigit(0) }
                Button("00") { store.pressDigit(0); store.pressDigit(0) }
                Button("⌫") { store.backspace() }
            }
            HStack(spacing: 6) {
                ForEach([1000, 5000, 10000], id: \.self) { y in
                    Button("+\(y)") { store.addQuick(y) }
                }
            }
        }
    }
}
```

### 58-5. レジ画面1枚 と @main

```swift
struct RegisterView: View {
    let store: RegisterStore

    var body: some View {
        HStack(spacing: 0) {
            ProductPanel(store: store)
            Divider()
            VStack(spacing: 0) {
                CartPanel(store: store)
                Divider()
                actionArea
            }
            .frame(width: 400)
        }
        .frame(minWidth: 820, minHeight: 540)
    }

    // 会計状態で表示を切り替える（A-4）
    @ViewBuilder
    private var actionArea: some View {
        switch store.state {
        case .idle, .scanning:
            HStack {
                Button("会計へ進む") { store.goToPayment() }.disabled(store.cart.isEmpty)
                Spacer()
                Button("中断") { store.cancelSale() }.disabled(store.cart.isEmpty)
            }
            .padding()
        case .choosingPayment:
            PaymentChoice(store: store)
        case .cashInput:
            CashInput(store: store)
        case .done:
            DoneView(store: store)
        }
    }
}

@main
struct RegisterApp: App {
    @State private var store = RegisterStore()
    var body: some Scene {
        WindowGroup { RegisterView(store: store) }   // ← 起動時にこれが自動で出る
    }
}
```

## 動かし方とできた合図

1. Xcode でアプリを新規作成し、上のコードを1ファイルに貼る（`@main` は1つだけ）
2. Run（⌘R）。**Neo（macOS）** ではクリック、iPad ではタップ

**できた合図**:

- 左に商品パネル、右にカートが出る
- 商品を3つクリックすると、カートに行が並び、下に**合計2行**が出る
  - 例: KH-001×1 ＋ ST-001×2 ＋ ST-003×1 →
    ```
    sats払い　2200sats ＋ 300円
    現金　　　2500円
    ```
- 一点物（KH-001）を2回クリックしても増えない。在庫0になった商品は **SOLD OUT** で押せない
- 「会計へ進む」→「現金」→ 数字キーで受取額を入れると**お釣り**が出る。受取額が請求額未満だと**確定が押せない**
- 確定すると「✓ 完了」となり、在庫管理ありの商品の在庫が減る
- 「sats払い」を選ぶと、sats単価のない行（ST-003、野良）の**現金分**だけ受け取る流れになる。現金分が0ならそのまま完了する

## ポイント

- 状態は **`@Observable` の store 1つ**に集約する。画面は `store.state` を見て切り替えるだけ（A-4）
- 合計は「**sats合計**」「**現金分**」「**現金合計**」を区別して持つ。円とsatsは合算しない（A-3）
- `satsLine` は全行satsなし→「選択不可」、現金分0→「satsのみ」、あれば「sats ＋ 現金分」
- 現金会計は `request額 = 受取額 - お釣り` を毎回計算する。`canConfirm` で確定ボタンを無効化（A-5）
- sats払いで現金分があるときは、確認済みとして**現金分だけ現金で受け取る**（併用。A-6-1）
- 在庫の減算は**完了のときだけ**。対象は在庫管理ありの登録商品のみ。野良は触らない（A-7）
- 完了時は **検証が終わってからまとめて減算**する。1 件でも足りなければ `state` を変えず、`stockProblems` を画面に出す（`08_在庫を減らす.md`）
- OSで違うAPIは `#if os(macOS) / #else / #endif` で分ける（ここでは画像の有無チェック）
- 実運用では、会計状態とカートを**更新のたびに端末内へ保存**して、再起動後に復元する（A-3）
