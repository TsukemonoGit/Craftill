# 33. お釣りと確定ボタンを作る

元: `../siyou.md` A-5（現金決済）

**ゴール**: 現金の**受取額**と**お釣り**を計算する。お釣り = 受取額 − 請求額。
受取額が請求額未満の間は**確定できない**。1,000 / 5,000 / 10,000 円ボタンで受取額を増やす。

> 純ロジックの練習。**ブック（Book）**で作る。
> これを SwiftUI の画面にするときは**アプリ**で作る（レッスン7の「② アプリで表示する」と同じ）。

## 前提データ（このまま貼れば動く）

## 33-1. 受取額とお釣りを持つ型

「請求額」は決まっていて動かない。「受取額」はボタンを押すたびに増える。

```swift
/// 現金入力の状態。
struct CashInput {
    let totalJpy: Int          // 請求額（動かない）
    var receivedJpy: Int = 0   // 受取額（増える）

    // お釣り = 受取額 − 請求額
    var changeJpy: Int { receivedJpy - totalJpy }

    // 確定してよいか（受取額が請求額以上）
    var canConfirm: Bool { receivedJpy >= totalJpy }

    // 表示用のお釣り（確定できるまでは 0 とみなす）
    var displayChangeJpy: Int { canConfirm ? changeJpy : 0 }

    // 受取額を増やす（数字キー・金額ボタン）
    mutating func add(_ yen: Int) {
        receivedJpy += yen
    }

    // 受取額を 0 に戻す
    mutating func clear() {
        receivedJpy = 0
    }
}
```

- `var changeJpy: Int { ... }` … **計算プロパティ**。持たずに毎回計算する
- `canConfirm` … `receivedJpy >= totalJpy` が成り立つときだけ true
- `mutating func` … `struct` の中身（`receivedJpy`）を書き換える関数に付ける印
- `displayChangeJpy` … 請求額に届く前はマイナスになるので、画面用に 0 とみなす

## 33-2. 金額ボタンを表す

レジ画面のボタンはこの3つ。押すと `add` する。

```swift
let quickButtons = [1000, 5000, 10000]   // 1,000 / 5,000 / 10,000 円

/// ボタンを押したときの動き。
func pressQuickButton(_ input: inout CashInput, amount: Int) {
    input.add(amount)
}
```

- `inout CashInput` … 「この値を書き換える」と宣言する書き方（`&` を付けて渡す）

## 33-3. 動かしてみる

```swift
var cash = CashInput(totalJpy: totalJpy)   // 請求 ¥1400

print("請求額: ¥\(cash.totalJpy)")
print("確定できる？ \(cash.canConfirm)")             // false（受取0）

// 1,000円ボタンを押す
pressQuickButton(&cash, amount: 1000)
print("受取 ¥\(cash.receivedJpy) / お釣り ¥\(cash.displayChangeJpy) / 確定 \(cash.canConfirm)")

// もう一度 1,000円
pressQuickButton(&cash, amount: 1000)
print("受取 ¥\(cash.receivedJpy) / お釣り ¥\(cash.changeJpy) / 確定 \(cash.canConfirm)")

// 5,000円の例（別の会計）
var cash2 = CashInput(totalJpy: 3800)
cash2.add(5000)
print("請求 ¥3800 → 受取 ¥\(cash2.receivedJpy) / お釣り ¥\(cash2.changeJpy) / 確定 \(cash2.canConfirm)")
```

**できた合図**:
- `請求額: ¥1400`
- `確定できる？ false`
- `受取 ¥1000 / お釣り ¥0 / 確定 false`（受取が請求に届いていない）
- `受取 ¥2000 / お釣り ¥600 / 確定 true`
- `請求 ¥3800 → 受取 ¥5000 / お釣り ¥1200 / 確定 true`

---

## ポイント
- お釣り = **受取額 − 請求額**。自動で計算する
- 受取額が請求額未満の間は `canConfirm` が false。**確定ボタンは無効**にする
- 1,000 / 5,000 / 10,000 円ボタンは `add` で受取額に足すだけ
- SwiftUIにするときは、この `CashInput` を `@State` のプロパティとして持ち、`canConfirm` で
  `.disabled(!cash.canConfirm)` を付ければ「確定ボタン無効」がそのまま表せる
