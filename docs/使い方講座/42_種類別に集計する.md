# 種類別に集計する

元: `../siyou.md` A-8

売上を**商品の種類ごと**にまとめる練習。
種類ごとに「販売した数量」と「金額」を出す。金額は明細の `paid_in`（受取方法）ごとに分ける。
**円（`jpy`）と sats（`sats`）は合算しない**（別々に数える）。集計対象は**登録商品だけ**（野良商品は別扱い）。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動く。

## 集計の入れ物

種類ごとに「数量・円・sats」を1つにまとめる。

```swift
struct TypeTotal {
    var qty = 0          // 販売数量の合計
    var amountJpy = 0    // paid_in == "jpy" の円合計
    var amountSats = 0   // paid_in == "sats" のsats合計
}
```

**ポイント**: 円とsatsを**別の欄**に持つ。同じ欄に足すと合算になってしまうので分ける。

---

## 種類別に集計する関数

```swift
/// 明細から、種類IDごとの集計を作る。
/// - `item_type == "adhoc"`（野良）は対象外
/// - `paid_in` ごとに円（jpy）とsats（sats）を分ける
func totalsByType(_ items: [SaleItem]) -> [String: TypeTotal] {
    var result: [String: TypeTotal] = [:]

    for item in items {
        // 登録商品以外は飛ばす（野良商品は種類別集計に含めない）
        guard item.itemType == "registered", let typeId = item.typeId else { continue }

        var total = result[typeId] ?? TypeTotal()
        total.qty += item.qty

        if item.paidIn == "sats" {
            // satsで受け取った行 → satsの額を足す
            total.amountSats += (item.unitPriceSats ?? 0) * item.qty
        } else {
            // 円で受け取った行 → 円の額を足す
            total.amountJpy += item.unitPriceJpy * item.qty
        }

        result[typeId] = total
    }
    return result
}
```

- `guard ... else { continue }` … 条件に合わない行は**次へ進む**（`1_初心者メモ.md` の `guard`）。
- `result[typeId] ?? TypeTotal()` … まだ無ければ新しく作る。
- `item.paidIn == "sats"` のときだけ sats 額を足す。**円とsatsを混ぜない**ための分岐。

## 表示して確認する

```swift
func typeName(_ typeId: String) -> String {
    productTypes.first { $0.typeId == typeId }?.name ?? typeId
}

let totals = totalsByType(saleItems)

// 種類IDの順にそろえて表示
for typeId in totals.keys.sorted() {
    let t = totals[typeId]!
    print("\(typeId) \(typeName(typeId)): 数量 \(t.qty) / 円 \(t.amountJpy) / sats \(t.amountSats)")
}

// 野良だけ別に数える（種類別には入れない）
let adhocCount = saleItems.filter { $0.itemType == "adhoc" }.reduce(0) { $0 + $1.qty }
print("（野良商品 \(adhocCount) 個は種類別集計に含めない）")
```

**できた合図**:
```
keyholder キーホルダー: 数量 2 / 円 800 / sats 1200
sticker ステッカー: 数量 3 / 円 900 / sats 0
（野良商品 1 個は種類別集計に含めない）
```

- `sticker` は ST-001 を2個（円600）＋ ST-003 を1個（円300）＝ **数量3・円900・sats0**。
- `keyholder` は KH-005 を1個（円800）＋ KH-002 を1個（sats1200）＝ **数量2・円800・sats1200**。
- 円とsatsが**別々**に出ていることを確認する（1200 を円に足していない）。

## 覚えておくこと

- 集計対象は**登録商品のみ**。野良商品（`adhoc`）は金額を別に数える（`../siyou.md` A-8）。
- 金額は明細の `paid_in` ごと。`jpy` は円、`sats` は sats。**合算しない**。
- 在庫管理なし型も「販売数量」は集計するが、在庫一覧には出さない。
- 集計の元は**販売時点の単価**（`unit_price_jpy` / `unit_price_sats`）。今の商品マスタの価格ではない。
