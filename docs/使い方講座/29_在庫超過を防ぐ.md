# 29. 在庫超過を防ぐ

元: `../siyou.md` A-1（商品の種類・カート数量）、A-1（SOLD OUT）、C-6 #7

**ゴール**: 数量管理型（`counted`）の商品を、**在庫数を超えて**カートに入れられないようにする。
「追加」でも「＋で数量を増やす」ときでも同じ上限で止める。在庫0なら追加しない。

> 画面は出さず、`print` で結果を見る**純ロジック**の練習。**ブック（Book）**で作る。

## 前提データ（このまま貼れば動く）

```swift
import Foundation

// ── 在庫の扱い（種類ごと）────────────────
enum StockMode {
    case counted   // 数量管理型（ステッカー。在庫を数で持つ）
    case unique    // 一点物型（キーホルダー。在庫は1か0）
    case none      // 在庫管理なし型（今回は商品なし）

// ── 種類の定義（product_types 相当）──────
struct ProductType {
    let typeId: String       // 例: "sticker"
    let name: String         // 例: "ステッカー"
    let idPrefix: String     // 例: "ST"
    let idDigits: Int        // 例: 3
    let stockMode: StockMode
    let attrLabel1: String?  // 例: "色"
    let attrLabel2: String?  // 例: "模様"
    let attrLabel3: String?  // 例: nil
}

// ── 商品（products 相当）────────────────
struct Product {
    let id: String           // 例: "KH-008"
    let typeId: String       // 例: "keyholder"
    let name: String
    let priceJpy: Int
    let priceSats: Int?      // nil なら sats払いでも現金で受け取る

    let attr1: String?

// ── 種類定義（`../開発/6_データベース.md` より）
```

## 29-1. 上限チェックの材料をそろえる

カートに何個あるか、をいつでも引けるようにする。あとで `addToCart` から使う。

```swift
// 種類を引く
func productType(_ product: Product) -> ProductType? {
    productTypes.first { $0.typeId == product.typeId }
}

// カートに入っている数量（無ければ0）
func cartQty(_ id: String) -> Int {
    cart.first { $0.product.id == id }?.qty ?? 0
}

// カートへ書き込む（新規なら行を足し、既にあれば数量を書き換える）
func put(_ product: Product, qty: Int) {
    if let i = cart.firstIndex(where: { $0.product.id == product.id }) {
        cart[i].qty = qty
    } else {
        cart.append(CartLine(product: product, qty: qty))
    }
}
```

## 29-2. 追加する関数（在庫超過をはねる）

結果を `enum` で返すと、成功と失敗をはっきり分けられる。

```swift
// 追加の結果
enum AddResult {
    case added(qty: Int)          // 追加できた（追加後の数量）
    case rejected(reason: String) // 追加できなかった
}

/// 商品をカートに1つ追加する。在庫を超えるときは追加しない。
func addToCart(_ product: Product) -> AddResult {
    guard let pt = productType(product) else {
        return .rejected(reason: "種類が未定義")
    }
    let inCart = cartQty(product.id)

    switch pt.stockMode {
    case .counted:
        let stock = product.stock ?? 0
        if stock <= 0 {
            return .rejected(reason: "在庫0なので追加できません")   // 在庫0は追加不可
        }
        if inCart + 1 > stock {
            return .rejected(reason: "在庫超過: \(product.name) は残り\(stock)個")
        }
        put(product, qty: inCart + 1)
        return .added(qty: inCart + 1)

    case .unique:
        if inCart >= 1 {
            return .rejected(reason: "一点物: \(product.name) は追加済み")
        }
        put(product, qty: 1)
        return .added(qty: 1)

    case .none:
        put(product, qty: inCart + 1)   // 在庫管理なしは上限なし
        return .added(qty: inCart + 1)
    }
}
```

- `stock <= 0` … 在庫が無い（0個）ので追加しない
- `inCart + 1 > stock` … 今の数量に1足したら在庫を超える、の意味

## 29-3. ＋（数量増減）でも同じ上限で止める

「追加」だけでなく「＋で増やす」ときも、在庫を超えないようにする。

```swift
/// カート内の行を＋1する。在庫を超えるときは増やさない。
func increase(_ id: String) -> AddResult {
    guard let i = cart.firstIndex(where: { $0.product.id == id }) else {
        return .rejected(reason: "カートにない")
    }
    let product = cart[i].product
    guard let pt = productType(product) else {
        return .rejected(reason: "種類が未定義")
    }

    if pt.stockMode == .unique {
        return .rejected(reason: "一点物は数量1固定")   // 一点物は増やせない
    }
    if pt.stockMode == .counted {
        let stock = product.stock ?? 0
        if cart[i].qty + 1 > stock {
            return .rejected(reason: "在庫超過: 残り\(stock)個")
        }
    }
    cart[i].qty += 1
    return .added(qty: cart[i].qty)
}
```

## 29-4. 動かしてみる

```swift
// 結果を1行で出す補助
func show(_ name: String, _ result: AddResult) {
    switch result {
    case .added(let qty):       print("\(name): 追加OK（カートの数量 \(qty)）")
    case .rejected(let reason): print("\(name): エラー / \(reason)")
    }
}

// ① ST-001（在庫10）を10個入れる → 11個目で在庫超過
for _ in 1...10 { _ = addToCart(products[0]) }
print("10個入れた後の数量:", cartQty("ST-001"))     // 10
show("ST-001 の11個目", addToCart(products[0]))     // 在庫超過

// ② 在庫0の商品（棚卸しで0になった想定）
cart.removeAll()
var soldOutST = products[1]     // ST-002 をコピー
soldOutST.stock = 0
show("ST-002（在庫0）", addToCart(soldOutST))       // 在庫0なので追加不可

// ③ ＋で増やすときも上限で止まる
cart.removeAll()
var few = products[0]
few.stock = 2                   // 残り2個の想定
_ = addToCart(few)
_ = addToCart(few)
show("ST-001 の＋3個目", increase("ST-001"))        // 在庫超過（残り2）
```

**できた合図**:
- `ST-001 の11個目: エラー / 在庫超過: ステッカー まる は残り10個`
- `ST-002（在庫0）: エラー / 在庫0なので追加できません`
- `ST-001 の＋3個目: エラー / 在庫超過: 残り2個`

---

## ポイント
- 在庫の上限判定は**「追加」と「＋」の両方**で同じ `stock` を使う
- 在庫0は追加させない。**数量管理型（`counted`）だけ**が在庫超過のチェック対象
- 一点物型（`unique`）は数量1固定。在庫管理なし型（`none`）は上限なし
- チェックは「在庫を超えないか」だけ。実際の在庫の減算は**会計の完了時**に行う（別の話）
