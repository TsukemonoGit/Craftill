# 追加レッスン: 画面遷移とモーダルを使う（NavigationStack / sheet / 状態で出し分け）

元: `../開発/5_画面構成.md`（レジ画面1枚）、`../siyou.md` A-4
`02_練習メニュー.md` の「61. 画面遷移とモーダルを使う」。

**会計の状態がどう決まるか**は `56_会計の状態を切り替える.md` で扱いました。
このレッスンは **その先**、つまり「画面をどう出し分けるか」です。

覚えるのは3つ:

- **状態で出し分ける**: `switch` で、同じ画面の中身だけを入れ替える（会計の進行）
- **`NavigationStack` ＋ `navigationDestination`**: 商品詳細などへ**積んで**進む（戻るボタン付き）
- **`.sheet`**: QRリーダーや確認などを**一時的に重ねて**出す

> **Svelteとの対比**: `{#if}` / `{#each}` で表示を分けるのと近いのが `switch`。
> `NavigationStack` / `.sheet` はルーターの「ページ遷移」「モーダル」にあたります。

画面（UI）を出すので、**アプリ（App）**として新しく作ります。

## 前提データ

型の定義は `base/Types.swift` から paste します。ここでは画面に必要な分だけ書きます。

import SwiftUI

// 会計の状態は base/Types.swift の SaleState（8状態）を使います

// ── 商品のサンプル ──

## 1. 状態で出し分ける（`switch`）

親（レジ画面）が `@State` で状態を持ち、`switch` で子Viewを選びます。
子には `@Binding` で状態を渡し、子側で進めます。

```swiftui
struct RegisterRootView: View {
    @State private var state: SaleState = .idle
    @State private var cart: [CartLine] = initialCart
    @State private var showScanner = false

    var body: some View {
        NavigationStack {
            VStack(spacing: 12) {
                // いまの状態を小さく表示（切り替わっているのが分かる）
                Text("いま: \(state.rawValue)")
                    .font(.caption).foregroundStyle(.secondary)

                // 会計の状態で、出す画面を1枚に出し分ける（A-4）
                switch state {
                case .idle, .scanning:
                    ScanView(state: $state, cart: cart)      // 待機中／スキャン中
                case .choosingPayment:
                    PaymentSelectView(state: $state)
                case .cashInput:
                    CashInputView(state: $state)
                case .satsWaiting:
                    SatsWaitingView(state: $state)
                case .mixedCashInput:
                    CashInputView(state: $state)             // 併用現金入力中も同じ画面
                case .suspended:
                    SuspendedView(state: $state)
                case .done:
                    DoneView(state: $state)
                }
            }
            .padding()
            .toolbar {
                Button("QR読取") { showScanner = true }      // sheet を開く
            }
            .navigationDestination(for: String.self) { id in // push で進んだときの行き先
                ProductDetailView(productId: id)
            }
        }
        .sheet(isPresented: $showScanner) {
            ScannerSheet()                                   // 一時的に重ねる画面
        }
    }
}
```

> `case .cashInput` と `case .mixedCashInput` が同じ `CashInputView` を使うのは、
> **入力画面は同じ・違うのは請求額だけ**だからです（A-6-1）。
> どちらの状態かで渡す金額を変えます。

> **重要**: ここでは `state = .xxx` と直接書いています。これは教材用の簡略版です。
> 実運用では `56_会計の状態を切り替える.md` の `move(...)` を通してください。

## 2. 各状態の画面（子View）

どの子も `@Binding var state` を持ち、ボタンで**次の状態へ進めます**。

```swiftui
struct ScanView: View {
    @Binding var state: SaleState
    let cart: [CartLine]

    var body: some View {
        VStack(spacing: 12) {
            Text(cart.isEmpty ? "レジ待機中" : "商品をスキャン中").font(.title2)
            Text("カート \(cart.count)件")

            HStack {
                Button("会計へ進む") { state = .choosingPayment }   // スキャン中 → 支払方法選択
                    .disabled(cart.isEmpty)
                Button("中断") { state = .idle }                     // → 待機中
                    .disabled(cart.isEmpty)
            }

            // 商品をタップ → 詳細へ push（NavigationStack の遷移）
            NavigationLink("商品 KH-001 の詳細", value: "KH-001")
                .font(.caption)
        }
    }
}

struct PaymentSelectView: View {
    @Binding var state: SaleState
    var body: some View {
        VStack(spacing: 12) {
            Text("お支払い方法").font(.title2)
            Button("現金") { state = .cashInput }        // → 現金入力中
            Button("sats払い") { state = .satsWaiting }   // → sats待ち
            Button("戻る") { state = .scanning }          // → スキャン中
        }
    }
}

struct CashInputView: View {
    @Binding var state: SaleState
    var body: some View {
        VStack(spacing: 12) {
            Text("現金入力中").font(.title2)
            Button("受取額を確定（完了）") { state = .done }   // → 完了
            Button("中断") { state = .idle }                  // → 待機中
        }
    }
}

struct SatsWaitingView: View {
    @Binding var state: SaleState
    var body: some View {
        VStack(spacing: 12) {
            Text("satsの入金待ち").font(.title2)
            Text("WoS で入金を確認したら「済」").font(.caption)
            Button("済（完了）") { state = .done }              // → 完了
            Button("方法をえらびなおす") { state = .choosingPayment }
        }
    }
}

struct SuspendedView: View {
    @Binding var state: SaleState
    var body: some View {
        VStack(spacing: 12) {
            Text("中断しました").font(.title2)
            Button("待機中へ") { state = .idle }   // → 待機中
        }
    }
}

struct DoneView: View {
    @Binding var state: SaleState
    var body: some View {
        VStack(spacing: 12) {
            Text("✓ 完了").font(.largeTitle)
            Button("待機中へ") { state = .idle }   // → 待機中
        }
    }
}
```

## 3. push で進む画面（`navigationDestination`）

`NavigationLink(value:)` で進み、`navigationDestination(for:)` で行き先を決めます。
**値の型（ここでは `String`）を合わせます**。

```swiftui
struct ProductDetailView: View {
    let productId: String

    var body: some View {
        let p = products.first { $0.id == productId }
        VStack(spacing: 8) {
            Text(productId).font(.headline)
            Text(p?.name ?? "-")
            if let sats = p?.priceSats {
                Text("\(sats) sats")
            } else {
                Text("―（現金）")     // sats単価なし（`25_オプショナルを「―（現金）」にする.md` の表示ルール）
            }
        }
    }
}
```

## 4. 重ねて出す画面（`.sheet`）

QRリーダーのように**一時的に出す**画面は `.sheet` です。
閉じるときは `@Environment(\.dismiss)` を使います。

```swiftui
struct ScannerSheet: View {
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        VStack(spacing: 12) {
            Text("QRリーダー").font(.headline)
            Text("ここにカメラの映像").font(.caption).foregroundStyle(.secondary)
            Button("閉じる") { dismiss() }
        }
        .padding()
        .frame(width: 420, height: 300)
    }
}
```

## どの仕組みを使う？

| したいこと | 使うもの |
| --- | --- |
| 会計の進行（待機中→…→完了）を出し分ける | `switch`（同じ画面の入替） |
| 商品詳細などへ進む・戻る | `NavigationStack` ＋ `navigationDestination` |
| QRリーダー・確認などを一時的に重ねる | `.sheet` |

- 会計の進行は **1枚の画面**で表します。「戻る」と **状態そのものが変わる** ので、
  push の戻るより `switch` が合います（A-4）。
- 補助的な画面（詳細・リーダー）は、状態を壊さずに重ねたいので push や sheet を使います。

---

## できた合図

- 起動時は **待機中** と出る。カートに初期値が入っているので「商品をスキャン中」
- 「会計へ進む」→ **支払方法選択** に切り替わる
- 「現金」→ **現金入力中**、「sats払い」→ **sats待ち** に切り替わる
- 「済（完了）」や「受取額を確定（完了）」→ **完了** に切り替わる
- 「待機中へ」→ **待機中** に戻る
- 「商品 KH-001 の詳細」を押すと詳細画面へ **進み**、戻れる
- 「QR読取」を押すと QRリーダーが **下から重なり**、「閉じる」で消える

---

## ポイント

- 会計の進行は `switch state` で **1枚の画面** を出し分ける
- 状態を `rawValue` で表示すると、遷移の順番が見やすくなります
- `.cashInput` と `.mixedCashInput` は同じ入力画面を使ってよい（請求額だけ違う）
- 補助画面は `NavigationStack`（push）と `.sheet`（重ねる）を使う
- `navigationDestination(for:)` の型と `NavigationLink(value:)` の型を **必ず合わせる**
- `.sheet` を閉じるときは `@Environment(\.dismiss)` を使う
- **遷移の判断そのものは `56_会計の状態を切り替える.md`**。このレッスンは表示だけ
- 実際の配置・横幅は実機で確認して決める（`../開発/5_画面構成.md`）
