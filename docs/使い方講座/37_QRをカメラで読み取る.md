# 37. QRをカメラで読み取る【大問】

元: `../siyou.md` A-2

カメラでQRを読み取り、**商品IDの文字列**（例 `KH-008`）を取り出す。読み取りはApple公式の **AVFoundation**（カメラ映像）と **Vision**（`VNDetectBarcodesRequest`、QRの解析）で行う。
カメラは**「アプリ（App）」でしか動かない**（ブック不可）。**MacのXcodeアプリで実行**する。許可の設定が要る（`05_Xcodeでプロジェクト作成.md` のカメラの注意）。

大問なので小問に分ける。

- 小問1: カメラの許可を設定する（entitlement / Info.plist）
- 小問2: 読み取った文字列を商品IDとして整える（ブック）
- 大問: カメラ映像からQRを読み取るクラスを作る（アプリ）

---

## 前提データ
```swift
// 登録商品（6_データベース.md のサンプル。一部抜粋）
struct Product {
    let id: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?
    var stock: Int?
}

let products: [Product] = [
    Product(id: "ST-001", name: "ステッカー まる",   priceJpy: 300, priceSats: 500,  stock: 10),
    Product(id: "ST-003", name: "ステッカー しかく",  priceJpy: 300, priceSats: nil,  stock: 10),
    Product(id: "KH-001", name: "キーホルダー 01",   priceJpy: 800, priceSats: 1200, stock: 1),
    Product(id: "KH-008", name: "キーホルダー 08",   priceJpy: 800, priceSats: 1200, stock: 1),
    Product(id: "KH-020", name: "キーホルダー 20",   priceJpy: 800, priceSats: 1200, stock: 1),
]

/// 在庫のある商品をIDで探す。
func findProduct(_ id: String, in products: [Product]) -> Product? {
    products.first { $0.id == id }
}
```

## 小問1: カメラの許可を設定する
**MacとiPadで違うのはここだけ。** 設定しないとカメラ起動時にクラッシュする（`05_Xcodeでプロジェクト作成.md`）。

**macOS**
- App SandboxがONなら、Signing & Capabilities → **App Sandbox → Camera** にチェック
  - entitlement `com.apple.security.device.camera`
- Info に `NSCameraUsageDescription`（日本語の説明文）を追加
- 個人利用で配布しないなら、App Sandbox自体をOFFにする手もある（その場合はInfoだけで動く）

**iOS / iPadOS**
- Info に `NSCameraUsageDescription` を追加

```xml
<!-- Reji.entitlements（macOS。App Sandboxを使う場合） -->
<key>com.apple.security.device.camera</key>
<true/>
```

```xml
<!-- Info.plist。macOS も iOS も同じキー -->
<key>NSCameraUsageDescription</key>
<string>商品のQRコードを読み取るためにカメラを使います。</string>
```

## 小問2: 読み取った文字列を商品IDとして整える（ブック）
QRの中身は商品IDそのもの（例 `KH-008`。A-2）。読み取り値には前後の空白などが入るので整えて、登録商品にあるか確認する。

```swift
/// 読み取った文字列から商品IDを取り出す。
/// 前後の空白を除いて大文字にそろえ、登録商品にあるものだけ返す。無ければ nil。
func productID(fromScanned raw: String, in products: [Product]) -> String? {
    let id = raw.trimmingCharacters(in: .whitespacesAndNewlines).uppercased()
    return findProduct(id, in: products)?.id
}

print(productID(fromScanned: " kh-008\n", in: products) ?? "なし")   // KH-008
print(productID(fromScanned: "XX-999",   in: products) ?? "なし")   // なし
```
- `trimmingCharacters` … 前後の空白・改行を除く
- 登録にないIDは `nil` にして、カートへ入れない（A-2）

**できた合図**: `KH-008` と `なし` が出る。

## 大問: カメラ映像からQRを読み取る（アプリ）
`AVCaptureSession` でカメラ映像を取り出し、1フレームごとに `VNDetectBarcodesRequest` でQRを探す。見つかったら `onScan` に文字列を渡す。

```swift
import AVFoundation
import Vision

/// カメラ映像からQRを読み取り、文字列を渡すクラス。
final class QRScanner: NSObject, AVCaptureVideoDataOutputSampleBufferDelegate {
    private let session = AVCaptureSession()
    private let queue = DispatchQueue(label: "qr.scanner")
    private var isConfigured = false

    /// QRを1つ読み取ったときにメインで呼ばれる。
    var onScan: (@MainActor (String) -> Void)?

    /// カメラを準備して読み取りを始める。
    /// - Returns: 準備に成功したら true。許可がない・カメラがないときは false。
    func start() -> Bool {
        if !isConfigured {
            guard configure() else { return false }
            isConfigured = true
        }
        if !session.isRunning {
            queue.async { self.session.startRunning() }
        }
        return true
    }

    /// 読み取りを止める。
    func stop() {
        queue.async {
            if self.session.isRunning { self.session.stopRunning() }
        }
    }

    /// セッション（カメラの入出力）を組み立てる。
    private func configure() -> Bool {
        guard let device = AVCaptureDevice.default(for: .video),
              let input = try? AVCaptureDeviceInput(device: device) else {
            return false   // カメラがない、または許可がない
        }

        session.beginConfiguration()
        if session.canAddInput(input) { session.addInput(input) }

        let output = AVCaptureVideoDataOutput()
        output.alwaysDiscardsLateVideoFrames = true
        output.setSampleBufferDelegate(self, queue: queue)
        if session.canAddOutput(output) { session.addOutput(output) }

        session.commitConfiguration()
        return true
    }

    // 1フレームごとに呼ばれる（バックグラウンドの queue）
    func captureOutput(_ output: AVCaptureOutput,
                       didOutput sampleBuffer: CMSampleBuffer,
                       from connection: AVCaptureConnection) {
        guard let pixelBuffer = CMSampleBufferGetImageBuffer(sampleBuffer) else { return }

        // Vision で QR（barcode）を探す
        let request = VNDetectBarcodesRequest()
        request.symbologies = [.qr]   // QRだけに絞る
        let handler = VNImageRequestHandler(cvPixelBuffer: pixelBuffer, options: [:])
        try? handler.perform([request])

        guard let results = request.results else { return }
        for barcode in results {
            guard let text = barcode.payloadStringValue else { continue }
            Task { @MainActor in
                self.onScan?(text)    // 例 "KH-008"
            }
            return   // 1フレームにつき1つで十分。重複追加は冷却時間で防ぐ
        }
    }
}
```
- `AVCaptureVideoDataOutput` で映像を1フレームずつ受け取る
- `VNDetectBarcodesRequest` の `symbologies = [.qr]` でQRだけを対象にする
- 見つかった文字列は `barcode.payloadStringValue`（中身は商品ID）
- `captureOutput` は別スレッドで呼ばれるので、画面を触る前に `Task { @MainActor }` でメインへ戻す

### 画面につなぐ
```swift
import AVFoundation
import SwiftUI

@MainActor
final class ScannerModel: ObservableObject {
    @Published var message: String?
    private let scanner = QRScanner()

    func start() {
        let ok = scanner.start()
        if !ok {
            message = "カメラを起動できません。許可の設定を確認してください。"
            return
        }
        scanner.onScan = { [weak self] text in
            guard let self else { return }
            if let id = productID(fromScanned: text, in: products) {
                self.message = "読み取り: \(id)"
            } else {
                self.message = "登録にないQRです: \(text)"
            }
        }
    }

    func stop() { scanner.stop() }
}

struct QRScanView: View {
    @StateObject private var model = ScannerModel()

    var body: some View {
        VStack(spacing: 12) {
            Text(model.message ?? "商品のQRをカメラへ向けてください")
            Button("カメラを開始") { model.start() }
            Button("停止") { model.stop() }
        }
        .padding()
    }
}
```
- カメラ映像のプレビューは `AVCaptureVideoPreviewLayer`。SwiftUIに出すには `UIViewRepresentable`（Macは `NSViewRepresentable`）で包む（ここでは割愛）
- 読み取り値は `productID(fromScanned:in:)` で登録商品か確認してからカートへ渡す

## ポイント
- 読み取りは**Apple公式**（AVFoundation / Vision）。追加インストール不要
- **読み取り処理・カメラは端末内で完結**し、通信は不要（A-10 #1）
- Neoは**画面側のカメラのみ**。商品のQRをカメラへ向ける
- 読み取れない場合は、商品パネル・ID手動入力で代替する（A-2）
- つまずき: 起動即クラッシュ → ほぼ許可の設定漏れ（entitlement か Info.plist）

**できた合図**: 「カメラを開始」でプレビューが出て、QRを映すと `読み取り: KH-008` のように表示される。初回は許可のダイアログが出る。
