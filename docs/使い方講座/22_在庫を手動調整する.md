# 追加レッスン: 在庫を手動調整する

元: `../siyou.md` A-7、A-11、A-19-1、受け入れテスト C-6 #54
`02_練習メニュー.md` の「22. 在庫を手動調整する」。

棚卸しのときに、数えた**正しい在庫数**へ手で直す練習です（A-7）。**PIN必須**の管理操作です（A-11）。

- **現在庫を上書き**し、**差分（新しい数 − 現在庫）** を `stock_movements` に **`adjust`** で記録する（A-7、A-19-1）
- **在庫管理なし型**・**野良商品**は在庫の対象外なので、調整しない
- 一点物型は 0 か 1 しか入れない
- 理由（棚卸し・破損・紛失など）を **`stock_movements` に持てない**のは要注意。仕様にも列がありません

> このレッスンは**純ロジック**なので、ブック（Book）にそのまま貼って動きます。
> 画面（SwiftUI）はアプリ（App）で作ります（`01_初心者メモ.md`）。

## わざと間違う①: 現在庫に足し算する

調整は「**新しい数**」を入れます。でも「**何個増えたか**」を計算するつもりで
現在庫に**足して**しまう実装はよくあります。
```swift NG
// わざと間違う版①：差分を足してしまう
func adjustStockV1(productId: String, newStock: Int,
                   inventory: inout [Product], movements: inout [StockMovement]) -> String {
    guard let i = inventory.firstIndex(where: { $0.id == productId }) else {
        return "商品が見つかりません"
    }
    // ★ 「新しい数」と「差分」を取り違えている
    inventory[i].stock = (inventory[i].stock ?? 0) + newStock
    movements.append(StockMovement(id: "M-\(movements.count)",
                                   productId: productId, delta: newStock,
                                   reason: .adjust, saleId: nil, at: Date()))
    return "調整しました"
}
```

**何が壊れるか**

| 現在の在庫 | 入力した「新しい数」 | わざと間違う版 | 正しい版 |
| --- | --- | --- | --- |
| 10 | 12 | **22** | 12 |
| 10 | 8 | **18** | 8 |

**在庫管理としては壊滅**です。C-6 #54 は
「CSV再取り込みで**既存商品の在庫は変更しない**」と書いていますが、
手動調整は「**数えた値を上書きする**」のが正しい操作です（A-7）。

**直し方**: 上書きと差分の計算を**別々に**書き、**差分はログに残すだけ**にします。

```swift 断片
// base/3 §6 の該当部分
let diff = newStock - current          // ★ 差分 = 新しい数 − 現在庫
inventory[i].stock = newStock         // ★ 現在庫は「上書き」

guard diff != 0 else { return .success("変化なし") }   // 変わらなければログも増やさない

movements.append(StockMovement(
    id: ids.nextMovementID(), productId: productId,
    delta: diff, reason: .adjust, saleId: nil, at: at))   // ← ログに残すのは「差分」
```

> **「現在庫」と「ログ」は別の値**です。現在庫は `newStock`、ログの `delta` は `diff`。
> ここを混ぜると **A-19-1 の不変条件**（`products.stock == Σ stock_movements.delta`）が崩れます。
> `base/3` §9 の通し確認で **`全部一致: true`** になることを確認できます。

## わざと間違う②: PIN を先に確認せず、在庫を触ってから弾く

```swift NG
// わざと間違う版②：PIN の前に在庫触る
func adjustStockV2(productId: String, newStock: Int, pin: String,
                   inventory: inout [Product]) -> String {
    guard let i = inventory.firstIndex(where: { $0.id == productId }) else { return "見つかりません" }
    inventory[i].stock = newStock          // ★ PIN を見る前に書き換えている
    guard pin == "1234" else { return "PINが違います" }
    return "調整しました"
}
```

**何が壊れるか**

**PINが間違っているのに、在庫が変わった状態で終わります**（A-11）。
割り込みが入ると、**在庫だけ書き換わった記録のない状態**が残ります。

**直し方**: `base/3` の `adjustStock` は **PIN が 1 番目** にあります。

```swift 断片
guard pin == correctPIN else { return .failure("PINが違います") }   // ★ 最初
guard let i = inventory.firstIndex(where: { $0.id == productId }) else { ... }
```

> ガード節を**上から順**に読んで、「何が起きる前に何を確認するか」を書いてください。
> `18_販売を取り消す.md`（`voidSale`）も同じ順番です（A-9 も PIN が先）。

## 2. 通しの確認

下のコードを、**土台（`base/Types.swift` の型 ＋ `base/3_標準ロジック.md` の §1・§3・§6）の
下に続けて置いて**、`swift` で動かします。

```swift
// ════════ 通しの確認（在庫の手動調整・A-7 / A-11 / A-19-1）════════

let types: [ProductType] = [
    ProductType(typeId: "sticker", name: "ステッカー", idPrefix: "ST", idDigits: 3,
                stockMode: .counted, attrLabel1: "色", attrLabel2: nil, attrLabel3: nil),
    ProductType(typeId: "keyholder", name: "キーホルダー", idPrefix: "KH", idDigits: 3,
                stockMode: .unique, attrLabel1: "色", attrLabel2: nil, attrLabel3: nil),
    ProductType(typeId: "ticket", name: "入場券", idPrefix: "TB", idDigits: 3,
                stockMode: .none, attrLabel1: nil, attrLabel2: nil, attrLabel3: nil),
]
let now = Date(timeIntervalSince1970: 1_700_000_000)
/// 商品マスタCSVの中身
let productMaster: [Product] = [
    Product(id: "ST-001", typeId: "sticker", name: "ステッカー まる",
            priceJpy: 300, priceSats: 500, stock: 10),
    Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01",
            priceJpy: 800, priceSats: 1200, stock: 1),
    Product(id: "TB-001", typeId: "ticket", name: "入場券",
            priceJpy: 1000, priceSats: nil, stock: nil),
]
var inventory: [Product] = []      // ← 最初は空。営業前の取り込みで入っていく
var movements: [StockMovement] = []
var ids = IdSequencer()

func p4(_ s: String) { print("  " + s) }
func stocks4() -> String {
    inventory.map { "\($0.id)=\($0.stock.map(String.init) ?? "なし")" }.joined(separator: " ")
}
func showAdjust(_ r: AdjustResult) -> String {
    switch r {
    case .success(let m): return "success(\(m))"
    case .failure(let e): return "failure(\(e))"
    }
}
func logSum4(_ id: String) -> Int {
    movements.filter { $0.productId == id }.reduce(0) { $0 + $1.delta }
}

/// 初期在庫を initial で記録する（A-1、A-19-1）。これをしないと自己点検が合いません
print("【0】営業前の取り込み（initial を記録）")
registerInitialStock(productMaster, inventory: &inventory,
                     movements: &movements, ids: &ids, types: types, at: now)
p4("在庫 → " + stocks4())

print("【1】上の書き（新しい数を入れる）")
p4("ST-001 を 12 に: " + showAdjust(adjustStock(productId: "ST-001", newStock: 12, reason: "棚卸し",
        correctPIN: "1234", pin: "1234", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))
p4("在庫 → " + stocks4() + "　（10 → 12。足した 22 ではない）")
p4("ログの delta = " + String(logSum4("ST-001")))

print("【2】下の書き（減らす）")
p4("ST-001 を 8 に: " + showAdjust(adjustStock(productId: "ST-001", newStock: 8, reason: "棚卸し",
        correctPIN: "1234", pin: "1234", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))
p4("在庫 → " + stocks4())

print("【3】変化なしならログを増やさない")
let before = movements.count
p4("ST-001 を 8 に: " + showAdjust(adjustStock(productId: "ST-001", newStock: 8, reason: "棚卸し",
        correctPIN: "1234", pin: "1234", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))
p4("movements が増えない: " + String(before == movements.count))

print("【4】PIN が違うと何も変わらない（A-11）")
let beforeStock = stocks4()
p4("PIN 0000: " + showAdjust(adjustStock(productId: "ST-001", newStock: 99, reason: "棚卸し",
        correctPIN: "1234", pin: "0000", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))
p4("在庫が変わらない: " + String(beforeStock == stocks4()))

print("【5】一点物型は 0 か 1（A-1、A-7）")
p4("KH-001 を 2 に: " + showAdjust(adjustStock(productId: "KH-001", newStock: 2, reason: "棚卸し",
        correctPIN: "1234", pin: "1234", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))

print("【6】在庫管理なし型は調整できない（A-7）")
p4("TB-001 を 5 に: " + showAdjust(adjustStock(productId: "TB-001", newStock: 5, reason: "棚卸し",
        correctPIN: "1234", pin: "1234", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))

print("【7】0 未満は弾かれる")
p4("ST-001 を -1 に: " + showAdjust(adjustStock(productId: "ST-001", newStock: -1, reason: "棚卸し",
        correctPIN: "1234", pin: "1234", inventory: &inventory, movements: &movements,
        ids: &ids, types: types, at: now)))

print("【8】在庫の自己点検（A-19-1：正とログの合計が一致する）")
var allMatch = true
for p in inventory {
    let stock = p.stock ?? 0
    let logged = logSum4(p.id)
    if stock != logged { allMatch = false }
    p4("\(p.id): 正=\(stock) ログ合計=\(logged) " + (stock == logged ? "OK" : "不一致"))
}
p4("全部一致: " + String(allMatch))

print("【9】ログの並び")
p4(movements.map { m in "\(m.id)=\(m.productId) \(m.delta > 0 ? "+" : "")\(m.delta) \(m.reason.rawValue)" }
        .joined(separator: " / "))
```

## ポイント

- 調整は **`newStock` で上書き**する。差分を足さない（A-7）
- **ログに残すのは差分 `diff`** だけ（`delta = newStock - current`）
- **`diff == 0` ならログを増やさない**。「変化なし」を記録するとログが汚れる
- **PIN は最初**に確認する。在庫に触ってからだと、記録の無い変更が残る（A-11）
- 在庫管理なし型・**野良は調整できない**（`guard mode != .none`）
- 一点物型は **0 か 1 以外を弾く**（A-1、A-7）
- 変動IDは **`IdSequencer.nextMovementID()`**。`M-%03d` を自分で作らない（A-19-4）
- 調整の**理由（棚卸しなど）は仕様に列が無い**。実装前に `siyou.md` へ追記する（A-19-9 #1 と同じ方式）
- 調整しても `products.stock` が正のままなので、**A-19-1 の不変条件は保たれる**。
