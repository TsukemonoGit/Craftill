# 在庫を手動調整する【小】

元: `../siyou.md` A-7, A-11

棚卸しのときに、数えた**正しい在庫数**へ手で直す練習です（A-7）。**PIN必須**の管理操作です（A-11）。

- **現在庫を上書き**し、**差分（新しい数 − 現在庫）**を計算する。
- 差分を `stock_movements` に **`adjust`** で記録する（A-7）。
- **在庫管理なし型**・**野良商品**は在庫の対象外なので、調整しない。
- 理由を入力できる（棚卸し・破損・紛失など）。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動きます。
> 画面（SwiftUI）は **アプリ（App）** で作ります（`01_初心者メモ.md`）。

## 前提データ

```swift
import Foundation   // String(format:) に必要

// ── 在庫の扱い（種類ごと）──
enum StockMode {
    case counted   // 数量管理型（ステッカー）: 0以上の整数
    case unique    // 一点物型（キーホルダー）: 0か1
    case none      // 在庫管理なし型: 在庫を持たない（今回は未使用）
}

// ── 商品（products 相当）──
struct Product {
    let id: String
    let typeId: String
    let name: String
    var stock: Int?         // 在庫（none は nil）
    let stockMode: StockMode
}

// ── 在庫変動ログ（stock_movements 相当）──
struct StockMovement {
    let id: String
    let productId: String
    let delta: Int          // 増減数（+/-）
    let reason: String      // initial / sale / void / adjust
    let saleId: String?     // 手動調整では nil
    let at: String          // 日時（ISO 8601）
}

// ── 商品のサンプル（../開発/6_データベース.md）──
let productSeed: [Product] = [
    Product(id: "ST-001", typeId: "sticker",   name: "ステッカー まる",   stock: 10, stockMode: .counted),
    Product(id: "ST-002", typeId: "sticker",   name: "ステッカー さんかく", stock: 10, stockMode: .counted),
    Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく", stock: 10, stockMode: .counted),
    Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01",   stock: 1,  stockMode: .unique),
    Product(id: "KH-005", typeId: "keyholder", name: "キーホルダー 05",   stock: 1,  stockMode: .unique),
]

// ── 変動ログのIDを作る ──
var movementSerial = 0
func nextMovementID() -> String {
    movementSerial += 1
    return String(format: "M-%03d", movementSerial)
}
```

## 大問: 在庫を手動調整する

```swift
enum AdjustResult {
    case success(String)   // 成功（変化のメモ）
    case failure(String)   // 失敗（理由）
}

func resultText(_ r: AdjustResult) -> String {
    switch r {
    case .success(let memo):  return "OK: \(memo)"
    case .failure(let reason): return "失敗: \(reason)"
    }
}

/// 在庫を手で直す。PIN必須（A-11）。
/// - 現在庫を newStock で上書きし、差分を stock_movements に adjust で記録する。
/// - 在庫管理なし型・野良は対象外。
func adjustStock(productId: String,
                 newStock: Int,
                 reason: String,
                 pin: String, correctPIN: String,
                 products: inout [Product],
                 movements: inout [StockMovement],
                 at: String) -> AdjustResult {

    // ── PIN認証（A-11）──
    guard pin == correctPIN else { return .failure("PINが違います") }

    guard let i = products.firstIndex(where: { $0.id == productId }) else {
        return .failure("商品が見つかりません: \(productId)")
    }
    // 在庫管理なし型は対象外（A-7）
    guard products[i].stockMode != .none else {
        return .failure("在庫管理なし型は調整できません")
    }
    // 種類ごとの範囲チェック
    guard newStock >= 0 else { return .failure("在庫は0以上で入力してください") }
    if products[i].stockMode == .unique && newStock > 1 {
        return .failure("一点物型の在庫は0か1です")
    }

    // ── 上書きと差分の計算 ──
    let current = products[i].stock ?? 0
    let delta = newStock - current       // 差分（＋/−）
    products[i].stock = newStock         // 現在庫を上書き

    // ── 差分を adjust で記録（変わったときだけ）──
    if delta != 0 {
        movements.append(StockMovement(id: nextMovementID(),
                                       productId: productId,
                                       delta: delta,
                                       reason: "adjust",
                                       saleId: nil,
                                       at: at))
    }

    let reasonText = reason.isEmpty ? "" : "／理由: \(reason)"
    return .success("\(products[i].name): 在庫 \(current) → \(newStock)（差 \(String(format: "%+d", delta))）\(reasonText)")
}
```

- `String(format: "%+d", delta)` … 符号付きで `+5` / `-3` と出す。
- `delta != 0` … **変わっていなければ記録しない**（同じ数の調整でログを増やさない）。
- `inout` … 渡した在庫表・ログそのものを書き換える。呼ぶときは `&` を付ける（`07_追加レッスン.md`）。

## 試す

```swift
var products = productSeed
var movements: [StockMovement] = []
let pin = "1234"

// ① 棚卸し: ST-001 の実数が12だった → 10 から 12 へ（+2）
print(resultText(adjustStock(productId: "ST-001", newStock: 12, reason: "棚卸し",
                             pin: pin, correctPIN: pin,
                             products: &products, movements: &movements,
                             at: "2026-10-13T12:00:00+09:00")))

// ② 破損: ST-003 が3枚こわれていた → 10 から 7 へ（-3）
print(resultText(adjustStock(productId: "ST-003", newStock: 7, reason: "破損",
                             pin: pin, correctPIN: pin,
                             products: &products, movements: &movements,
                             at: "2026-10-13T12:05:00+09:00")))

// ③ PIN違い → 何も変わらない
print(resultText(adjustStock(productId: "ST-002", newStock: 5, reason: "棚卸し",
                             pin: "0000", correctPIN: pin,
                             products: &products, movements: &movements,
                             at: "2026-10-13T12:06:00+09:00")))

// ④ 一点物に2を入れようとする → エラー
print(resultText(adjustStock(productId: "KH-001", newStock: 2, reason: "棚卸し",
                             pin: pin, correctPIN: pin,
                             products: &products, movements: &movements,
                             at: "2026-10-13T12:07:00+09:00")))
```

**できた合図**:
```
OK: ステッカー まる: 在庫 10 → 12（差 +2）／理由: 棚卸し
OK: ステッカー しかく: 在庫 10 → 7（差 -3）／理由: 破損
失敗: PINが違います
失敗: 一点物型の在庫は0か1です
```

在庫とログを確認します。

```swift
for p in products {
    print("\(p.id)  \(p.name)  在庫 \(p.stock.map { String($0) } ?? "—")")
}
print("── 変動ログ（adjust）──")
for m in movements {
    print("\(m.id)  \(m.productId)  \(String(format: "%+d", m.delta))  \(m.reason)  \(m.saleId ?? "—")  \(m.at)")
}
```

**できた合図**:
```
ST-001  ステッカー まる  在庫 12
ST-002  ステッカー さんかく 在庫 10
ST-003  ステッカー しかく  在庫 7
KH-001  キーホルダー 01  在庫 1
KH-005  キーホルダー 05  在庫 1
── 変動ログ（adjust）──
M-001  ST-001  +2  adjust  —  2026-10-13T12:00:00+09:00
M-002  ST-003  -3  adjust  —  2026-10-13T12:05:00+09:00
```

- ③・④は失敗したので、`ST-002` は 10 のまま、`KH-001` は 1 のまま。
- ログは**成功した2件**だけ。差分の符号（`+2` / `-3`）がそのまま入っている。

## ポイント

- 手動調整は**管理操作**。PIN認証を最初に通す（A-11）。
- **現在庫を上書き**し、**差分（新 − 現在）**を計算する。
- 差分を `stock_movements` に **`adjust`**（`sale_id` は空）で記録する（A-7）。
- 種類ごとの範囲を守る。`counted` は0以上、`unique` は0か1。
- **在庫管理なし型**・**野良商品**は在庫の対象外なので調整しない（A-7）。
- 差分が0のときは記録しない。現在庫は「記録の合計」でいつでも計算し直せる（A-7）。
