# 初心者メモ（Swift超入門）

SwiftもPlaygroundsも初めての方向け。分からない言葉が出たらここに戻る。
対象は `2_練習メニュー.md` の「2. 商品モデルを作る」で出てくるコード。

---

## Playgrounds って？
iPadの**Swift練習帳アプリ**。コードを書いて、すぐ実行して、結果を見られる。ファイルを作らなくていい。

1. App Storeで **「Swift Playgrounds」** を入れる
2. アプリを開く → **「マイPlayground」→「Playgroundを作成」→ 空白(Blank)**
3. 画面に出てくる `import SwiftUI` などは**消してOK**（残っていてもよい）
4. コードを書いて、**実行ボタン(▶)** を押す
5. `print("...")` と書くと、書いた文字が下/右の**コンソール**に出る

最初は「テンプレを消して `print("やあ")` と書いて▶」だけで十分。
アプリ内の**「コードを学ぼう」**という初心者コースが一番おすすめ。

### つまずき①: 「Expressions are not allowed at the top level」
- **原因**: 「App」を作ってしまった。Appのファイルは普通のSwiftファイル扱いで、一番外側（トップレベル）に `print` や `let x = ...` を書けない
- **直し方**: 「マイPlayground」に戻り、新規作成で **「Playground」→「Blank」** を選ぶ（**「App」ではない**）。そこなら ▶ で動く
- 「トップレベル」＝関数やクラスの中ではなく、**ファイルの一番外側**のこと
- どうしてもAppでしたい時は、コードを `func test() { ... }` に入れて、`ContentView` の `body` などから `test()` と呼ぶ

## `struct Product` って？
**「商品1つ分のデータを入れる箱の“形（ひな形）”」**。
`struct` は「構造体」。こういう項目をまとめて1つの仲間にします、という定義。
例えると**商品カードの雛形**。

```swift
struct Product {
    let id: String        // ID      例: "KH-008"
    let name: String      // 名前    例: "キーホルダー 08"
    let priceJpy: Int     // 円の値段 例: 800
    let priceSats: Int?   // satsの値段 例: 1200
    var stock: Int?       // 在庫     例: 1
}
```

| 書き方 | 意味 |
| --- | --- |
| `id` / `name` | 欄の名前 |
| `: String` | **文字（テキスト）** を入れる欄 |
| `: Int` | **整数（数字）** を入れる欄 |
| `let` | あとから**変えられない** |
| `var` | あとから**変えられる**（在庫は減るので `var`） |
| `: Int?` の `?` | **あるかも / 空っぽかも**（オプショナル。下で説明） |

> 補足: `let id, name: String` は「id と name は両方 String」という**省略した書き方**。上の例は1行ずつ書いた版で意味は同じ。

## `Int?` の `?`（オプショナル）って？
**「値が入っているかもしれないし、何も入っていない(nil)かもしれない」** という意味。
- `ST-003` は satsの値段が**空（NULL）**。それが `nil`（ニル＝空っぽ）
- `nil` のときは「sats払いはできない」と判断する

使うときは、空かどうか確認してから取り出す：
```swift
if let sats = product.priceSats {   // 入っていれば取り出す
    print("sats価格は \(sats)")
} else {
    print("この商品はsats払いなし") // 空っぽのとき
}
```

## `enum StockMode` って？
**「決まった選択肢のうち、どれか1つ」** を表す型（`enum`＝列挙型）。
種類を3パターンに限定しておくと、変な値にならず安全。

```swift
enum StockMode {
    case counted   // 数量管理型（ステッカー。在庫を数で持つ）
    case unique    // 一点物型（キーホルダー。在庫は1か0）
    case none      // 在庫管理なし型（今回は使わない）
}
```
使い方: `let mode = StockMode.counted` → 「これは数量管理型」と決まる。

## 全部つなげた例（Playgroundsに貼ってみてOK）
```swift
struct Product {
    let id: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?
    var stock: Int?
}

enum StockMode {
    case counted
    case unique
    case none
}

let kh008 = Product(id: "KH-008", name: "キーホルダー 08",
                    priceJpy: 800, priceSats: 1200, stock: 1)
print(kh008.name)      // キーホルダー 08
print(kh008.priceJpy)  // 800

let st003 = Product(id: "ST-003", name: "ステッカー しかく",
                    priceJpy: 300, priceSats: nil, stock: 10)
if let sats = st003.priceSats {
    print("sats価格: \(sats)")
} else {
    print("この商品はsats払いなし")  // ← こちらが出る
}
```

**コツ**: コピペより**自分で打ち込む**と覚える。少し変えてみる（名前や値段を変える）のも効果的。

## 言葉のミニ辞典
| 言葉 | かんたんに言うと |
| --- | --- |
| `struct` | データをまとめる箱の形 |
| `enum` | 決まった選択肢のどれか1つ |
| `let` / `var` | 変えられない / 変えられる |
| `String` / `Int` | 文字 / 整数 |
| `nil` / `?` | 空っぽ / 空っぽかも |
| `print()` | 文字を出力する |
| `if let` | 空っぽか確認して取り出す |
