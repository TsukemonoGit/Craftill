# 40. 販売記録を書き出す

元: `../siyou.md` A-8

販売（`sales`）と明細（`sale_items`）を **JSON または CSV** で書き出す。
列名は `siyou.md` A-13 の項目名（`6_データベース.md` と同じ）。日時は ISO 8601 の文字列として持っている前提なので、そのまま出す。
計算は**純ロジックなので「ブック（Book）」**で試す。ファイル保存は**「アプリ（App）」**。

## 1. まとめて出すための入れ物
```swift
/// 書き出すファイルの中身（sales と sale_items をまとめる）。
struct SalesExport: Codable {
    let sales: [Sale]
    let saleItems: [SaleItem]
}
```

## 2. JSONに書き出す
```swift
/// 販売記録をJSONのデータにする。キーは snake_case（saleId → sale_id）。
func salesJSONData(_ export: SalesExport) throws -> Data {
    let encoder = JSONEncoder()
    encoder.keyEncodingStrategy = .convertToSnakeCase   // 列名そろえ
    encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
    return try encoder.encode(export)
}

let export = SalesExport(sales: sales, saleItems: saleItems)
if let data = try? salesJSONData(export),
   let text = String(data: data, encoding: .utf8) {
    print(text)
}
```

- `.convertToSnakeCase` で Swiftの `saleId` が `sale_id` になり、列名と一致する
- `.sortedKeys` はキーをABC順にそろえて見やすくする（無くてもよい）
- `nil` の項目は **キーごと出ない**（例: `completed_at` が無い会計）

## 3. CSVで書き出す
JSONだと空欄の列が消える（`total_sats` がない会計はキーも出ない）。列をそろえたいときはCSVにする。

```swift
/// CSVの1つの値を安全な形にする（カンマ・引用符・改行があれば "..." で囲む）。
func csvField(_ value: String) -> String {
    let needsQuote = value.contains(",") || value.contains("\"") || value.contains("\n")
    if !needsQuote { return value }
    return "\"\(value.replacingOccurrences(of: "\"", with: "\"\""))\""
}

/// sales を1行ずつCSVにする。
func salesCSV(_ sales: [Sale]) -> String {
    var lines = ["sale_id,status,method,total_jpy,total_sats,received_jpy,change_jpy,confirmed_at,refunded,completed_at"]
    for s in sales {
        let row: [String] = [
            csvField(s.saleId), s.status, s.method,
            s.totalJpy.map { String($0) } ?? "",
            s.totalSats.map { String($0) } ?? "",
            s.receivedJpy.map { String($0) } ?? "",
            s.changeJpy.map { String($0) } ?? "",
            csvField(s.confirmedAt ?? ""),
            String(s.refunded),
            csvField(s.completedAt ?? ""),
        ]
        lines.append(row.joined(separator: ","))
    }
    return lines.joined(separator: "\n")
}

/// sale_items を1行ずつCSVにする。
func saleItemsCSV(_ items: [SaleItem]) -> String {
    var lines = ["item_id,sale_id,item_type,type_id,product_id,qty,unit_price_jpy,unit_price_sats,paid_in,name_snapshot"]
    for it in items {
        let row: [String] = [
            csvField(it.itemId), csvField(it.saleId), it.itemType,
            it.typeId ?? "", it.productId ?? "",
            String(it.qty), String(it.unitPriceJpy),
            it.unitPriceSats.map { String($0) } ?? "",
            it.paidIn, csvField(it.nameSnapshot),
        ]
        lines.append(row.joined(separator: ","))
    }
    return lines.joined(separator: "\n")
}

print(salesCSV(sales))
print(saleItemsCSV(saleItems))
```
`sales` の出力:
```
sale_id,status,method,total_jpy,total_sats,received_jpy,change_jpy,confirmed_at,refunded,completed_at
S-20261013-001,completed,cash,1400,,2000,600,,0,2026-10-13T11:00:00+09:00
S-20261013-002,completed,mixed,300,1200,500,200,2026-10-13T11:05:00+09:00,0,2026-10-13T11:05:30+09:00
S-20261013-003,completed,cash,1200,,1200,0,,0,2026-10-13T11:10:00+09:00
S-20261013-004,voided,mixed,300,1200,,,2026-10-13T11:20:00+09:00,0,
```
- `voided` の行は `received_jpy`・`change_jpy`・`completed_at` が空（sats確認済みで中断。A-4）
- `cash` は `total_sats` が空、`lightning` は `total_jpy` が空

## 4. ファイルへ（アプリ）
```swift
import Foundation

/// 文字列をUTF-8のテキストとして書き出す。
func write(_ text: String, to url: URL) throws {
    try text.write(to: url, atomically: true, encoding: .utf8)
}
```
- 保存先はMacなら保存ダイアログ、iPadならファイルアプリ／共有シート（A-8）
- 文字コードはUTF-8
- 終了時に必須、営業中も任意のタイミングで実行できる（PIN必須。A-11）

## ポイント
- 列名は `siyou.md` A-13 と同じ（`sales` と `sale_items`）
- `refunded` は数値（0/1）で持つ
- JSONは入れ子＋空欄省略、CSVは列がそろい表計算で見やすい。用途で選ぶ
- `paid_in` を見ればその行が円かsatsか分かる（sats照合・集計に使う。A-8）

**できた合図**: JSONなら `sale_id` などのキーで中身が出る。CSVなら `sales` 4行（＋明細）が出て、空欄の列がそろっている。
