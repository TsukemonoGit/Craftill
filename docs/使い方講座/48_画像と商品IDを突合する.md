# 画像と商品IDを突合する

元: `../siyou.md` A-17

画像ビルドスクリプトの**検証**の練習。
商品マスタCSVの商品IDと、原本画像のファイル名を突き合わせ、次の2つを一覧で出す。

- **欠落** … 画像がない商品ID（CSVにあるのに画像が無い）
- **余剰** … 商品IDにないファイル（画像はあるのにCSVに無い）

`Set`（集合）の差で求める。`../siyou.md` A-17 の処理「1. 検証」に対応。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動く。
> 実際は Mac のコマンドラインツールが CSV とフォルダを読み、この判定を行う。

---

## Set（集合）の差って？

`Set` は「重複のない集まり」。2つの集合の差を取ると「片方にだけあるもの」が出せる。

| 書き方 | 意味 |
| --- | --- |
| `A.subtracting(B)` | AにあってBにないもの（AからBを取り除く） |
| `A.union(B)` | AとBのどちらかにあるもの |
| `A.intersection(B)` | AとBの両方にあるもの |

ここでは `csvIDs.subtracting(imageIDs)` が**欠落**、`imageIDs.subtracting(csvIDs)` が**余剰**。

## ファイル名から拡張子を除く

画像ファイル名 `KH-008.jpg` から、商品IDにあたる `KH-008` を取り出す。

```swift
/// "KH-008.jpg" → "KH-008"（拡張子を外す）
func baseName(_ fileName: String) -> String {
    return URL(fileURLWithPath: fileName).deletingPathExtension().lastPathComponent
}

print(baseName("KH-008.jpg"))  // KH-008
print(baseName("ST-001"))      // ST-001（拡張子が無くてもそのまま）
```

- `URL(fileURLWithPath:)` … ファイル名を「道」として扱う。
- `.deletingPathExtension()` … 最後の `.jpg` を外す。
- `.lastPathComponent` … フォルダが混ざっていてもファイル名だけ取る。

## 突合する関数

```swift
struct MatchResult {
    let missing: [String]   // 欠落：画像がない商品ID
    let surplus: [String]   // 余剰：商品IDにないファイル名
}

func checkImages(productIDs: [String], imageFiles: [String]) -> MatchResult {
    // 商品IDの集合
    let csvIDs = Set(productIDs)
    // ファイル名から拡張子を外した「画像側のID」の集合
    let imageIDs = Set(imageFiles.map { baseName($0) })

    let missing = csvIDs.subtracting(imageIDs).sorted()   // CSVにあって画像にない
    let surplus = imageIDs.subtracting(csvIDs).sorted()   // 画像にあってCSVにない

    // 余剰は「ファイル名」で見たいので、元のファイル名に戻す
    let surplusFiles = imageFiles
        .filter { surplus.contains(baseName($0)) }
        .sorted()

    return MatchResult(missing: missing, surplus: surplusFiles)
}
```

**ポイント**:
- 商品IDと画像名は**同じ決まり**（商品ID＝ファイル名の本体）なので、`Set` にして引き算すればよい。
- `.sorted()` を付けると、表示順が毎回同じになって見やすい。

## 表示して確認する

```swift
let result = checkImages(productIDs: productIDs, imageFiles: imageFiles)

print("欠落（画像なしの商品ID）: \(result.missing.count) 件")
for id in result.missing {
    print("  \(id)")
}

print("余剰（商品IDにないファイル）: \(result.surplus.count) 件")
for name in result.surplus {
    print("  \(name)")
}

if result.missing.isEmpty && result.surplus.isEmpty {
    print("突合OK: すべての商品IDに画像があり、余分なファイルもありません")
}
```

**できた合図**:
```
欠落（画像なしの商品ID）: 1 件
  KH-013
余剰（商品IDにないファイル）: 1 件
  KH-021.jpg
```
`KH-013` は画像が無いので**欠落**、`KH-021.jpg` はCSVに無いので**余剰**。

## 実際のファイルを読む場合（Macのコマンドラインツール）

スクリプトでは、CSVと `originals/` を実際に読み、同じ判定をする。

```swift
#if os(macOS)
/// originals/ フォルダのファイル名を一覧にする
func listFiles(in folderPath: String) -> [String] {
    let fm = FileManager.default
    let names = (try? fm.contentsOfDirectory(atPath: folderPath)) ?? []
    return names.sorted()
}

/// 画像として扱う拡張子だけ残す（.DS_Store などを除く）
func onlyImages(_ names: [String]) -> [String] {
    let exts: Set<String> = ["jpg", "jpeg", "png", "heic", "webp"]
    return names.filter { exts.contains(URL(fileURLWithPath: $0).pathExtension.lowercased()) }
}

let files = onlyImages(listFiles(in: "originals"))
let checked = checkImages(productIDs: productIDs, imageFiles: files)
print("欠落:", checked.missing, " 余剰:", checked.surplus)
#else
// iPad/iOS はアクセスできるフォルダが限られる。突合は Mac のスクリプトで行う
print("突合は Mac のコマンドラインツールで実行する")
#endif
```

- `#if os(macOS)` … Mac でのみ、フォルダを直接読む。（`06_QRを試す.md` の `#if` と同じ考え方）
- 余剰に `memo.txt` のような画像でないファイルが出ると紛らわしいので、拡張子で絞る。

## 覚えておくこと

- 検証は「**欠落**（画像なしの商品ID）」と「**余剰**（商品IDにないファイル）」の2つを一覧で出す（`../siyou.md` A-17）。
- 判定は `Set` の差（`subtracting`）で簡潔に書ける。
- 商品IDと画像名が同じ決まりだからこそ、集合の引き算だけで突合できる（`46_商品IDから画像名を導出する.md`）。
- 検証で欠落・不一致があれば一覧を表示する。ビルドを止めるか警告にするかは運用で決める（`../siyou.md` Q18）。
