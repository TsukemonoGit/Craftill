# 34. 併用会計の請求額を計算する

元: `../siyou.md` A-6-1（請求sats額・現金分）

**ゴール**: 併用会計の請求額を出す。

- **請求sats額** = sats単価のある行の「sats単価 × 数量」の合計
- **現金分** = sats単価のない行の「円単価 × 数量」の合計
- 現金分が 0 なら**併用なし**（satsだけ）
- 全行sats単価なしなら **sats払いを選べない**
- **レート換算はしない**。野良商品も同じ扱い

> 純ロジックの練習。**ブック（Book）**で作る。

## 34-1. sats額と現金分を分けて足す

ポイントは「**sats単価がある行か、ない行か**」で振り分けること。

```swift
/// 請求sats額。sats単価のある行だけを足す。
func totalSats(_ lines: [CartLine]) -> Int {
    lines.reduce(0) { $0 + (($1.unitSats ?? 0) * $1.qty) }
}

/// 現金分。sats単価のない行だけを足す。
func cashPartJpy(_ lines: [CartLine]) -> Int {
    lines.reduce(0) { $0 + (($1.unitSats == nil ? $1.unitJpy : 0) * $1.qty) }
}

/// 現金払いの全額（全行の円合計）。参考。
func totalJpy(_ lines: [CartLine]) -> Int {
    lines.reduce(0) { $0 + $1.unitJpy * $1.qty }
}
```

- `unitSats ?? 0` … sats単価が無ければ 0（sats合計には足さない）
- `unitSats == nil ? unitJpy : 0` … sats単価が無い行だけ円を足す（現金分）
- `reduce(0) { $0 + ... }` … 配列を1つの数にまとめる（合計の定番）

## 34-2. sats払いを選べるか／会計の方法

```swift
/// sats単価のある行が1行以上あれば、sats払いを選べる。
func canPaySats(_ lines: [CartLine]) -> Bool {
    lines.contains { $0.unitSats != nil }
}

/// 会計の方法を決める。
/// - sats単価の行が無い → 現金のみ（sats払い不可）
/// - sats単価の行があり、現金分0 → satsのみ
/// - sats単価の行があり、現金分あり → 併用
func decideMethod(_ lines: [CartLine]) -> PaymentMethod {
    guard canPaySats(lines) else { return .cash }
    return cashPartJpy(lines) == 0 ? .lightning : .mixed
}
```

## 34-3. 動かしてみる

```swift
// ① 併用（mixed）: KH-002（sats1200）＋ ST-003（satsなし¥300）＋ 野良¥1200（satsなし）
let mixedCart: [CartLine] = [
    line(products[4], qty: 1),   // KH-002
    line(products[2], qty: 1),   // ST-003
    CartLine(name: "委託品A", unitJpy: 1200, unitSats: nil, qty: 1, isAdhoc: true),
]
print("① 請求sats: \(totalSats(mixedCart)) sats")   // 1200
print("① 現金分: ¥\(cashPartJpy(mixedCart))")        // 300 + 1200 = 1500
print("① 方法: \(decideMethod(mixedCart))")          // mixed

// ② satsのみ（lightning）: ST-001（sats500）を2枚 → 現金分0
let satsOnly: [CartLine] = [ line(products[0], qty: 2) ]
print("② 請求sats: \(totalSats(satsOnly)) sats／現金分 ¥\(cashPartJpy(satsOnly))")  // 1000／0
print("② 方法: \(decideMethod(satsOnly))")           // lightning

// ③ 全行satsなし（現金のみ）: sats払いは選べない
let cashOnly: [CartLine] = [ line(products[2], qty: 1) ]   // ST-003（satsなし）
print("③ sats払いを選べる？ \(canPaySats(cashOnly))")        // false
print("③ 方法: \(decideMethod(cashOnly))")           // cash
```

**できた合図**:
- `① 請求sats: 1200 sats` / `① 現金分: ¥1500` / `① 方法: mixed`
- `② 請求sats: 1000 sats／現金分 ¥0` / `② 方法: lightning`
- `③ sats払いを選べる？ false` / `③ 方法: cash`

## ポイント
- **sats単価がある行**が sats で受け取る分、**ない行**が現金分。行ごとに振り分ける
- 請求sats額は sats単価 × 数量の合計。**レート換算はしない**（円からsatsを計算しない）
- 現金分が 0 なら併用なし（`lightning`）。現金分があれば併用（`mixed`）
- 全行sats単価なしなら sats払いを選べない（`cash` のみ）
- 野良商品も行として同じ計算に混ざる。sats単価が無ければ現金分に入る
- 参考: `../開発/6_データベース.md` の会計例2（KH-002 ＋ ST-003 → 1200 sats ＋ ¥300）と同じ計算
