# 追加レッスン: 支払方法と合計の内訳

元: `../siyou.md` A-5, A-6-1
`02_練習メニュー.md` の「11. 支払方法と合計の内訳」。

支払方法は3つ（A-13 の `sales.method`）。

| `PaymentMethod` | 意味 |
| --- | --- |
| `cash` | 全額現金 |
| `lightning` | sats払い（現金分なし） |
| `mixed` | sats払い（現金分あり）＝併用 |

合計は**支払方法ごとに2行**で表示する（A-3）。

```
sats払い　○○sats ＋ ○○円
現金　　　○○円
```

- 現金の○○円 … **全行の円合計**（Σ 円単価×数量）
- sats払いの○○sats … **sats単価のある行**のsats合計（Σ sats単価×数量）
- sats払いの○○円 … **sats単価のない行**の円合計（＝現金分。sats払いでも現金で受け取る分）

**ルール**（A-6-1）:
- 現金分が0円なら、sats払いは「**○○sats**」だけ表示する。
- 全行がsats単価なしなら、sats払いは「**選択不可**（sats単価のある商品がありません）」と表示する。

## 合計を計算する

3つの合計をまとめて返す。

```swift
struct Totals {
    var sats: Int = 0        // sats単価のある行のsats合計
    var cashForSats: Int = 0 // sats単価のない行の円合計（＝現金分）
    var cash: Int = 0        // 全行の円合計
}

func totals(_ cart: [CartLine]) -> Totals {
    var t = Totals()
    for line in cart {
        if let s = line.unitPriceSats {          // sats単価がある行
            t.sats += s * line.qty           //   → sats合計へ
        } else {                             // sats単価がない行
            t.cashForSats += line.unitPriceJpy * line.qty  // → 現金分へ
        }
        t.cash += line.unitPriceJpy * line.qty   // 現金合計には全部足す
    }
    return t
}
```
- `if let s = line.unitPriceSats` … sats単価の有無で分ける（`01_初心者メモ.md`）

## sats払いが選べるか

```swift
/// sats単価のある行が1行以上あれば、sats払いを選べる（A-6-1）
func canPayBySats(_ cart: [CartLine]) -> Bool {
    return cart.contains { $0.unitPriceSats != nil }
}
```
- `contains { ... }` … 条件に合う要素が1つでもあれば `true`

## 合計の2行を作る

```swift
func totalLines(_ cart: [CartLine]) -> (satsLine: String, cashLine: String) {
    let t = totals(cart)

    let satsLine: String
    if !canPayBySats(cart) {
        // 全行がsats単価なし → 選択不可
        satsLine = "sats払い　選択不可（sats単価のある商品がありません）"
    } else if t.cashForSats == 0 {
        // 現金分がない → satsだけ
        satsLine = "sats払い　\(t.sats)sats"
    } else {
        // sats ＋ 現金分
        satsLine = "sats払い　\(t.sats)sats ＋ \(t.cashForSats)円"
    }

    return (satsLine, "現金　　　\(t.cash)円")
}
```

## 支払方法を決める

```swift
/// 客が選んだ方法を、記録用の3つに振り分ける
func resolveMethod(chooseSats: Bool, cart: [CartLine]) -> PaymentMethod {
    if !chooseSats { return .cash }
    return totals(cart).cashForSats == 0 ? .lightning : .mixed
}
```

## 試す

```swift
// 例1: 全部sats単価あり（ST-001×2 + KH-001×1）
let cart1 = [line(product("ST-001"), qty: 2), line(product("KH-001"), qty: 1)]
let l1 = totalLines(cart1)
print(l1.satsLine)   // sats払い　2200sats
print(l1.cashLine)   // 現金　　　1400円

// 例2: sats単価なしを含む（KH-002×1 + ST-003×1）
let cart2 = [line(product("KH-002"), qty: 1), line(product("ST-003"), qty: 1)]
let l2 = totalLines(cart2)
print(l2.satsLine)   // sats払い　1200sats ＋ 300円
print(l2.cashLine)   // 現金　　　1100円

// 例3: 全部sats単価なし（ST-003×2）
let cart3 = [line(product("ST-003"), qty: 2)]
let l3 = totalLines(cart3)
print(l3.satsLine)   // sats払い　選択不可（sats単価のある商品がありません）
print(l3.cashLine)   // 現金　　　600円

// 支払方法の判定
print(resolveMethod(chooseSats: false, cart: cart1))  // cash
print(resolveMethod(chooseSats: true,  cart: cart1))  // lightning（現金分0）
print(resolveMethod(chooseSats: true,  cart: cart2))  // mixed（現金分300）
```

## ポイント

- 合計は「**sats合計**」「**現金分**」「**現金合計**」の3つを区別して持つ。円とsatsは**合算しない**
- 現金分があるかで `lightning` と `mixed` が決まる
- 全行sats単価なし → sats払いは**選択不可**（理由も表示する）
- 野良商品（sats単価なし）は現金分に自動で入る
- 支払方法選択画面にも、カートと同じ**2行**を表示する（A-4）
