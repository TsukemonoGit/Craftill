# 追加レッスン: カートを編集する（削除・数量増減）

元: `../siyou.md` A-3
`02_練習メニュー.md` の「9. カートを編集する」。

カートの行に対して、削除と数量の＋／－を行う（A-3 の表）。

| 種類 | ＋／－ | 数量 |
| --- | --- | --- |
| 数量管理型 `counted` | ＋／－で調整。在庫超過はエラー | 0以上 |
| 一点物型 `unique` | **なし**（数量1固定） | 常に1 |
| 在庫管理なし型 `none` | ＋／－で調整。上限なし | 0以上 |
| 野良商品 | ＋／－で調整 | 0以上 |

- **数量が0になる操作**は「**行の削除**」として扱う（確認ダイアログあり）。
- 削除は全種類でできる（商品名・数量を確認ダイアログに表示）。

> ここは**純ロジック**なので **ブック（Book）** で書ける。画面（SwiftUI）は **アプリ（App）** で作る（`01_初心者メモ.md`）。

## 在庫と種類は、カートではなく表から引く

`CartLine` には在庫も種類も無い（A-7）。必要なときは**表から引きます**。

```swift
/// カートの行が属する種類（野良は nil）
func productType(of line: CartLine) -> ProductType? {
    guard let typeId = line.typeId else { return nil }      // 野良は種類を持たない
    return productTypes.first { $0.typeId == typeId }
}

/// カートの行の現在の在庫（在庫管理なし・野良は nil）
func currentStock(of line: CartLine, in products: [Product]) -> Int? {
    guard productType(of: line) != nil else { return nil }
    return products.first { $0.id == line.id }?.stock
}

```

> 「カートに入れた時の値」ではなく、**いまの表の値**で判定します。08_在庫を減らす.md と同じ考え方です。

## 小計を出す

```swift
/// 1行の小計 = 円単価 × 数量
func subtotal(_ line: CartLine) -> Int {
    return line.unitPriceJpy * line.qty
}

/// カート全体の円合計
func cartTotal(_ cart: [CartLine]) -> Int {
    return cart.reduce(0) { $0 + subtotal($1) }
}
```
- `reduce(0) { ... }` … 配列をまとめて1つの値にする。`$0` は「たまった合計」、`$1` は「今回の行」

## 数量を増やす（＋）

```swift
func increase(at i: Int, cart: inout [CartLine], products: [Product]) -> String {
    let line = cart[i]

    if productType(of: line)?.stockMode == .unique {
        return "\(line.name) は一点物なので数量1固定です"
    }
    // 在庫管理ありは在庫を超えない
    if productType(of: line)?.stockMode == .counted,
       let stock = currentStock(of: line, in: products), line.qty + 1 > stock {
        return "在庫超過: \(line.name)（在庫 \(stock)）"
    }

    cart[i].qty += 1
    return "\(line.name) ×\(cart[i].qty)"
}
```

## 数量を減らす（－）

数量が0になるなら、その行を削除する。

```swift
func decrease(at i: Int, cart: inout [CartLine]) -> String {
    let line = cart[i]

    if productType(of: line)?.stockMode == .unique {
        return "\(line.name) は一点物なので数量1固定です"
    }
    if line.qty <= 1 {
        cart.remove(at: i)                                  // 数量0 → 行の削除
        return "\(line.name) を削除しました"
    }
    cart[i].qty -= 1
    return "\(line.name) ×\(cart[i].qty)"
}
```

## 行を削除する

削除は全種類でできる（＋／－とは別のボタン）。

```swift
func remove(at i: Int, cart: inout [CartLine]) -> String {
    let name = cart[i].name
    let qty = cart[i].qty
    cart.remove(at: i)
    return "削除: \(name) ×\(qty)"     // 確認ダイアログには 商品名・数量を出す
}
```

## 試す

```swift
var cart: [CartLine] = [
    line(products[0], qty: 2),   // ST-001 を2枚
    line(products[3], qty: 1),   // KH-001 を1点
]

print(cartTotal(cart))               // 300×2 + 800×1 = 1400
print(increase(at: 0, cart: &cart, products: products))  // ST-001 → ×3
print(decrease(at: 0, cart: &cart))  // ×2
print(decrease(at: 0, cart: &cart))  // ×1
print(decrease(at: 0, cart: &cart))  // 数量0 → 削除（KH-001 が前に詰める）
print(increase(at: 0, cart: &cart, products: products))  // いま index0 は KH-001 → 固定メッセージ
```
- `at i: Int` … 「何番目の行か」。`cart[i]` でその行を取り出す
- 削除すると**後ろの行が前に詰める**ので、`index` はずれる。画面では行ごとに操作するのが安全

ステッカー まる を削除しました

## ポイント

- `unique` は＋／－を**無効**にする（数量1固定）。押しても何も変えずメッセージを返す
- `counted` の＋は**在庫を超えたらエラー**
- `decrease` で数量が0になったら `remove(at:)` で**行ごと消す**
- 「数量0＝削除」の操作だけ確認ダイアログを出す（A-3）
- 小計・合計はいつでも計算できる（保存しなくてよい）
- カート行は**在庫を持たない**。在庫・種類は `productType(of:)`・`currentStock(of:in:)` で**いまの表**から引く（A-7。`08_在庫を減らす.md` と同じ考え方）
