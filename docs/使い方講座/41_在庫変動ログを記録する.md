# 在庫変動ログを記録する

元: `../siyou.md` A-7

在庫が「いつ・どの商品が・いくつ増減したか」を**全部**記録する練習（`stock_movements`）。
現在庫は「初期在庫＋それまでの増減の合計」で求められる。表は `../開発/6_データベース.md` の `stock_movements` と同じ。

## 在庫変動を表す型

`delta` は「増減数」。増えるときは `+`、減るときは `-`。`reason` は変動の理由（4種類）。

```swift
/// 変動の理由。文字列はそのままDBに入る。
enum MovementReason: String {
    case initial   // 初期登録
    case sale      // 販売（減る）
    case void      // 販売取消（戻る）
    case adjust    // 手動調整（棚卸し）
}

struct StockMovement {
    let id: String           // 例: "M-001"
    let productID: String    // 商品ID
    let delta: Int           // 増減数（+/-）
    let reason: MovementReason
    let saleID: String?      // 会計に紐づく場合のみ（initial / adjust は nil）
    let at: String           // 日時（ISO 8601 の文字列）
}
```

| reason | いつ | `delta` の向き | `saleID` |
| --- | --- | --- | --- |
| `initial` | CSV取り込みで新規登録したとき | ＋（在庫値） | なし |
| `sale` | 会計が「完了」したとき | −（数量） | あり |
| `void` | 販売を取り消したとき | ＋（戻す数量） | あり |
| `adjust` | 棚卸しで数量を直したとき | ＋／−（差） | なし |

## ログを作る関数

```swift
var movementSerial = 0
func nextID() -> String {
    movementSerial += 1
    return String(format: "M-%03d", movementSerial)
}

/// 初期登録。在庫管理なし型（stock が nil）は記録しない。
func makeInitial(_ product: Product, at: String) -> StockMovement? {
    guard let s = product.stock else { return nil }
    return StockMovement(id: nextID(), productID: product.id,
                         delta: s, reason: .initial, saleID: nil, at: at)
}

/// 販売。数量ぶん減らす。
func makeSale(_ productID: String, qty: Int, saleID: String, at: String) -> StockMovement {
    StockMovement(id: nextID(), productID: productID,
                  delta: -qty, reason: .sale, saleID: saleID, at: at)
}

/// 販売取消。数量ぶん戻す。
func makeVoid(_ productID: String, qty: Int, saleID: String, at: String) -> StockMovement {
    StockMovement(id: nextID(), productID: productID,
                  delta: qty, reason: .void, saleID: saleID, at: at)
}

/// 手動調整。差（delta）をそのまま記録する。
func makeAdjust(_ productID: String, delta: Int, at: String) -> StockMovement {
    StockMovement(id: nextID(), productID: productID,
                  delta: delta, reason: .adjust, saleID: nil, at: at)
}
```

**ポイント**: どの記録も「同じ形」で書ける。だから後から合計すれば現在庫になる。

## 全件を記録して、現在庫を合計で求める

```swift
let t0 = "2026-10-13T10:00:00+09:00"

var movements: [StockMovement] = []

// 1. 初期登録（全商品）
for p in products {
    if let m = makeInitial(p, at: t0) { movements.append(m) }
}

// 2. 会計完了: ST-001 を2個 + KH-005 を1個（現金会計）
let saleID = "S-20261013-001"
let t1 = "2026-10-13T11:00:00+09:00"
movements.append(makeSale("ST-001", qty: 2, saleID: saleID, at: t1))
movements.append(makeSale("KH-005", qty: 1, saleID: saleID, at: t1))

// 3. 販売取消: さっきの ST-001 ×2 を戻す
let t2 = "2026-10-13T11:30:00+09:00"
movements.append(makeVoid("ST-001", qty: 2, saleID: saleID, at: t2))

// 4. 手動調整（棚卸し）
movements.append(makeAdjust("ST-002", delta: +5, at: "2026-10-13T12:00:00+09:00"))  // 見つかった
movements.append(makeAdjust("ST-003", delta: -3, at: "2026-10-13T12:00:00+09:00"))  // 壊れていた

// 現在庫 = その商品の delta の合計
func currentStock(_ movements: [StockMovement], productID: String) -> Int {
    movements.filter { $0.productID == productID }
             .reduce(0) { $0 + $1.delta }
}
```

## 表示して確認する

```swift
// 記録した全件を出す
for m in movements {
    let sign = String(format: "%+d", m.delta)   // +2 / -2 のように符号付き
    let sale = m.saleID ?? "—"
    print("\(m.id)  \(m.productID)  \(sign)  \(m.reason.rawValue)  \(sale)  \(m.at)")
}

print("---- 現在庫 ----")
for p in products {
    print("\(p.id)  \(p.name)  在庫 \(currentStock(movements, productID: p.id))")
}
```

**できた合図**（抜粋）:
```
M-004  KH-001  +1  initial  —  2026-10-13T10:00:00+09:00
M-008  KH-005  -1  sale     S-20261013-001  2026-10-13T11:00:00+09:00
M-009  ST-001  +2  void     S-20261013-001  2026-10-13T11:30:00+09:00
---- 現在庫 ----
ST-001  ステッカー まる   在庫 10
ST-002  ステッカー さんかく 在庫 15
ST-003  ステッカー しかく  在庫 7
KH-001  キーホルダー 01   在庫 1
KH-002  キーホルダー 02   在庫 1
KH-005  キーホルダー 05   在庫 0
```
`KH-005` は 1 → 0 になり SOLD OUT。`ST-001` は売って戻したので 10 のまま。

## 覚えておくこと

- `stock_movements` は**追記のみ**。記録を後から書き換えない（`../siyou.md` A-7）。
- 現在庫は「記録の合計」で何度でも計算し直せる。だから合計が合わなくなった時に原因を追える。
- 在庫管理なし型（`stock` が `nil`）と野良商品は**対象外**。記録を作らない。
- 日時は `../開発/6_データベース.md` に合わせて ISO 8601 の文字列で持つ。
