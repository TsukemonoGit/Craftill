# 38. 日時をISO8601にする

元: `../siyou.md` A-8, A-13

日時は**ISO 8601（タイムゾーン付き）の文字列**で保存する（`6_データベース.md` の `at` / `updated_at` / `completed_at`）。
例: `2026-10-13T10:00:00+09:00`。

Date → 文字列、文字列 → Date の変換は `ISO8601DateFormatter`。
**純ロジックなので「ブック（Book）」**で試す。

---

## 前提データ
```swift
import Foundation

// 在庫変動（6_データベース.md の stock_movements の一部）
struct StockMovement {
    let id: String
    let productID: String
    let delta: Int
    let reason: String   // initial / sale / void / adjust
    let at: Date         // 保存するときは ISO 8601 文字列にする
}
```

---

## 1. Date → ISO 8601 文字列
```swift
/// 日本時間（+09:00）のISO 8601文字列にする。
/// 例: "2026-10-13T10:00:00+09:00"
func iso8601String(_ date: Date) -> String {
    let formatter = ISO8601DateFormatter()
    formatter.formatOptions = [.withInternetDateTime]        // 日付＋時刻＋タイムゾーン
    formatter.timeZone = TimeZone(secondsFromGMT: 9 * 3600)  // 日本時間（+09:00）
    return formatter.string(from: date)
}

// ── 確かめるためのDateを用意する ──
var comps = DateComponents()
comps.year = 2026; comps.month = 10; comps.day = 13
comps.hour = 10; comps.minute = 0; comps.second = 0

var cal = Calendar(identifier: .gregorian)
cal.timeZone = TimeZone(secondsFromGMT: 9 * 3600)
let date = cal.date(from: comps)!    // 2026-10-13 10:00 (JST)

print(iso8601String(date))           // 2026-10-13T10:00:00+09:00
```
- `formatOptions = [.withInternetDateTime]` が基本形（日付・時刻・タイムゾーンをまとめたセット）
- `timeZone` を日本時間にすると、末尾が `+09:00` になる（指定しないと `Z`＝UTC になる）

**できた合図**: `2026-10-13T10:00:00+09:00` が出る。

---

## 2. 文字列 → Date
```swift
/// ISO 8601 文字列を Date にする。読めなければ nil。
func date(fromISO8601 string: String) -> Date? {
    let formatter = ISO8601DateFormatter()
    formatter.formatOptions = [.withInternetDateTime]
    // 入力にタイムゾーン（+09:00）が入っているので、timeZone の指定は不要
    return formatter.date(from: string)
}

let back = date(fromISO8601: "2026-10-13T10:00:00+09:00")
print(back != nil)                              // true
print(iso8601String(back!))                     // 2026-10-13T10:00:00+09:00（往復して同じ）

print(date(fromISO8601: "2026/10/13") == nil)   // true（形式違いは読めない）
```
- 読み取りは `+09:00` を解釈するので `timeZone` を指定しなくてよい
- 読めない形式は `nil` になる。`try?` の代わりに「`nil` かどうか」で失敗を判定する

**できた合図**: `true` / `2026-10-13T10:00:00+09:00` / `true` が出る（往復して元に戻る）。

---

## 3. 保存用の文字列にする（ブック）
```swift
/// 保存・エクスポート用に、日時を ISO 8601 文字列にする。
func forStorage(_ date: Date) -> String {
    iso8601String(date)
}

let movement = StockMovement(id: "M-101", productID: "ST-001",
                             delta: -2, reason: "sale", at: date)
print(forStorage(movement.at))   // 2026-10-13T10:00:00+09:00
```
- 同じ値が `at` / `updated_at` / `completed_at` のどの列でも使える
- 保存は**文字列**、アプリの中での計算は**Date**、と役割を分ける

---

## ポイント・つまずき
- `ISO8601DateFormatter` は**Apple公式**。`import Foundation` だけで使える
- **保存＝文字列、計算＝Date**。DBには文字列で入れ、比較・並べ替えはDateにしてから
- 書き出し側で `timeZone` を日本時間にしないと `Z`（UTC）になる。保存形式をそろえる
- 往復テスト（Date → 文字列 → Date）を必ず1回やる
- ミリ秒まで残したいときは `formatOptions` に `.withFractionalSeconds` を足す（今回の例は秒までで十分）

**できた合図**: `2026-10-13T10:00:00+09:00` が出て、文字列に戻すと同じ時刻になる。
