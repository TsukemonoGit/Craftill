# 追加レッスン: 現金の会計画面

元: `../siyou.md` A-5

**現金の会計画面**は、請求額を表示し、受け取ったお金を入力して、お釣りを出す画面です（A-5）。`../開発/5_画面構成.md` の「現金入力中」の図に対応します。ここは画面（UI）を出すので、**アプリ（App）**として新しく作ります。

現金会計で満たすこと:

- **請求額**を表示する（現金決済では全行の円合計）。
- **受取額**を入力する。**数字キー**と **1,000 / 5,000 / 10,000 円ボタン**で増やせる。
- **お釣り = 受取額 − 請求額**を自動計算する。
- 受取額 < 請求額の間は、**確定ボタンを無効**にする。
- 確定すると完了処理に進む。通信は不要。

> このファイルだけで完結します。アプリを新規作成し、そのまま貼れば動きます。

## 前提データ

```swift
import SwiftUI

// ── 商品（products 相当）────────────────
struct Product {
    let id: String
    let typeId: String
    let name: String
    let priceJpy: Int
    let priceSats: Int?     // この画面では円だけ使う
}

// ── カートの1行 ────────────────────────
// ── カートの行（形は 03_レッスン.md レッスン2 で決めたものと同じ）──
struct CartLine {
    let id: String          // 登録商品は商品ID、野良は "ADHOC-1" など
    let typeId: String?     // 登録商品は種類ID、野良は nil
    let name: String        // カートに入れた時点の商品名
    let unitPriceJpy: Int   // カートに入れた時点の円単価
    let unitPriceSats: Int? // カートに入れた時点のsats単価
    var qty: Int
    let isAdhoc: Bool       // 野良かどうか
}

/// 登録商品からカートの行を作る
func line(_ p: Product, qty: Int) -> CartLine {
    CartLine(id: p.id, typeId: p.typeId, name: p.name,
             unitPriceJpy: p.priceJpy, unitPriceSats: p.priceSats,
             qty: qty, isAdhoc: false)
}

// ── 商品のサンプル（../開発/6_データベース.md より）
let products: [Product] = [
    Product(id: "ST-001", typeId: "sticker",   name: "ステッカー まる",   priceJpy: 300, priceSats: 500),
    Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく", priceJpy: 300, priceSats: nil),
    Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01", priceJpy: 800, priceSats: 1200),
    Product(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02", priceJpy: 800, priceSats: 1200),
]

// ── カートの初期値（金額の合計が請求額になる）──
// ST-001×2（¥600）＋ KH-001×2（¥1600）＋ KH-002×2（¥1600）＝ ¥3800
let cart: [CartLine] = [
    line(products[0], qty: 2),   // ST-001
    line(products[2], qty: 2),   // KH-001
    line(products[3], qty: 2),   // KH-002
]

// 請求額（現金決済。全行の円合計）
let totalJpy = cart.reduce(0) { $0 + $1.unitPriceJpy * $1.qty }   // ¥3800
```

## 16-1. 現金入力の状態をまとめる

「請求額」は動かない。「受取額」はボタンを押すたびに増える。お釣りと確定可否は計算で出します。

```swift
/// 現金入力の状態。
struct CashInput {
    let totalJpy: Int          // 請求額（動かない）
    var receivedJpy: Int = 0   // 受取額（増える）

    // お釣り = 受取額 − 請求額
    var changeJpy: Int { receivedJpy - totalJpy }

    // 確定してよいか（受取額が請求額以上）
    var canConfirm: Bool { receivedJpy >= totalJpy }

    // 表示用のお釣り（届く前はマイナスになるので 0 とみなす）
    var displayChangeJpy: Int { canConfirm ? changeJpy : 0 }

    // 数字キー: いまの受取額の後ろに数字を1つ足す
    mutating func pressDigit(_ d: Int) { receivedJpy = receivedJpy * 10 + d }
    // 「00」キー
    mutating func pressDoubleZero() { receivedJpy = receivedJpy * 100 }
    // 1桁消す（⌫）
    mutating func backspace() { receivedJpy = receivedJpy / 10 }
    // 1,000 / 5,000 / 10,000 円ボタン
    mutating func addQuick(_ yen: Int) { receivedJpy += yen }
}
```

- `var changeJpy: Int { ... }` … **計算プロパティ**。持たずに毎回計算する
- `mutating func` … `struct` の中身（`receivedJpy`）を書き換える関数に付ける印
- `pressDigit(7)` で 3 → 37 のように、末尾に数字を足す

## 16-3. 現金入力画面

請求額・受取額・お釣りを上に出し、下に数字キーと金額ボタン、確定ボタンを置きます。

```swift
struct CashView: View {
    // 受取額を @State で管理する（変えると画面が更新される）
    @State private var cash = CashInput(totalJpy: totalJpy)

    // 数字キーの並び（0〜9）
    private let keyRows: [[String]] = [
        ["7", "8", "9"],
        ["4", "5", "6"],
        ["1", "2", "3"],
        ["0", "00", "⌫"],
    ]
    // 1,000 / 5,000 / 10,000 円ボタン
    private let quickButtons = [1000, 5000, 10000]

    var body: some View {
        VStack(spacing: 16) {
            // ── 金額の表示 ──
            VStack(alignment: .trailing, spacing: 8) {
                amountRow("請求額", cash.totalJpy)
                amountRow("受取額", cash.receivedJpy)
                amountRow("お釣り", cash.displayChangeJpy)
            }
            .font(.title2)
            .frame(maxWidth: .infinity, alignment: .trailing)

            HStack(alignment: .top, spacing: 24) {
                // ── 数字キー ──
                VStack(spacing: 8) {
                    ForEach(keyRows, id: \.self) { row in
                        HStack(spacing: 8) {
                            ForEach(row, id: \.self) { key in
                                KeyButton(title: key) { press(key) }
                            }
                        }
                    }
                }

                // ── 金額ボタン ──
                VStack(spacing: 8) {
                    ForEach(quickButtons, id: \.self) { yen in
                        KeyButton(title: "+\(yen)") { cash.addQuick(yen) }
                    }
                }
            }

            // ── 確定（受取額 < 請求額の間は無効）──
            Button(action: confirm) {
                Text("確定")
                    .font(.title3).bold()
                    .frame(maxWidth: .infinity)
                    .padding(.vertical, 12)
                    .background(cash.canConfirm ? Color.accentColor : Color.gray.opacity(0.3))
                    .foregroundStyle(Color.white)
                    .cornerRadius(10)
            }
            .buttonStyle(.plain)
            .disabled(!cash.canConfirm)
        }
        .padding()
        .frame(width: 460, height: 520)
    }

    // 金額の1行
    private func amountRow(_ label: String, _ yen: Int) -> some View {
        HStack {
            Text(label).foregroundStyle(.secondary)
            Spacer()
            Text("¥\(yen)")
        }
    }

    // キーを押したときの処理
    private func press(_ key: String) {
        switch key {
        case "⌫":  cash.backspace()
        case "00": cash.pressDoubleZero()
        default:   if let d = Int(key) { cash.pressDigit(d) }
        }
    }

    private func confirm() {
        // ここで完了処理を呼ぶ（販売記録の保存・在庫の減算など）
        print("確定: 請求 ¥\(cash.totalJpy) / 受取 ¥\(cash.receivedJpy) / お釣り ¥\(cash.changeJpy)")
    }
}
```

- `.disabled(!cash.canConfirm)` … 受取額が請求額未満の間、確定ボタンが押せなくなる
- `@State private var cash` … 構造体ごと `@State` で持つ。書き換えると画面が再描画される

## できた合図

- 起動直後は 請求額 **¥3800**、受取額 **¥0**、お釣り **¥0**、確定ボタンは**押せない**
- 「5」「0」「0」「0」と押すと受取額が **¥5000** になり、お釣りが **¥1200**、確定ボタンが押せる
- ⌫ で1桁ずつ戻せる。「+1000」で受取額に1,000円を足せる
- 受取額が請求額に届くまで確定ボタンは無効のまま
- 確定を押すとコンソールに「確定: 請求 ¥3800 / 受取 ¥5000 / お釣り ¥1200」と出る

---

## ポイント

- お釣り = **受取額 − 請求額**。`changeJpy` の計算プロパティで自動計算する
- 受取額が請求額未満の間は `canConfirm` が false。`disabled(!cash.canConfirm)` で確定ボタンが無効になる
- 数字キーは `pressDigit` で末尾に足す。「00」は ×100、⌫ は ÷10
- 1,000 / 5,000 / 10,000 円ボタンは `addQuick` で受取額に足すだけ
- 会計状態（受取額など）は本番では端末内へ保存し、アプリ切替や再起動のあと復元する（A-3）
- 現金会計は**通信不要**で完了できる（A-10）
