## レッスン3: テスト商品を配列で用意する

**配列**＝同じ型のものを順番に並べたもの。`[ ]` で囲み `,` で区切る。
`[Product]` は「**Product の配列**」という意味。

```swift
let products: [Product] = [
    Product(id: "ST-001", name: "ステッカー まる",   priceJpy: 300, priceSats: 500,  stock: 10),
    Product(id: "ST-003", name: "ステッカー しかく", priceJpy: 300, priceSats: nil,  stock: 10),
    Product(id: "KH-001", name: "キーホルダー 01",   priceJpy: 800, priceSats: 1200, stock: 1),
    Product(id: "KH-008", name: "キーホルダー 08",   priceJpy: 800, priceSats: 1200, stock: 1),
]

print(products.count)   // 4（何個あるか）

for p in products {     // 1個ずつ取り出して繰り返す
    print(p.id, p.name, p.priceJpy)
}
```
- `products.count` … 配列の中身の**数**
- `for p in products { ... }` … 1つずつ `p` に入れて中を繰り返す（`for` 文）

**できた合図**: `4` と、4商品のID・名前・値段が並んで出る。

## レッスン4: 合計の2行を出す関数

**関数**＝処理をまとめて名付けたもの。`func 名前(引数) -> 返す型 { ... }`。
ここでは「商品の並び」を渡すと「①sats額 ②sats払い時の現金分 ③現金払いの合計」を返す関数を作る（`../開発/5_画面構成.md` の合計）。
3つの値をまとめて返すため、`struct Totals`（3つの合計を持つ入れ物）を使う。

```swift
struct Totals {
    var sats = 0                  // sats単価がある行のsats合計
    var jpyWithoutSatsPrice = 0   // sats単価がない行の円合計（sats払い時の現金分）
    var cashJpy = 0               // 全行の円合計（現金払い）
}

func totals(_ items: [Product]) -> Totals {
    var result = Totals()
    for p in items {
        if let s = p.priceSats {                  // sats単価がある行
            result.sats += s                       //   → sats合計に足す
        } else {                                  // sats単価がない行
            result.jpyWithoutSatsPrice += p.priceJpy  //   → sats払い時の現金分に足す
        }
        result.cashJpy += p.priceJpy               // 現金払いの合計には全部足す
    }
    return result
}

// 例: ST-001 と ST-003 を買ったとき
let t = totals([products[0], products[1]])
print("sats払い: \(t.sats) sats + ¥\(t.jpyWithoutSatsPrice)")
print("現金払い: ¥\(t.cashJpy)")
```
- `struct Totals` の `var sats = 0` … 初期値を持たせてあるため、`Totals()` と書くだけで3つとも `0` で作れる
- `result.sats += s` … `result` の中の `sats` に足す（`+=` は「足して代入」）
- `if let` で sats単価の有無を分ける（`1_初心者メモ.md` 参照）

**できた合図**: ST-001（sats500）＋ST-003（satsなし¥300）で
`sats払い: 500 sats + ¥300` / `現金払い: ¥600` が出る。

## レッスン5: ID正規化（`"kh8"` → `"KH-008"`）

入力したIDを**決まった形**に直す。今回は「英字（接頭辞）＋3桁ゼロ埋め」。

```swift
import Foundation   // String(format:) に必要（ファイル先頭で import 済みなら不要）

func normalizeID(_ raw: String) -> String {
    let upper  = raw.uppercased()                 // 小文字→大文字
    let letters = upper.filter { $0.isLetter }    // 英字だけ取り出す
    let digits  = upper.filter { $0.isNumber }    // 数字だけ取り出す
    let n = Int(digits) ?? 0                       // 数字にする（空なら0）
    return letters + "-" + String(format: "%03d", n) // 3桁ゼロ埋め
}

print(normalizeID("kh8"))     // KH-008
print(normalizeID("KH-020"))  // KH-020
print(normalizeID("st 1"))    // ST-001
```
- `.filter { }` … 条件に合う文字だけ残す
- `String(format: "%03d", n)` … 3桁にゼロ埋め（8 → 008）
- 全角の英字対応などは**後で**でよい（今は半角前提）
- 数字が無い入力（例: `"kh"`）は `KH-000` になる。エラー扱いにする処理は**後で**でよい

**できた合図**: `KH-008` / `KH-020` / `ST-001` が出る。

## レッスン6: 会計状態の enum と遷移

会計の「今どの段階か」を enum で表す（`../siyou.md` A-4）。`switch` で分岐する。
表示用の文言は、enum の中に `label`（計算プロパティ）として持たせる。

```swift
enum SaleState {
    case idle             // 待機中
    case scanning         // スキャン中
    case choosingPayment  // 支払方法選択
    case cashInput        // 現金入力中
    case satsWaiting      // sats待ち
    case done             // 完了

    var label: String {
        switch self {
        case .idle:            return "レジ待機中"
        case .scanning:        return "商品をスキャン中"
        case .choosingPayment: return "支払方法を選んでください"
        case .cashInput:       return "現金を受け取り中"
        case .satsWaiting:     return "satsの入金待ち"
        case .done:            return "会計完了"
        }
    }
}

print(SaleState.scanning.label)
```
- `switch` … 選択肢ごとに処理を分ける。`enum` と相性がよい
- `var label: String { ... }` … 呼ぶたびに値を計算して返す「計算プロパティ」。`state.label` の形で使える
- `self` … その enum 自身の値（今どの `case` か）
- `.scanning` は `SaleState.scanning` の省略形
- 状態を次へ進める処理（遷移）は、`../siyou.md` A-4 の仕様を確認してから追加する（このレッスンでは未実装）

**できた合図**: `商品をスキャン中` が出る。

## レッスン7: SwiftUIでレジ画面を1枚

Playgroundsでは `PlaygroundSupport` で画面を表示できる（`1_初心者メモ.md` の**ブック**で）。
左に商品、右にカートという2列（`../開発/5_画面構成.md` の図）。
商品一覧はレッスン3の `products`、合計はレッスン4の `totals` から作る。

```swift
import SwiftUI
import PlaygroundSupport

struct RegisterView: View {
    // カートの中身（例: ST-001 と KH-008）
    let cart: [Product] = [products[0], products[3]]

    var body: some View {
        HStack {
            VStack(alignment: .leading) {          // 左: 商品
                Text("商品").font(.headline)
                ForEach(products, id: \.id) { p in
                    Text("\(p.id) \(p.name)")
                }
            }
            .padding()
            Divider()
            VStack(alignment: .leading) {          // 右: カート
                Text("カート").font(.headline)
                ForEach(cart, id: \.id) { p in
                    Text("\(p.id) \(p.name)")
                }
                Text("合計 ¥\(totals(cart).cashJpy)").bold()
            }
            .padding()
        }
        .frame(width: 600, height: 320)
    }
}

PlaygroundPage.current.setLiveView(RegisterView())
```
- `HStack` … 横に並べる。`VStack` … 縦に並べる
- `ForEach(配列, id: \.id)` … 配列を1つずつ表示する。`id: \.id` は「各商品を `id` で見分ける」という指定
- `"\(p.id)"` … 文字列の中に値を埋め込む
- `totals(cart).cashJpy` … レッスン4の関数で現金払いの合計を計算する
- `PlaygroundPage.current.setLiveView(...)` … 作った画面を表示する（Playground専用）
- 同じ商品をカートに2個入れると `id` が重複し、表示が不安定になる可能性がある。数量の扱いは、レッスン8の `CartLine`（数量 `qty` 付き）のような型で**後で**扱う
- `PlaygroundSupport` は、プロジェクトの種類によっては使えない可能性がある（App 形式では動かない場合がある。未確認）

**できた合図**: 左に商品4つ、右にカート2つと `合計 ¥1100` が横並びで表示される。

## レッスン8: UserDefaultsにJSONで保存 → 復元

会計状態を保存して、アプリを閉じても残るようにする練習（`../開発/1_決定事項.md` の決定）。
保存する物には `Codable` という印を付ける。

```swift
import Foundation

struct CartLine: Codable {
    var id: String
    var name: String
    var priceJpy: Int
    var qty: Int
}

let cartKey = "cart"   // 保存場所の名前（複数箇所に直書きすると誤字に気づきにくいため定数にする）

// 保存
let lines = [CartLine(id: "ST-001", name: "ステッカー まる", priceJpy: 300, qty: 2)]
if let data = try? JSONEncoder().encode(lines) {
    UserDefaults.standard.set(data, forKey: cartKey)
    print("保存した")
}

// 復元
if let data = UserDefaults.standard.data(forKey: cartKey),
   let restored = try? JSONDecoder().decode([CartLine].self, from: data) {
    print(restored)   // [CartLine(id: "ST-001", ...)]
}
```
- `Codable` … 「JSONに変換してよい」という印
- `JSONEncoder()` … Swiftの値 → JSONデータ
- `JSONDecoder()` … JSONデータ → Swiftの値
- `try?` … 失敗するかもしれない処理（失敗したら nil）。失敗の原因を知りたくなったら `do { } catch { }` に切り替える
- `UserDefaults.standard` … 端末の簡単な保存場所
- `cartKey` … 保存と復元で**同じ名前**を使う必要がある

**できた合図**: `保存した` と、復元した中身が出る。
※ Playgroundsを閉じて開き直すと「復元」だけでも中身が残っているか試せる（環境により異なる）。
