# 追加レッスン: カートの種類ごとの追加ルール

元: `../siyou.md` A-1
`02_練習メニュー.md` の「7. カートの種類ごとの追加ルール」。

商品の「種類」ごとに、カートへ追加したときの動きが変わる（A-1 の表）。

| 種類 | `stock_mode` | 追加したとき |
| --- | --- | --- |
| 数量管理型 | `counted` | 数量+1。在庫を超えたらエラー |
| 一点物型 | `unique` | 常に数量1。すでにカートにあればエラー |
| 在庫管理なし型 | `none` | 上限なしで+1 |


> ここは**純ロジック**なので **ブック（Book）** で書ける（`01_初心者メモ.md`）。画面（SwiftUI）を作る回は **アプリ（App）** で作る。
> このファイルだけで完結。冒頭のコードをそのままPlaygroundsに貼り、その下に続けて書けば動く。

## 前提データ

```swift
// ── 種類（在庫の扱い）────────────────────
enum StockMode {
    case counted   // 数量管理型（ステッカーなど）
    case unique    // 一点物型（キーホルダーなど）
    case none      // 在庫管理なし型
}

// ── 商品1つ分（テーブル products 相当）──
struct Product {
    let id: String          // 商品ID  例: "KH-008"
    let typeId: String      // 種類ID  例: "keyholder"
    let name: String        // 商品名
    let priceJpy: Int       // 円価格
    let priceSats: Int?     // sats価格（nil なら sats単価なし）
    var stock: Int?         // 在庫（none は nil）
    let stockMode: StockMode
}

// ── サンプル商品 ──
let products: [Product] = [
    Product(id: "ST-001", typeId: "sticker",   name: "ステッカー まる",     priceJpy: 300, priceSats: 500,  stock: 10, stockMode: .counted),
    Product(id: "ST-002", typeId: "sticker",   name: "ステッカー さんかく", priceJpy: 300, priceSats: 500,  stock: 10, stockMode: .counted),
    Product(id: "ST-003", typeId: "sticker",   name: "ステッカー しかく",   priceJpy: 300, priceSats: nil,  stock: 10, stockMode: .counted),
    Product(id: "KH-001", typeId: "keyholder", name: "キーホルダー 01", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
    Product(id: "KH-002", typeId: "keyholder", name: "キーホルダー 02", priceJpy: 800, priceSats: 1200, stock: 1, stockMode: .unique),
    // ... 以降省略 ...
]
```

## カートの行と追加結果の表現

カートは「商品＋数量」の並びで持ちます。また、追加の成否を画面側で表示しやすくするため、結果を `enum` で返します。

```swift
// カートの1行
struct CartLine {
    let product: Product
    var qty: Int
}

// 追加できたのか？
enum AddResult {
    case added(Product, qty: Int)   // 追加できた（いまの数量つき）
    case failed(String)             // 追加できなかった（理由）
}

func message(_ r: AddResult) -> String {
    switch r {
    case .added(let p, let qty): return "追加: \(p.name) × \(qty)"
    case .failed(let reason):    return "エラー: \(reason)"
    }
}
```

## 追加する関数（`inout` の活用）

```swift
func addToCart(_ product: Product, to cart: inout [CartLine]) -> AddResult {
    // 在庫管理ありで在庫0なら SOLD OUT（追加しない）
    if product.stockMode != .none, let stock = product.stock, stock == 0 {
        return .failed("\(product.name) は SOLD OUT です")
    }

    switch product.stockMode {
    case .unique:
        // 一点物型: すでにカートにあればエラー。数量は常に1
        if cart.contains(where: { $0.product.id == product.id }) {
            return .failed("\(product.name) はカート追加済みです")
        }
        cart.append(CartLine(product: product, qty: 1))
        return .added(product, qty: 1)

    case .counted, .none:
        // すでにカートにあるなら数量+1
        if let i = cart.firstIndex(where: { $0.product.id == product.id }) {
            let next = cart[i].qty + 1
            if let stock = product.stock, next > stock {   // counted だけ在庫チェック
                return .failed("\(product.name) は在庫 \(stock) を超えています")
            }
            cart[i].qty = next
            return .added(product, qty: next)
        }
        // 追加済み商品ではない場合（新規にひとつを追加）
        cart.append(CartLine(product: product, qty: 1))
        return .added(product, qty: 1)
    }
}
```

## 動作確認と合計の計算（`reduce` の活用）

```swift
var cart: [CartLine] = []

// 1. ST-001 を追加
print(message(addToCart(products[0], to: &cart)))
print("合計: \(cart.reduce(0) { $0 + $1.qty }) 個")

// 2. もう一度 ST-001 を追加 → 数量2
print(message(addToCart(products[0], to: &cart)))
print("合計: \(cart.reduce(0) { $0 + $1.qty }) 個")

// 3. KH-001 を追加
print(message(addToCart(products[3], to: &cart)))
print("合計: \(cart.reduce(0) { $0 + $1.qty }) 個")

// 4. もう一度 KH-001 を追加 → エラー（一点物型は重複不可）
print(message(addToCart(products[3], to: &cart)))
print("合計: \(cart.reduce(0) { $0 + $1.qty }) 個")
```

### 期待される出力結果
```text
追加: ステッカー まる × 1
合計: 1 個
追加: ステッカー まる × 2
合計: 2 個
追加: キーホルダー 01 × 1
合計: 3 個
エラー: キーホルダー 01 はカート追加済みです
合計: 3 個
```

## ポイント

1. **`inout` と `&`**  
   関数の引数に `inout` を付けると、「渡した変数そのものを直接書き換える」ことができます。呼び出し側は `&cart` と書いて「書き換えに同意する」必要があります。JS/TS の配列（参照型）のような挙動を、Swift の値型（配列）で実現する標準的な方法です。

2. **`reduce` による合計計算**  
   配列の要素を1つの値にまとめるには `reduce` を使います（JS の `Array.prototype.reduce` と同じ発想です）。  
   `cart.reduce(0) { $0 + $1.qty }` は、「初期値 `0`（`$0`）に対して、カートの各行（`$1`）の `qty` を順番に足し上げていく」処理です。  
   ※ Swift には `++` 演算子がないため、数量を増やす際は `+= 1` を使います。

3. **`switch` による種類の分岐**  
   - `unique`：カートに1行だけ存在可能。数量は常に1。再追加はエラー。
   - `counted` と `none`：すでにあれば `+1`。違いは**在庫チェックの有無**だけ。
   - SOLD OUT（在庫0）の判定は、在庫管理あり（`counted`・`unique`）の場合のみ行います。
