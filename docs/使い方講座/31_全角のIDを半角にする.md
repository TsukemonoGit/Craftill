# 31. 全角のIDを半角にする

元: `../siyou.md` A-2（手動入力）

**ゴール**: 手動入力のIDを正規形に直す。
全角英数字→半角、小文字→大文字、空白除去、**種類定義の接頭辞と照合**、番号は**種類の桁数でゼロ埋め**。
例: `ｋｈ８` → `KH-008`。

> 純ロジックの練習。**ブック（Book）**で作る。

## 31-1. 全角→半角は `applyingTransform` で

`String` には**文字を一括変換する**機能がある。全角英数字を半角にするのはこれで足りる。

```swift
let raw = "ｋｈ８"    // 全角の小文字＋全角数字
if let half = raw.applyingTransform(.fullwidthToHalfwidth, reverse: false) {
    print(half)      // kh8（半角になった）
}
```

- `.fullwidthToHalfwidth` … 全角→半角（全角英数字・全角空白など）
- `reverse: false` … 逆向き（半角→全角）にしない、の意味
- 戻り値は `String?`（失敗すると `nil`）

---

## 31-2. 正規形に直す関数

手順は「①全角→半角 ②大文字 ③空白除去 ④英字と数字に分ける ⑤接頭辞を種類定義と照合 ⑥桁数でゼロ埋め」。

```swift
/// 入力したIDを正規形（例: KH-008）に直す。接頭辞が種類定義になければ nil。
func normalizeProductID(_ raw: String) -> String? {
    // ① 全角→半角
    let half = raw.applyingTransform(.fullwidthToHalfwidth, reverse: false) ?? raw

    // ② 小文字→大文字
    let upper = half.uppercased()

    // ③ 空白（全角は半角化済み）を除去
    let noSpace = upper.filter { !$0.isWhitespace }

    // ④ 英字（接頭辞）と数字（番号）に分ける
    let prefix = String(noSpace.filter { $0.isLetter })
    let digitText = String(noSpace.filter { $0.isNumber })

    // ⑤ 接頭辞を種類定義と照合する（ここが独自ルール）
    guard let pt = productTypes.first(where: { $0.idPrefix == prefix }) else {
        return nil   // 知らない接頭辞はエラー
    }

    // ⑥ 番号を整数にして、種類の桁数でゼロ埋め
    guard let n = Int(digitText) else { return nil }
    let numbered = String(format: "%0\(pt.idDigits)d", n)

    return prefix + "-" + numbered
}
```

- `filter { $0.isLetter }` … 英字だけ残す（ハイフン `-` も落ちる）
- `productTypes.first { $0.idPrefix == prefix }` … 種類定義の接頭辞と照合
- `String(format: "%0\(pt.idDigits)d", n)` … `idDigits` が 3 なら `%03d`（8 → `008`）
- 桁数・接頭辞は**種類定義に従う**。ここを固定の `3` にしないのがポイント

## 31-3. 動かしてみる

```swift
for raw in ["ｋｈ８", "kh8", "KH-020", "st 1", "＊", "XY-1"] {
    if let id = normalizeProductID(raw) {
        print("\(raw) → \(id)")
    } else {
        print("\(raw) → エラー（対応する種類がない）")
    }
}
```

**できた合図**:
- `ｋｈ８ → KH-008`
- `kh8 → KH-008`
- `KH-020 → KH-020`
- `st 1 → ST-001`
- `＊ → エラー（対応する種類がない）`
- `XY-1 → エラー（対応する種類がない）`

## 31-4. 存在する商品かを調べる

正規化したあと、そのIDの商品が登録にあるかを見る。

```swift
/// 手動入力から商品を探す。見つからなければ nil。
func findProduct(_ raw: String) -> Product? {
    guard let id = normalizeProductID(raw) else { return nil }
    return products.first { $0.id == id }
}

print(findProduct("ｋｈ８")?.name ?? "見つかりません")   // キーホルダー 08
print(findProduct("kh9")?.name ?? "見つかりません")     // 見つかりません（KH-009 はサンプルに無い）
```

## ポイント
- 手動入力は**補正する**（全角→半角、大文字、空白除去、ゼロ埋め）。CSV取り込みは補正しない、という違いに注意
- 接頭辞は**種類定義の `idPrefix`**、桁数は**種類定義の `idDigits`** に従う
- 知らない接頭辞（種類が無い）はエラー。**存在しないIDはカートに追加しない**
- `applyingTransform` を使わない場合でも、全角「０〜９ Ａ〜Ｚ ａ〜ｚ」を辞書で置き換えれば同じことができる
