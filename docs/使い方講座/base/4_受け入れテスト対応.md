## 6. この表の使い方

1. レッスンを直すとき、**この表の該当行を見て記号だけ更新**する（○ → △ → —）
2. 新しいレッスンを作るときは、まずこの表を見て「既にどのレッスンが扱うか」を確かめる
3. C-6 に新しい項目が足されたら、この表にも足す（`../siyou.md` が正）
