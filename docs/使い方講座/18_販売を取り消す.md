# 販売を取り消す

元: `../siyou.md` A-9

完了した会計を**取り消す**（`status = voided`）練習。**管理操作**なので **PIN認証**が必要です（A-11）。

- 取消の本体: `sales.status` を `voided` にする。
- **在庫を戻す**: 在庫管理あり（`counted`・`unique`）の**登録商品**だけ。`stock_movements` に `void`（`+数量`）を記録する（A-7）。
- **在庫管理なし型**・**野良商品**は在庫の対象外なので**戻さない**。
- 返金済みフラグ（`refunded`。sats分）は**別操作**（PIN必須）。Lightningの返金は**システム外**（WoS操作）で手動対応する。
- **sats受領済みで中断した会計**（A-4）は完了前なので、**在庫を戻さない**。

> このレッスンは**純ロジック**なので、iPadの **ブック（Book）** にそのまま貼って動きます。
> 画面（SwiftUI）は **アプリ（App）** で作ります（`01_初心者メモ.md`）。

## 大問: 販売を取り消す

### 小問1: PINを確認する

`voidSale` の最初でPINを照合します。違えば何もしません。

```swift
enum VoidResult {
    case success([String])   // 成功（変化のメモ）
    case failure(String)     // 失敗（理由）
}

func resultText(_ r: VoidResult) -> String {
    switch r {
    case .success(let memo): return "OK: " + memo.joined(separator: " / ")
    case .failure(let reason): return "失敗: \(reason)"
    }
}
```

### 小問2〜3: 取消の本体（在庫を戻す → `voided` にする）

```swift
/// 販売を取り消す。PIN必須。
/// - 在庫管理ありの登録商品だけ在庫を戻し、stock_movements に void を記録する。
/// - 在庫管理なし型・野良は戻さない。
func voidSale(saleId: String,
              pin: String, correctPIN: String,
              sales: inout [Sale],
              items: [SaleItem],
              products: inout [Product],
              movements: inout [StockMovement],
              at: String) -> VoidResult {

    // ── PIN認証（A-11）──
    guard pin == correctPIN else { return .failure("PINが違います") }

    guard let si = sales.firstIndex(where: { $0.saleId == saleId }) else {
        return .failure("会計が見つかりません: \(saleId)")
    }
    // 完了していない / すでに取消済みは対象外。
    // sats受領済みで中断した会計は status が voided なので、ここで弾かれる（在庫は戻さない）
    guard sales[si].status == "completed" else {
        return .failure("この会計は取り消せません（完了していない / すでに取消済み）")
    }

    var memo: [String] = []

    // ── 在庫を戻す（在庫管理ありの登録商品のみ）──
    for item in items where item.saleId == saleId {
        guard item.itemType == "registered",
              let productId = item.productId,
              let pi = products.firstIndex(where: { $0.id == productId }) else { continue }
        // 在庫管理なし型は在庫の対象外 → 戻さない
        guard products[pi].stockMode != .none else { continue }

        let current = products[pi].stock ?? 0
        let restored = current + item.qty
        products[pi].stock = restored                     // 在庫を戻す
        movements.append(StockMovement(productId: productId,
                                       delta: item.qty,   // 戻すのでプラス
                                       reason: "void",
                                       saleId: saleId,
                                       at: at))
        memo.append("\(products[pi].name): 在庫 \(current) → \(restored)")
    }

    // ── 販売記録を取り消し状態にする ──
    sales[si].status = "voided"
    memo.insert("会計 \(saleId) を voided にしました", at: 0)

    return .success(memo)
}
```

### 小問5: sats受領済みで中断した会計は戻さない

会計4（`status = voided`、`completed_at` が空）は**完了前**なので在庫が戻っていません。取消を呼んでも弾かれます。

```swift
let r4 = voidSale(saleId: "S-20261013-004", pin: pin, correctPIN: pin,
                  sales: &sales, items: saleItemSeed,
                  products: &products, movements: &movements,
                  at: "2026-10-13T11:35:00+09:00")
print(resultText(r4))   // 失敗: この会計は取り消せません（...）
print("ST-001 在庫:", products.first { $0.id == "ST-001" }!.stock!)   // 10 のまま（動かない）
```

**できた合図**: 失敗のメッセージが出て、在庫は 10 のまま。

## 返金済みフラグ（sats分）

返金は**別操作**（PIN必須）。`refunded` を立てるだけで、実際の返金は **WoS（システム外）で手動**（A-9）。

```swift
func setRefunded(saleId: String, pin: String, correctPIN: String,
                 sales: inout [Sale]) -> VoidResult {
    guard pin == correctPIN else { return .failure("PINが違います") }
    guard let i = sales.firstIndex(where: { $0.saleId == saleId }) else {
        return .failure("会計が見つかりません")
    }
    guard sales[i].confirmedAt != nil else {
        return .failure("satsを受け取った会計ではありません")
    }
    sales[i].refunded = true
    return .success(["会計 \(saleId) を返金済みにしました（WoSでの返金は別途手動）"])
}

print(resultText(setRefunded(saleId: "S-20261013-002", pin: pin, correctPIN: pin, sales: &sales)))
```

**できた合図**: `OK: 会計 S-20261013-002 を返金済みにしました（WoSでの返金は別途手動）`

## ポイント

- 取消は**管理操作**。PIN認証を最初に通す（A-11）。
- 取り消せるのは**完了した会計**だけ。すでに `voided` の会計は何もしない。
- 在庫を戻すのは**在庫管理ありの登録商品だけ**。`none`・野良は `guard` で飛ばす。
- 在庫を戻したら、必ず `stock_movements` に `void`（`+数量`）を記録する（A-7）。
- **sats受領済みで中断した会計**（`completed_at` が空の `voided`）は、完了前なので**在庫を戻さない**。
- 返金済みフラグは別操作。実際のsats返金は**システム外**の手動対応（A-9）。
