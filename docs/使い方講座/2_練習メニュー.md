# 練習メニュー

MacBookが無くても、iPadの **Swift Playgrounds** で先に学べる。
ここで書いた**ロジック（合計・ID正規化・状態・保存）はほぼそのままMac/Xcodeに持っていける**。ただし画面表示の `PlaygroundSupport`（レッスン7）はPlayground専用なので、Macでは書き換えが必要。目標は「Macが来たら `../開発/4_最小構成やること.md` に合流」すること。

## iPadでできる（Macに持っていける）
- Swiftの基本（変数・if・ループ・関数・構造体・enum・オプショナル）
- SwiftUI（画面の組み立て。表示部分の `setLiveView` はMacで書き換え）
- ロジック（合計・在庫・ID正規化・状態遷移）
- UserDefaults（会計状態の保存にそのまま使う）

## Macでないとできない（今は無視）
- Xcode本体・macOSアプリのビルド
- SQLite、内蔵カメラのQR読取、保存ダイアログ
