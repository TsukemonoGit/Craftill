# 決定事項（確定していること）

「そのまま作っていいこと」だけ。迷ったらここ。詳細は `../siyou.md` の節（A-1 など）。

## 開発環境（確定）
- 言語: **Swift**（SwiftUI／UIKit）
- QR読み取り: **OS標準の読み取り機能 か ライブラリ のどちらか**で行う（どちらかで確定）
- 開発機: **Neo（MacBook）でXcodeを使い、開発・実行する**（Neoで開発することは確定）
- 署名: **無料で行う。課金しない**（Developer Programには加入しない）。**期限は7日として扱う**
- 対象: **macOS（Neo）のみ**。iPad版は当面作らない（任意・後回し）

## 全体
- **ネイティブアプリ**。macOS＋Xcode、Neo 1台で開発と実行（A-16）
- 運用者は1人（店主＝売り子＝開発者）
- **現金会計は通信不要**。通信を切っても全機能が動く（A-10）
- B(公開Web)は付随機能。**無くてもAは成立**。A→BはCloudflare KV、遅延は許容（A-14）
- Neoは**タッチパネルなし**。本書の「タップ」＝クリック

## 価格
- 円価格・sats価格は**商品ごとに事前確定**。登録商品の営業中改定なし（A-1）
- **レート換算はしない**。sats額は事前登録値のみ（A-6-1）
- sats価格は空でよい。空の商品は sats払いでも**現金で受け取る**（A-6-1）
- sats価格は、**円価格ごとの対応表**で一括設定できる（待機中・PIN必須）。空欄は変更しない。レート換算はしない（A-1）
- 野良商品は営業中に金額入力。**円価格に上限なし**。sats価格は任意（A-1）

## 商品の種類
- 商品は必ず「種類」に属する。既定3種類（A-1）
  - 数量管理型 `counted`＝残りN個、完了で減算
  - 一点物型 `unique`＝在庫0/1、カート数量は常に1
  - 在庫管理なし型 `none`＝在庫を持たない、SOLD OUTなし
- 種類は**種類定義CSV**で持つ。**再ビルド不要**で追加できる（A-1）
  - ※ CSV取り込み＝「商品登録機能」は**後回し**（作業手順P4）。最初はテスト商品を決め打ちで使う
- ID形式＝`<接頭辞>-<番号>`。番号は種類ごとの桁数でゼロ埋め（例 `KH-008`）（A-1）
- 商品画像は**ビルド時にアプリへ同梱**。実行時の取り込み・差し替えなし（A-1）

## レジ・会計
- 追加経路は4つ：QR読み取り／ID手動入力／商品パネル／野良追加（A-2）
- 商品パネルとカートは**同一画面**（A-3）
- 合計表示は**2行固定**（A-3）:
  ```
  sats払い　○○sats ＋ ○○円
  現金　　　○○円
  ```
- sats払いは行ごとに受取方法が決まる：sats単価あり→sats、なし→現金（**併用会計**）（A-6-1）
- 会計状態は**更新のたびに端末内保存**。アプリ切替・強制終了・再起動・スリープ後に復元（A-3）
- 会計状態: 待機中→スキャン中→支払方法選択→（現金入力中 または sats待ち→併用現金入力中）→完了（A-4）

## 在庫
- 現在庫は**端末内DBが唯一の正**。管理対象は `counted`・`unique` の登録商品のみ（A-7）
- 減算は**完了時のみ**。中断・取消では減算しない（A-7）
- 変動は `stock_movements` に全件記録（initial/sale/void/adjust）（A-7）

## sats / WoS
- WoSでInvoiceを作成し客が払う。レジは**Invoice文字列を保持しない**（A-6-2）
- **1会計1Invoice**。再利用しない（A-6-2）
- 入金確認は**手動**（店主がWoSで確認→「済」ボタン）。自動確認はしない（A-6-3）
- 店主がWoSへ入力する額は**請求sats額のみ**。現金分は入れない（A-6-1）
- WoSは自己管理型前提（日本で確認できている）（A-15）

## 取消・認証
- 販売取消は完了後の管理操作。**PIN必須**（A-9）
- PIN必須の操作：販売取消／在庫手動調整／CSV再取り込み／エクスポート／sats確認済み併用会計の中断／返金済みフラグ設定（A-11）
- 野良商品の追加、カートの追加・削除はPIN不要（A-11）
- 中断の扱い（A-4）:
  - 通常中断＝販売確定なし・在庫変動なし・**記録なし**
  - sats確認済み中断＝`status=voided` の記録を残す（`confirmed_at` あり、`completed_at` 空）。在庫は未減算のまま

## 野良商品（登録外）
- 営業中にカート画面から追加。在庫対象外・`stock_movements` 記録なし（A-1）
- **Bへ送らない**・価格一覧に含めない（A-1）
- カート行に「野良」表示（A-1）

## データ
- 端末内 **SQLite等**。アプリ削除でデータも消える想定（要確認）（A-16）
- **会計状態（カート・支払方法・請求額など）は UserDefaults に JSON で保存**（変わるたび保存、完了/中断で消す。仮置きだが当面これでよい）（A-3）
- テーブル: `product_types` / `products` / `sales` / `sale_items` / `stock_movements` / `sync_log`（A-13）
- 販売の `method`: `cash` / `lightning` / `mixed`（A-13）
- 明細の `paid_in`: `jpy` / `sats`（A-13）

## 公開サイト(B)
- 閲覧のみ・認証なし。書き込み機能なし（B-3）
- Aのスナップショットで**全商品を置き換え**（1キー保存）（B-2）
- 画像はAから送らず、開発者がMacから**別途デプロイ**（A-14）
- 非公開商品・野良商品は表示しない（B-1）
