# 入口

## これは何か
フリマで **1人・Mac 1台** で使う **レジ・在庫管理のネイティブアプリ**。
sats(Lightning)決済は **Wallet of Satoshi(WoS) を手で操作**して受け取る。
おまけで **公開Webサイト(B)** がある（無くてもレジは成立する）。

## 優先順位
1. **レジ機能** 今回使いたい商品（下のテスト商品）を、フリマで使えるようにする。
2. **Web公開** レジができてから。
3. **拡張＝他の商品にも使えるようにする。** 商品登録機能（CSV取り込み・A-18等）をあとから足す。

**最小構成＝レジ機能のみ。** 拡張もWebも含めない。まず最小機能を作り、徐々に増やす。

### テスト商品（今いれてあるもの＝今回使いたい商品）
| 種類 | 個数 | ID |
| --- | --- | --- |
| ステッカー（数量管理型） | 3種 | ST-001〜003 |
| キーホルダー（一点物型） | 20点 | KH-001〜020 |

- 商品登録機能は無くてよい。テスト商品は**決め打ち**で用意する。
- 最終的には任意の商品を登録できる（種類・商品をCSVで定義。再ビルド不要）が、それは**拡張** → `../siyou.md` A-1・A-18

## 最初に作るもの（P1）
**テスト商品＋現金だけで1日店が回るレジ。**
sats・商品登録機能・Web公開は後（P2〜P5）。

> まだMacが無い場合は、iPadで `8_iPadで準備.md` を先に進めておく。

## 進め方（1サイクル＝1タスク）
1. `4_最小構成やること.md` の一番上の「未チェック」を **1つだけ**選ぶ
2. 分からなければ `1_決定事項.md`、それでも分からなければ `../siyou.md` の該当節 **1つだけ**読む
3. 実装する
4. 「OK」を満たすか確かめる
5. チェックを付ける

まとめて読まない。1つずつ。
