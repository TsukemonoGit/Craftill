# 覚えておくこと
- **営業中は準備画面に入れない**（誤操作防止）。準備へ戻る時はPIN
- 商品パネルとカートは**同一画面**（確定事項 A-3）
- QR読取ラベル生成は当日の前提なので最小構成に含む
- 横幅・配置は P0 で実機確認して決める（Q16）
