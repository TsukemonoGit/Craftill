# データベース仕様（端末内 SQLite）

元ネタ: `../siyou.md` の A-13。ここは実装用にまとめ直したもの。

## 方針
- 端末内 **SQLite**。**現在庫・販売はここが唯一の正**。
- 金額は**整数**。**円とsatsは合算しない**（別の列）。
- 日時は ISO 8601（タイムゾーン付き）の文字列。**仮置き**
- 最小構成で使う: `product_types` / `products` / `sales` / `sale_items` / `stock_movements`
- `sync_log` は Web公開(B)・P5 で使う

---

## product_types（商品の種類）
| 列 | 型 | 制約 | 説明 |
| --- | --- | --- | --- |
| `type_id` | TEXT | PK | 種類ID（例 `sticker`） |
| `name` | TEXT | NOT NULL | 表示名（例 ステッカー） |
| `id_prefix` | TEXT | NOT NULL, UNIQUE | 接頭辞（例 `ST`） |
| `id_digits` | INTEGER | NOT NULL | ID桁数（例 3） |
| `stock_mode` | TEXT | NOT NULL | `counted` / `unique` / `none` |
| `attr_label_1` | TEXT | NULL | 属性ラベル（例 色） |
| `attr_label_2` | TEXT | NULL | （例 模様） |
| `attr_label_3` | TEXT | NULL | |
| `updated_at` | TEXT | NOT NULL | 更新日時 |

## products（商品）
| 列 | 型 | 制約 | 説明 |
| --- | --- | --- | --- |
| `product_id` | TEXT | PK | `ST-001` 形式 |
| `type_id` | TEXT | NOT NULL, FK→product_types | 種類 |
| `name` | TEXT | NOT NULL | 商品名 |
| `price_jpy` | INTEGER | NOT NULL, ≥1 | 円価格 |
| `price_sats` | INTEGER | NULL, ≥1 | sats価格。**NULLなら sats払いでも現金で受け取る** |
| `stock` | INTEGER | NULL | 在庫。`none`はNULL、`counted`は≥0、`unique`は0/1 |
| `attr_1` | TEXT | NULL | 属性の値 |
| `attr_2` | TEXT | NULL | |
| `attr_3` | TEXT | NULL | |
| `image_ref` | TEXT | NULL | 同梱画像への参照。**アプリ内のみ。Bへ送らない** |
| `is_public` | INTEGER | NOT NULL | `1`公開 / `0`非公開 |
| `updated_at` | TEXT | NOT NULL | 更新日時 |

- Bへ送る `has_image`（画像の有無）は、`image_ref` の有無から**導出**する（列には持たない）

## sales（会計1件）
| 列 | 型 | 制約 | 説明 |
| --- | --- | --- | --- |
| `sale_id` | TEXT | PK | |
| `status` | TEXT | NOT NULL | `completed` / `voided` |
| `method` | TEXT | NOT NULL | `cash`（全額現金）/ `lightning`（satsのみ）/ `mixed`（併用） |
| `total_jpy` | INTEGER | NULL | 現金で受け取る請求額（`cash`=円合計、`mixed`=現金分、`lightning`=NULL） |
| `total_sats` | INTEGER | NULL | 請求sats額（`lightning`・`mixed`。`cash`=NULL） |
| `received_jpy` | INTEGER | NULL | 受取額（`cash`・`mixed`） |
| `change_jpy` | INTEGER | NULL | お釣り（`cash`・`mixed`） |
| `confirmed_at` | TEXT | NULL | sats入金の確認時刻（済ボタン承認。`lightning`・`mixed`） |
| `refunded` | INTEGER | NOT NULL | 返金済みフラグ（sats分）。既定0 |
| `completed_at` | TEXT | NULL | 完了日時。**sats確認済みで中断した会計はNULL** |

## sale_items（明細）
| 列 | 型 | 制約 | 説明 |
| --- | --- | --- | --- |
| `item_id` | TEXT | PK | |
| `sale_id` | TEXT | NOT NULL, FK→sales | |
| `item_type` | TEXT | NOT NULL | `registered` / `adhoc`（野良） |
| `type_id` | TEXT | NULL | 販売時点の種類ID（`registered`のみ） |
| `product_id` | TEXT | NULL | FK（`registered`のみ） |
| `qty` | INTEGER | NOT NULL | 数量 |
| `unit_price_jpy` | INTEGER | NOT NULL | 販売時点の円単価 |
| `unit_price_sats` | INTEGER | NULL | 販売時点のsats単価（sats価格が空の行はNULL） |
| `paid_in` | TEXT | NOT NULL | `jpy` / `sats`。この行の受取方法 |
| `name_snapshot` | TEXT | NOT NULL | 販売時点の商品名（野良は入力名、未入力は「野良」） |

- `cash` の会計は**全行 `jpy`**。`lightning`・`mixed` は `unit_price_sats` がある行が `sats`、ない行が `jpy`

## stock_movements（在庫変動）
| 列 | 型 | 制約 | 説明 |
| --- | --- | --- | --- |
| `id` | TEXT | PK | |
| `product_id` | TEXT | NOT NULL, FK→products | |
| `delta` | INTEGER | NOT NULL | 増減数（+/-） |
| `reason` | TEXT | NOT NULL | `initial` / `sale` / `void` / `adjust` |
| `sale_id` | TEXT | NULL, FK→sales | |
| `at` | TEXT | NOT NULL | 日時 |

## sync_log（Bへの送信ログ）※P5
| 列 | 型 | 説明 |
| --- | --- | --- |
| `id` | TEXT PK | |
| `at` | TEXT | 送信試行日時 |
| `result` | TEXT | `success` / `failed` |
| `detail` | TEXT | エラー内容 |

---

## 最小構成での使われ方
| 場面 | 触るテーブル |
| --- | --- |
| 起動 | `product_types`・`products` を読む（テスト商品は決め打ちで入っている） |
| カート追加/削除 | **保存しない（メモリ上。ただし会計状態は別途保存。下記）** |
| 会計完了 | `sales`＋`sale_items` を追加、`products.stock` を減算、`stock_movements` に `sale` |
| 販売取消 | `sales.status=voided`＋`refunded`、`products.stock` を戻す、`stock_movements` に `void` |
| 手動在庫調整 | `products.stock` 変更、`stock_movements` に `adjust` |

### 会計の例1: 現金会計（`method = cash`）
ステッカー2枚（¥300×2）＋ キーホルダー05（¥800×1）= **¥1400**。受取 ¥2000、お釣り ¥600。
```sql

(sale_id, status, method, total_jpy, total_sats, received_jpy, change_jpy, confirmed_at, refunded, completed_at) VALUES
('S-20261013-001','completed','cash',1400,NULL,2000,600,NULL,0,'2026-10-13T11:00:00+09:00');

INSERT INTO sale_items
(item_id, sale_id, item_type, type_id, product_id, qty, unit_price_jpy, unit_price_sats, paid_in, name_snapshot) VALUES
('I-001','S-20261013-001','registered','sticker',  'ST-001',2,300,500,'jpy','ステッカー まる'),
('I-002','S-20261013-001','registered','keyholder','KH-005',1,800,1200,'jpy','キーホルダー 05');

INSERT INTO stock_movements (id, product_id, delta, reason, sale_id, at) VALUES
('M-101','ST-001',-2,'sale','S-20261013-001','2026-10-13T11:00:00+09:00'),
('M-102','KH-005',-1,'sale','S-20261013-001','2026-10-13T11:00:00+09:00');
-- products: ST-001 stock 10→8、KH-005 stock 1→0
```

### sats確認済みで中断した会計（`status = voided`）
在庫は減らさない。`completed_at` は空、`confirmed_at` は入る。
```sql
INSERT INTO sales
(sale_id, status, method, total_jpy, total_sats, received_jpy, change_jpy, confirmed_at, refunded, completed_at) VALUES
('S-20261013-004','voided','mixed',300,1200,NULL,NULL,'2026-10-13T11:20:00+09:00',0,NULL);
-- sale_items は残す。stock_movements は発生させない
```

## 補足
- **会計状態（カート・支払方法・請求額など）の保存先は未規定。** 案：`current_state` テーブルに1行JSON、またはUserDefaults。**仮置き**
- 円換算レートは持たない（Q8）
- 野良商品の委託元を別列で持つかは未決定（Q13）
- インデックスの案: `products(type_id)`、`sale_items(sale_id)`、`stock_movements(product_id)`
- テーブル構成の詳細元: `../siyou.md` A-13
