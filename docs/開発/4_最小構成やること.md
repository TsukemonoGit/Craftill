# 最小構成やること（まずこれだけ）

**ゴール:** テスト商品を、レジで会計して、在庫が減る。**現金のみ。**
（sats・商品登録機能・Web公開(B)はやらない。頭に置くだけ）

進め方: **上から1つずつ。** 各項目の「OK」を満たせば完了。`../siyou.md` を見るのは詰まった時だけ。

**未決定はもう無い。** 会計状態の保存先は `UserDefaults` に決定済み（`2_未決定事項.md` §12）。
作業中に実機を見て決めてメモするのは次の2つだけ。
- レジ画面の配置（商品パネルとカートの並べ方）
- カメラの設置方法・営業中のスリープ無効（Neoの設定）

---

## 1. 土台（まず環境）
- [ ] **Neoのモデル・macOSバージョンを見てメモする**（どこかに書き残すだけでよい）→ OK: メモできた
- [ ] **Swift環境をととのえる**（NeoにXcode、新規プロジェクトを作る）→ OK: プロジェクトができる
- [ ] ビルドしてNeoで起動する → OK: アプリが起動する
- [ ] 画面を1つ表示する（`Hello`でよい）→ OK: 画面が出る
- [ ] **データベースのよみとり・書き込みを確認する**（SQLite等）→ OK: テーブル作成 → 1行追加 → 読める

## 2. 商品データを入れる
- [ ] 商品テーブルを作る → OK: 商品を保存できる
- [ ] テスト商品を入れる（ステッカー3 ST-001〜003・キーホルダー20 KH-001〜020）→ OK: 23件が読める
- [ ] 商品画像を同梱して1枚表示する → OK: 画像が出る

## 3. QR（商品IDのQRを作る・読み取る）
QRの中身は**商品IDの文字列そのもの**（例 `KH-008`）。これで読み取ったIDを商品に結びつける。
- [ ] **商品IDのQRを生成する**（例 `KH-008` → QR）→ OK: QR画像が出る
- [ ] QRに**商品ID文字も併記**して、印刷できる形にする → OK: 印刷して商品に貼れる
- [ ] **テスト商品のQRラベルを作り、各商品に付ける**（テスト段階でも付ける）→ OK: 全商品にQRが付く
- [ ] **QR読取機能を確認する**（内蔵カメラでQRを読む）→ OK: QRの文字（例 `KH-008`）が取れる
- [ ] 読んだIDから商品を引く → OK: 該当商品が分かる

## 4. 最小レジ
- [ ] 商品パネル（商品を一覧表示。クリックで追加）→ OK: クリックでカートに入る
- [ ] QRを読んでカートに追加 → OK: 読んだ商品がカートに入る
- [ ] カートを表示（商品名・単価・数量・小計・合計）→ OK: 合計が正しい
- [ ] 削除・数量の＋／－ → OK: 合計が変わる
- [ ] 現金会計（受取額を入力 → お釣り表示）→ OK: お釣りが正しい
- [ ] 会計完了で在庫を減らす → OK: 在庫が1減る
- [ ] 完了した会計をDBに残す → OK: 後から見える

## 5. 最低限の安全
- [ ] アプリを閉じて開き直しても、在庫とカートが残る → OK: 復元される
- [ ] 在庫0の商品は追加できない（SOLD OUT）→ OK: 押しても増えない
